# 数据保存与带回

## 在哪里找

软件首次默认保存到 `%LOCALAPPDATA%\MotionAcquisitionData`。在资源管理器地址栏粘贴这个路径可打开；若界面另选了目录，以界面目录为准。主窗口和 Direct 分别记住自己的设置，两处都要核对。

公共电脑建议明确选用个人可写、本地非云盘目录，例如 `C:\LabData\Grating`。不要采集到 GitHub 仓库、压缩包、OneDrive、网络盘或正在同步的目录。不要依赖公共 Windows 账号的默认目录长期保存。

## 每轮完成后

1. 确认采集已结束、日志已写完；Direct 完成必要的关闭使能操作。
2. 点“打开本次数据目录”或会话“定位会话目录”。检查 `samples.csv`、`manifest.json`、`config_snapshot.yaml`、`acquisition.log`、`events.jsonl`；直控还应有 `control_commands.jsonl`。失败/中断会话保留原样，检查 manifest 和日志，不改成 completed。
3. 回放双图，查看数据范围、失败读取和摘要；必要时“保存结果图 PNG”。PNG 是辅助结果，不能代替原始会话。
4. **复制整个会话目录并保留原目录名及内部结构**到 U 盘/移动硬盘；不剪切、不重命名原会话、不在 CSV 中手工删异常行。可连同当天数据根目录一起复制。
5. 现场记录和导出的图另存到 `notes` / `figures`，不写回原始会话。若有示波器波形，另存并在记录中注明关联会话；它不会自动进入本上位机 CSV。
6. 在备份位置重新打开一个会话回放，确认文件复制完整，再离开实验室。实验室电脑原件保留到备份核实后；自动清理政策由实验室管理员确认。

## 回宿舍

把完整会话复制到宿舍电脑的本地数据区，使用同版主窗口“打开会话目录”回放；不需要连接任何设备。离线查看和现场采集可分开完成，不需要把宿舍电脑搬去实验室。

本仓库用于软件和手册分发，不用于自动上传原始实验数据。不要把未发表数据随手提交到 Git。若实验室不能联网，提前把完整工具包及本手册存在 U 盘。

2026-09-17 后的新会话不再生成 `checksums.sha256`；没有该文件本身不表示采集失败。老会话已有的账本原样保留，不补写或重生成。
