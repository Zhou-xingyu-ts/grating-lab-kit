# 实验记录模板

复制到单独的现场记录目录后填写，不写回原始会话。

| 项目 | 本次记录 |
|---|---|
| 日期、操作者、实验室电脑/Windows 用户 | 待填 |
| 实验名称、目的 | 待填 |
| 软件标题/版本 | 待填，应核对 20261023-ux2 |
| Windows 版本及 x64 | 待填 |
| USB-CAN 型号/硬件 ID、驱动版本 | 待填 |
| interface / 通道 / bitrate / Node-ID | 待现场核对 |
| 驱动器型号、反馈源、轴、方向 | 待填 |
| 本次适用的逐线放行/缺口记录 | 待填；缺失不以本表替代 |
| 获准的连接、预检、使能、运动动作及范围 | 待填 |
| 工作方式：只读 / Direct | 待填 |
| 运动主站及其他主站关闭状态 | 待填 |
| 采样对象、请求周期、持续时间 | 待填 |
| 本地数据根目录、完整会话路径 | 待填 |
| 真实运动参数及单位依据；无依据记 raw | 待填 |
| 预检、错误码、运行结果、读取失败情况 | 待填 |
| 结束时使能/主站状态；不明记 unknown | 待填 |
| 图表、示波器波形等关联文件 | 待填 |
| U 盘备份路径及备份后回放确认 | 待填 |
