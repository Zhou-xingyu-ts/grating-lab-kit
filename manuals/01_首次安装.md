# 首次安装

整理日期：2026-10-31；适用上位机：20261023-ux2。

## 1. 电脑和文件

- 使用 Windows 10/11 x64；本包没有在 32 位、ARM 或 Linux 上验证。
- 有可写本地磁盘及数 GB 空间用于解压、临时文件和数据。安装系统驱动通常需要管理员协助；日常采集用固定的普通 Windows 账号即可。
- 下载完整 `GratingLabKit-Windows-x64-20261031-r2.zip`，完整解压。Motion Acquisition 在 `software\MotionAcquisitionV9`，无需另找安装程序。不要直接在压缩包中打开 EXE，不要只带一个 EXE。
- 建议程序放 `C:\LabTools\GratingLabKit`，采集数据在软件中明确设为自己可写的 `C:\LabData\Grating`，或使用默认 `%LOCALAPPDATA%\MotionAcquisitionData`。
- 若为定期清理、还原或重启丢失文件的公共电脑，必须在离开前把数据复制出去。

## 2. 安装 CAN 驱动（只在电脑缺少驱动时）

完整包中 `installers\PEAK-Drivers-Setup-official-20261031.zip` 是从 [PEAK 官方下载入口](https://www.peak-system.com/quick/DrvSetup) 下载的原包。解压后由实验室管理员按厂商安装程序操作，保留 USB-CAN 驱动与 PCAN-Basic 组件；PCAN-View 可供现场诊断。不要自动更新一台已经可用的采集电脑。

PEAK [驱动下载页](https://www.peak-system.com/support/downloads/drivers/)说明当前驱动包包含 PCAN-Basic。随包驱动是整理当日官网版本，**尚未在实验室电脑和现有 XCAN-USB 上验证**。宿舍电脑当前 `PCANBasic.dll` 为 5.0.1.1131、`Pcan_usb.sys` 为 5.1.2.20099；这只是迁移对照信息，不代表新下载包与其相同。

现有 USB-CAN 的现场记录为 `UTC-T01 / XCAN-USB`，硬件 ID `USB\VID_0C72&PID_000C`，曾通过 PEAK 兼容链路使用。它不因此成为厂商原装 PCAN 产品，也不能保证任何新驱动均兼容。若驱动不能识别，保留报错并核对适配器供应商支持的驱动，不改固件、不刷适配器。

本工具包不自动运行安装程序。驱动安装和后续接入设备是两步独立操作；不要为了检查安装而直接执行运动。

## 3. Servo Studio（需要时安装）

`installers\DINGS_Servo_Studio_20220712.zip` 是工作区已有官方软件下载包的原样副本，不是本次新下载版本。解压，按其中厂商安装程序及 [Servo Studio 官方手册](DINGS_Servo_Studio_Manual.pdf) 操作。

只读记录且驱动器已配置好时，不必为了上位机安装全部开发工具。驱动器调参、Jog、Home、厂商波形诊断等仍使用 Servo Studio。**Direct 连接前退出 Servo Studio，关闭其他 CAN 客户端**，防止重复主站或端口占用。

## 4. 先做无硬件的人工检查

1. 保持实验设备未连接，双击 `software\MotionAcquisitionV9\MotionAcquisitionV9.exe`。
2. 核对标题有 `20261023-ux2`，主窗口默认 Demo/离线。
3. 填好本地数据目录和实验名称，关闭再打开，核对保存目录。
4. 可在 Demo 中人工检查一次保存与回放；这些是模拟数据，实验名注明 `DEMO`，不算现场证据。
5. 可打开 Direct 查看界面，但先不要点击“连接并预检”。
6. 目标机是用户提供的小新 Pro 16 2021 / Ryzen 5 5600 / GTX 1650 / 16 GB；配置足以用于本上位机，具体 Windows 和驱动仍需核对。按 [新电脑调试信息](../debug/新电脑调试信息.md) 导出环境 JSON，并用 [随包原始会话](../reference-data/README.md) 检查离线回放。

这些步骤由操作者在新电脑执行，本次整理未代为运行新电脑检查。若程序打不开，按 [常见问题](04_常见问题.md) 排查；不需要先安装 Python、Keil、STM32 工具或 Git。
