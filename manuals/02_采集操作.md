# 采集操作

以下供获准后的现场操作。下载软件不代表已放行接线、上电、CAN 连接、预检、使能或运动；本次整理没有执行这些动作。

## 先选择一种工作方式

| 目的 | 程序 | 谁负责运动 |
|---|---|---|
| 只记录驱动器状态/位置 | 主窗口 `MotionAcquisitionV9.exe` | 既有经放行的运动入口；采集程序只读 |
| 既有固定单轴 +5000/-5000 counts 往返并记录 | `MotionAcquisitionV9Direct.exe` | Direct 自己控制，与采集共用 CAN client |
| 查看已采集的数据 | 主窗口或 Direct 的回放按钮 | 无设备连接 |

不要同时运行两种真实采集流程。Direct 用一个进程和一个 CAN 会话；不要另开主窗口连接同一适配器。其他真实控制主站须先完成各自关闭。若 Servo Studio 负责运动，要先确认它使用的连接方式和采集链路能共存；不要让两个 CAN 写主站同时控制台架。

## 现场开始前

- 确认使用的是原有 DS-BVM 单轴台架、原有反馈和已验收的接线，没有因换电脑而擅改驱动器参数。
- 核对当前上电前逐线放行矩阵、逐线验收记录和未闭合缺口。原工作区权威文档为 `02_实验与现场/01_当前执行/39_上电前逐线放行矩阵.md`、`40_逐线验收记录表.md`、`46_未闭环逐线缺口清单.md`；它们没有作为已放行记录复制到本仓库。缺少当次适用记录时先取得记录，不凭本手册放行。
- 操作者确认急停/STO、限位、Z 轴负载支撑和正负向行程余量；软件状态未知时停止后续动作。
- 核对适配器、通道、波特率和真实 Node-ID。历史现场基线是 `PCAN_USBBUS1 / 1 Mbps / Node 1`；`622` 是旧 UI/文件名线索，不能作为 CANopen Node-ID。
- 明确本次保存目录、实验名称、反馈源、操作者和动作范围，使用 [记录模板](05_实验记录模板.md)。

## A. 主窗口只读采集

1. 打开 `MotionAcquisitionV9.exe`，进入“采集”。
2. 在“只读连接”中选择“真实 PCAN/CANopen”，填写现场核实的 interface=`pcan`、通道、波特率、Node-ID。这里可以编辑；不要把 Direct 的固定参数当作通用配置。
3. 取得本次 CAN 只读连接许可后点“连接”，再点“只读通信测试”。保存失败对象和报错；测试失败先排查，不开运动。
4. 在“采集与保存”填实验名称、操作者、轴、方向、备注和**数据根目录**；核对采样周期、持续时间、对象勾选。20 ms 是请求周期，不保证七个 SDO 对象同时采样或达到 50 Hz。
5. 通信测试通过且本次采集获准后，点“开始采集”。需要运动时只使用已明确获准的既有运动入口。
6. 到时结束或点“停止采集”。**它只停止记录，不停止电机。** 运动由负责运动的入口收尾。
7. 确认会话已保存后“断开”；进入“会话管理与分析”查看本次摘要、回放并导出图。

## B. Direct 固定单轴运动采集

Direct 只适用于固定 `PCAN_USBBUS1 / 1,000,000 bit/s / Node 1`。三项任意一项与现场不符，停止使用该入口，不通过改系统设置凑成旧配置。

1. 完成其他主站关闭，退出 Servo Studio 和其他 CAN 客户端；打开 `MotionAcquisitionV9Direct.exe`。启动本身不连接设备。
2. 填“保存目录”和“实验名”。Direct 会单独记住这两项；新电脑不会带入宿舍电脑的设置。
3. 核对界面轨迹：`+5000 counts → 驻留 2 s → 返回 -5000 counts → 采集 2 s`。速度/加减速沿用驱动器已配置 raw 值，不在本窗口重新设定。此流程不是任意轨迹、Jog 或 Home。
4. 获准后点“1. 连接并预检”，检查原始状态、模式、错误码、预检位置和运动参数。预检会访问真实 CAN，总线只读也需要对应许可。
5. 仅在该次使能与固定往返获准、现场条件满足且预检通过后，点“开始运动采集”。不要因回放正常而认为运动已放行。
6. 正常往返完成后，**程序保持使能**。查看结果并点“关闭使能”，确认状态，再退出窗口。
7. 中止时用“停止并关闭使能”；异常或状态 unknown 时记录报错并按现场规程处置。软件 Halt→Disable 不是物理急停/STO。
8. 点“打开本次数据目录”；用“回放 / 保存结果图”查看完整会话。不要只复制截图或单个 CSV。

## 数据解释

- 给定/实际位置和跟随误差以原始 counts 保存；读取失败处断线，不代表位置归零。
- `0x6064` 是驱动器 Position Actual，不是独立自研光栅尺采样证明；速度/电流对象保留 raw，不擅自标成 RPM/mA。
- 默认不能宣称外部标定精度、硬实时、STM32/GM1 已验证或完整替代 Servo Studio。
