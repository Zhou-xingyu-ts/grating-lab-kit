## 3. 候选方向证据分配

| 方向 | 支撑文献线索 | 当前判断 |
|---|---|---|
| A 单轴外部全闭环与误差补偿 | Digital closed-loop nanopositioning；dual-loop nanopositioning；低速伺服 PI/PIP；摩擦补偿；赖建君系统 | 保底方向，适合开题前期和近期实验数据 |
| B 自研光栅尺反馈 XY 精密平台闭环控制 | XY compliant stage + ADRC；dual-linear-motor gantry robust contour control；cross-coupled ILC；dual-axis precision stage improved ILC；planar motion stage PID+DOB | 推荐主线，价值和可行性最平衡 |
| C 多自由度光栅反馈多轴/多自由度控制 | 多自由度光栅编码器综述；absolute-type multi-DOF grating encoder；grating-based multi-DOF laser linear encoder；NPS6D200 6D closed-loop stage；overactuated nanopositioning control allocation | 升级方向，需等自研光栅尺接口和平台资源明确 |
| D 面向纳米定位的先进控制算法 | ADRC nanopositioning；DOB-MPC；feedforward tuning by ILC；RBFNN predictive control；LSTM inversion feedforward-feedback | 算法储备，不建议单独作为主线 |

## 4. 推荐题目

首选题目：

```text
基于自研光栅尺反馈的精密运动平台建模与闭环控制方法研究
```

若李星辉明确支持二维平台和自研光栅尺样机：

```text
基于自研增量式光栅尺反馈的二维精密运动平台闭环控制与误差补偿研究
```

备选保底题目：

```text
基于自研光栅尺反馈的单轴精密运动平台外部全闭环控制与误差补偿研究
```

不建议题目：

```text
面向纳米定位的先进运动控制算法研究
```

原因：该题容易变成普通控制算法课题，削弱“自研光栅尺进入闭环控制”的组内锚点。
