# D3：有限模型竞争与域外失效

## 1. 总裁决

**D3 = `PARTIALLY_SUPPORTED`。**

现有数据足以运行一次有独立文件留出的有限模型竞争，并成功发现“一步拟合很好但free-run失效”的候选；数据不足以选出参数稳定、跨工况可迁移的最终模型。

## 2. 数据拆分

| 角色 | 文件/片段 | 样本轮次 | 条件 | 选择理由 |
|---|---|---:|---|---|
| 训练 | `202749` 第三次正向开始前的前缀 | 6,912 | 5000/50/150，2次完整往返 | 排除被窗口截断的第三次返回 |
| 同工况留出 | `203414` 全文件 | 11,986 | 5000/50/150，1次完整往返 | 不同采集文件 |
| 参数域外 | `202323` 全文件 | 5,980 | 5000/50/300，1次完整往返 | 同行程/速度，只改变A/D/J |

该拆分满足“独立文件验证”的最低形式，但留出和域外都只有一次完整往返，置信区间不足。

统一比较项包括训练误差、独立验证误差、参数稳定性、残差结构、跨参数迁移和域外性能下降；一步预测与free-run分开报告。

## 3. 有限候选

| 候选 | 结构用途 | 复杂度 |
|---|---|---:|
| unit-gain bias | `y=u+b` 静态偏差基线 | 1个自由参数 |
| static affine | `y=a u+b` 静态斜率+偏差 | 2 |
| ARX1 | 上一输出+上一输入 | 3 |
| ARX1 delay2 | 上一输出+两拍前输入 | 3 |
| ARX1 direction | ARX1+当前demand方向符号 | 4 |
| ARX2 | 两拍输出+两拍输入 | 5 |

所有候选只解释商业闭环整体，不对应物理M/B/K或内部环。

## 4. 统一结果

| 候选 | 训练一步/free-run RMSE | 同工况留出一步/free-run | 域外一步/free-run | 稳定性/残差裁决 |
|---|---:|---:|---:|---|
| unit-gain bias | 9.284 / 9.284 | 3.974 / 3.974 | 11.585 / 11.585 | 稳定朴素基线，残差强相关 |
| static affine | 8.788 / 8.788 | 3.940 / 3.940 | 11.552 / 11.552 | 增益稳定，偏置漂移 |
| ARX1 | 6.976 / 239.558 | 3.727 / 128.831 | 5.490 / 185.155 | 递推发散，拒绝 |
| ARX1 delay2 | 5.793 / 发散 | 2.844 / 发散 | 5.559 / 发散 | 留出有限预测不足1%，拒绝 |
| ARX1 direction | 2.952 / 发散 | 1.516 / 发散 | 2.286 / 发散 | 方向项改善一步误差但掩盖不稳定，拒绝 |
| ARX2 | 1.712 / 8.284 | 0.893 / 3.632 | 1.547 / 11.332 | free-run稳定但域外退化、残差相关 |

单位为 counts。

## 5. 模型复杂度收益

- 同工况留出：ARX2 free-run 3.632，比静态仿射3.940只改善约7.8%。
- A/D/J=300域外：ARX2 11.332，比静态仿射11.552只改善约1.9%。
- ARX2同工况free-run残差一阶相关约0.966，说明“误差结构仍未解释”。

因此复杂模型没有在域外形成与复杂度相称的收益。当前合理裁决是保留静态基线和ARX2作为下一轮有限候选，不宣布ARX2胜出。

## 6. 参数稳定性

| 模型 | 三文件重拟合结果 | 裁决 |
|---|---|---|
| static affine | 增益1.00084—1.00154；截距-1.73…-0.48 counts | 局部静态关系相对稳定，偏置随文件变 |
| ARX1 | 输出系数0.973/1.044/1.007；输入系数+0.027/-0.044/-0.007 | 输入系数变号，不是稳定一阶对象 |
| ARX1 delay2 | 输出系数1.171—1.467 | 不稳定 |
| ARX1 direction | 方向系数13.80—15.18，但递推发散 | 不能因系数看似稳定就接受模型 |
| ARX2 | 四系数随文件明显变化 | 结构候选，不是已辨识参数集 |

## 7. 域外失效是否已被检测

是，但只能作为一次案例：

- 静态和ARX2在同工况留出约3.6—4.0 counts；
- 到A/D/J=300文件均退化到约11.3—11.6 counts；
- ARX2的额外复杂度没有阻止域外退化。

这支持D3的“域外报警/退回简单模型”研究逻辑；由于域外文件只有一次往返，尚不能估计失效概率或置信区间。

## 8. D3进入正式研究的门

1. 每个核心工况至少3个独立文件，而不是只在一个文件内拆段；
2. 每文件至少3个完整对称往返，并保存完整前后静止段；
3. 预注册候选和窗口，禁止看结果后无限增阶；
4. 一步、free-run、同工况留出、跨工况域外四类结果必须同时报告；
5. 参数符号、极点稳定性和残差相关必须作为拒绝门；
6. 不把最优预测模型解释成内部机械或控制器组件。
