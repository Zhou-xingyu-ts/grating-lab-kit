## 1. 4.1 运动台性能测试（PDF 70–74）

### 1.1 4.1.1 误差校正与可重复性（PDF 71–73）

- **测试平台**（图4.1/4.2，PDF70–71）：光谱共焦传感器（STIL，量程 400 µm）+ 三轴运动台；**激光干涉仪**为长度基准，标靶装在运动台上。
- **被测轴反馈**：z 轴光栅尺 **HEIDENHAIN RCLC A-9404-2030，栅距 20 µm**；"200 倍电子细分 → 0.1 µm 分辨率"（细分电路型号未注明）。
- **实验方案**：−10 mm ~ +10 mm 全行程，**0.5 mm 步进**，双向定位，**重复两次**，得位移-误差映射（图4.3，4 子图：全行程定位精度/误差 × 2 次）。
- **误差特征识别**：误差随位移单调递减 → **余弦误差特征**（光栅尺安装夹角）。
- **补偿方程（最小二乘，单位 µm）**：
  - 式(4.1a) Δcos1 = −1.774×10⁻³·x² − 0.5639（**x² 疑为印刷错误，待核验**）
  - 式(4.1b) Δcos2 = −1.830×10⁻³·x³ − 0.3859（**x³ 疑为印刷错误，待核验**）
  - 结论：斜率一致（相对偏差 3.2%，正文称 <1% —— 数值不符，待核验），截距差异=光栅尺与干涉仪零点未对齐。
  - 式(4.2) 最终统一补偿 **Δcos = −1.8×10⁻³·x**（x 单位 µm 时系数无量纲；在 x=±10 mm 处补偿量约 ∓18 µm，与图4.3 误差幅值 ±20 µm 自洽——进一步佐证式4.1 的 x²/x³ 为误印，应为 x 一次项）
- **第一级补偿结果**：残余误差 −5 µm ~ +7.5 µm（图4.4）。
- **第二级误差——2 mm 周期波动**（图4.4，PDF71）：残余误差仍呈现与丝杠导程（2 mm）同周期的波动。成因推断：丝杠径向跳动复合机制——①螺母副倾角变化→阿贝误差；②丝杠偏心→附加余弦分量。强非线性+多参数耦合 → **不做机理建模**。
- **可重复性量化**：式(4.3) 皮尔逊相关系数 r = Σ(y₁⁽ⁱ⁾−ȳ₁)(y₂⁽ⁱ⁾−ȳ₂) / √(Σ(y₁⁽ⁱ⁾−ȳ₁)²·Σ(y₂⁽ⁱ⁾−ȳ₂)²)；**r = 0.999999（p<0.001）**。
- **第三级：数据驱动补偿**：构建**位置-误差查找表 + 实时线性插值补偿** → 定位精度提升至 **±1 µm**（图4.5）。原文要点："该方法通过数据驱动方式规避复杂机理建模，实现了更高的定位精度。" —— 与用户 D1 主线"低频等效模型"方法论同构。

### 1.2 4.1.2 分辨率与重复定位精度（PDF 73–74）

- **重复定位精度测量**：**13 次重复定位实验** → 位置重复性标准差 **0.09 µm**（置信度 99.7%）→ 按 **3σ 准则**：**重复定位精度 = ±0.27 µm**（图4.6：横轴 1–13 实验次数）。
- **滤波与最小步进**：为抑制光栅尺信号噪声，控制算法设数字滤波器，**最小步进量 5 个脉冲当量 = 0.5 µm**（脉冲当量 0.1 µm）。
- **分辨率实验**：**5 组单向步进**（图4.7：总行程 0–5 步，单次步进 0.50–0.56 µm 量级）→ 实际位移相对指令**平均偏差 0.06 µm，最大 <0.1 µm**，与光栅尺理论分辨率 0.1 µm 相符 → 滤波未引入显著迟滞。
- **性能总结**：分辨率 0.5 µm（最小步进口径）、定位精度 ±1 µm、重复定位精度 ±0.27 µm（第5章/4.4 小结一致）。

## 2. 4.2 基线漂移校正算法验证（PDF 74–76）

- **测试集三类干扰**：缓变型（温漂/铜箔形变/余弦误差）、阶跃型（阶梯/盲孔缺陷）、非线性（传感器热迟滞指数衰减）。
- **结果**：BEADS 对三类基线均良好拟合（图4.8 a–d）。
- **对比实验**（图4.8d 数据 vs 图4.9 a–d）：
  - 中值滤波：窗口必须 ≥2× 特征宽度，宽特征窗口过大淹没特征/过小误判基线；
  - 形态学闭运算：先膨胀后腐蚀，引入**阶梯效应**；
  - 小波分解 / EMD：需高分解层数，效率低，去基线后仍有波动。
- **结论**：BEADS 综合最优（鲁棒+自适应）。

## 3. 4.3 铜箔盲孔阵列扫描与重建（PDF 76–80）

- **样件**：激光加工铜箔微盲孔阵列（图4.10），单孔直径 ~100 µm、深 ~40 µm；扫描参数：x 向 10 mm、y 步进 **0.02 mm**。
- **三级联预处理**：双向窗口剔除离群点 → AKF 抑制高频振动噪声 → BEADS 消除基线漂移。
- **分区域配准**：全局点云按盲孔阵列分布分割为子区域（**间距容差 ±0.2 mm**），各子点云做运动约束配准（图4.11：配准前边缘锯齿化 → 配准后连续平滑）。
- **RANSAC 多次平均抗随机性**（PDF78）：RANSAC 随机采样导致模型参数波动 → 重复 N 次：
  - 式(4.4) N 组平面方程 A_i x + B_i y + C_i z + D_i = 0
  - 式(4.5) 平均法向量 n̄ = Σ n̂_i / n（n̂_i 归一化）
  - 式(4.6) 平均 D̄ = Σ D_i / n
  - 式(4.7) **5 次拟合平均平面：z = 0.0x − 1.27×10⁻³·y + 5.10×10⁻³**
- **盲孔分割**：DBSCAN（**ε=0.1 mm，min_samples=20**）→ 7 个盲孔（图4.13 二维投影）。

## 4. 实验方法对用户课题的迁移价值

1. **±0.27 µm 的测量口径（可整体复制）**：激光干涉仪基准 → 全行程 0.5 mm 步进双向两次 → 余弦误差拟合补偿（式4.1/4.2）→ 残余 2 mm 周期波动识别 → 皮尔逊 r 检验可重复性 → 查找表+线性插值 → ±1 µm → 13 次重复定位 → 3σ → ±0.27 µm。当前台架 counts 域做重复定位实验时可套用"13 次/3σ/99.7%"统计口径，仅缺外部长度基准（`1 count≈0.5 µm` 未标定）。
2. **误差分层补偿思想**：确定性（余弦，可建模）→ 半确定性（丝杠周期，机理难建模但可查表）→ 随机（阿贝/高斯，只减小 L）——三层分类可直接用作当前台架误差实验的分层假设。
3. **数据驱动补偿替代机理建模（式4.3 + 查找表）**：r=0.999999 的可重复性论证方法是"低频等效模型可辨识性"论述的现成模板。
4. **盲孔实验的三级联处理流水线**（双向窗口+AKF+BEADS+分区域配准+DBSCAN+最小外接圆）是完整的数据分析样板；其"深度负偏→补偿"揭示算法-测量耦合误差的处理流程（识别→归因→统计补偿→复测）。
