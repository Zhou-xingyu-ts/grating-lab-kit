# 02 第3章 线扫描表面轮廓重建算法（PDF 51–69，正文页 33–51）

> 本章回答：线扫描数据怎么预处理（异常值→卡尔曼→基线校正）、多帧怎么配准、几何特征怎么重建。
> 页码均为 **PDF 页号**。

## 1. 3.1 线扫描数据预处理（PDF 51–60）

### 1.1 噪声三分法（PDF 51）

| 噪声源 | 成因 | 特征 |
|---|---|---|
| 传感器固有噪声 | 光电热噪声、量化误差 | 高斯白噪声，统计时不变 |
| 运动台位移噪声 | 机械振动、导轨非线性 | 周期性，功率谱集中在特定频段 |
| 铜箔形变噪声 | 刚性不足+夹持弹性形变 | 低频缓变基线漂移 |

对策：卡尔曼滤波（前两类）+ 基线校正（第三类）。

### 1.2 3.1.1 异常值预处理（PDF 52–53）

- **成因**：光斑直径随离焦扩散（d(z)=d₀√(1+(z/z_R)²)，z_R 瑞利长度）；光斑同时覆盖突变特征（盲孔边缘）→ 多深度光谱叠加 → 单峰查表解算错误 → 零值/跳变离群点（图3.1/3.2）。
- **处理**：零值→相邻点均值；跳变→**双向窗口检测**：
  - 式(3.1a) Δ_forward = |z_i − μ_forward|，μ_forward = (1/N)Σ_{k=i−N}^{i−1} z_k
  - 式(3.1b) Δ_backward = |z_i − μ_backward|，μ_backward = (1/N)Σ_{k=i+1}^{i+N} z_k
  - 阈值条件 th1 < Δ < th2 时用窗口均值替换（th1/th2 论文未给具体值，N 未给）。

### 1.3 3.1.2 线性卡尔曼滤波 LKF（PDF 53–56）

- **静止噪声实测**（图3.4）：标准差 **0.042 µm**、峰峰值 0.256 µm；分布近似高斯（图3.4b 直方图）。
- **一般模型**：
  - 式(3.2) x[k] = A·x[k−1] + B·u[k−1] + w[k−1]，w ~ N(0, Q)
  - 式(3.3) z[k] = H[m]·x[k] + v[k]，v ~ N(0, R)
- **递推五式**（图3.5 流程图，交叉验证：英文会议论文式(3)–(9) 完全对应）：
  1. x̂⁻[k] = A·x̂[k−1] + B·u[k−1]（先验状态）
  2. P⁻[k] = A·P[k−1]·Aᵀ + Q（先验协方差）
  3. K[k] = P⁻[k]·H[m]ᵀ·(H[m]·P⁻[k]·H[m]ᵀ + R)⁻¹（卡尔曼增益）
  4. x̂[k] = x̂⁻[k] + K[k]·(z[k] − H[m]·x̂⁻[k])（后验状态）
  5. P[k] = (I − K[k]·H[m])·P⁻[k]（后验协方差）
- **增益机制定性**：R 大 → K→0 → 信预测；P⁻ 大 → K→H[m]⁻¹ → 信观测。
- **静止场景简化模型**（式3.4/3.5，PDF55）：x[k]=x[k−1]+w[k]；z[k]=x[k]+v[k]。即 A=H=I、B=0；**Q=1×10⁻⁵**；**R=[σ²]，σ=0.042 µm**。
- **效果**：滤波后标准差 0.042→**0.011 µm（−73.8%）**；K 与 P 随时间收敛至稳态（图3.7）。
- **资源复杂度**：内存 O(n²)、计算 O(n³)，马尔可夫性只需存上一时刻（利于嵌入式）。
- 交叉验证：英文会议论文 §2.2 同式（F、B、H、Q、R 记号）；会议论文中静止噪声采集 1 s、直方图近似高斯、图5/6 与论文图3.4/3.6 同数据。

### 1.4 3.1.3 自适应卡尔曼滤波 AKF（PDF 56–58）

- **动机**：Q/R 时变——变速时导轨摩擦随机波动→Q 变；表面反射率差异→R 变；铜箔形变破坏式(3.4) 稳态假设。图3.8：vmax=500/1000/1500/2000 r/min 下噪声幅值随速度增大（铝块扫描、已最小二乘去除余弦误差）。
- **自适应律（残差法）**：式(3.6)
  - **R̂[k] = α·R[k−1] + (1−α)·(ε[k]·εᵀ[k] − H[m]·P⁻[k]·H[m]ᵀ)**
  - ε[k] = z[k] − H[k]·x̂⁻[k] 为观测残差，α 为遗忘因子（α 值论文未给）。
- **表3.1 抑制效果（PDF58）**：速度 100–2000 RPM，20 档。原数据标准差 0.60–0.44 µm，AKF 后 0.47–0.32 µm，**降噪 16.2%–30.3%**（低速差、高速好；速度 >1000 RPM 后约 20–30%）。
- **结论**：固定参数 LKF 在动态工况下信噪比反而低于原始数据（模型失配误差放大）；AKF 稳态性能略差于理想参数 LKF，但鲁棒。
- ⚠️ 会议论文用的是 **MAE 最小化选 Q/R**（offline 调参），论文正文用的是**残差在线递推**（式3.6）——两种策略，写综述时不要混淆。

### 1.5 3.1.4 基线漂移校正：改进 BEADS（PDF 58–61）

- **问题**：低频基线（铜箔形变/温漂/余弦误差）与表面微形貌频率混叠；高通滤波会丢粗糙度信息（图3.10）。
- **加性分解模型**：式(3.7) **y(t) = x(t) + b(t) + n(t)**（信号+基线+噪声）
- **三个先验**：①基线二阶差分稀疏（平滑性）；②噪声在变换域（小波域）稀疏；③边界周期性 y(0)=y(T)。
- **优化目标**：式(3.8) **λ₀‖y−(x+b)‖²₂ + λ₁‖∇²b‖₁ + λ₂Φ(x)**（数据保真+基线稀疏+可选信号稀疏；λ₂=0 或 Φ=0 可关闭）。
- **抛物线预校正**（Navarro-Huerta 等[47]）：
  - 式(3.9) p(t) = A·t² + B·t + C
  - 式(3.10a) C = min_{0≤t≤T} y(t)
  - 式(3.10b) A = ½(y(0) + y(T) − 2C)
  - 式(3.10c) B = A − y(0)
  - 预处理 y′(t) = y(t) − p(t) 使端点归零，满足周期性假设。
- **三类基线敏感性实验**（图3.11/3.12）：①两端为 0 的二次基线——预处理无必要无副作用；②仅一端为 0 的指数基线——不预处理则右半区基线错误追踪信号（伪峰抑制）；③两端非 0 复杂基线——稀疏先验过度导致高频特征平滑畸变。
- **λ 调参难点**：λ 过大→特征被抹掉；过小→噪声干扰基线。论文自认这是普适性/自动化瓶颈。

## 2. 3.2 线扫描数据配准（PDF 61–65）

- **问题**：x 轴坐标隐性缺失（半闭环+非匀速扫描 → 由理论速度积分推算有累积偏差）；运动-信号在时域混叠。
- **多级配准框架**（图3.13）：局部位移估计（互相关+亚像素插值）→ 全局优化配准（平滑约束+TRF 求解）。
- **离散互相关**：式(3.11) r[k] = Σ_{n=1}^N (z₁[n]−z̄₁)·(z₂[(n+k) mod N]−z̄₂)，k∈[−K,K]；r 最大处 k_peak 为位移估计（**循环互相关**）。
- **三点二次插值（亚像素）**：式(3.12) δ = ½·(r[k−1]−r[k+1])/(r[k−1]−2r[k]+r[k+1])，δ∈(−0.5, 0.5)。
- 式(3.13) Δx = k_peak；式(3.14) x_comp[k] = κ_{y→x}·Σ_{i=1}^k Δx[i]（全局累积）；x_opt = x_init + x_comp。
- **像素偏移换算**：式(3.15) n_shift = round(dx[i]/y_step)（假设 x/y 正交，d_y = d_x）。
- **相邻线相似性误差**：式(3.16) e_align⁽ⁱ⁾ = ‖z_i[n_shift:N] − z_{i+1}[1:N−n_shift+1]‖²₂
- **平滑约束（二阶差分/加速度）**：式(3.17) Δ²x[i] = x[i−1] − 2x[i] + x[i+1]；式(3.18) e_smooth = λ(ΣΔ²x[i])²
- **总体目标**：式(3.19) **argmin E = Σ e_align⁽ⁱ⁾ + λ·e_smooth**，用信赖域反射（TRF）+ Huber 损失求解（**算法3.1 伪代码**，PDF64）。
- **效果**（图3.14 槽点云）：配准前边缘锯齿/曲率突变（破坏最小二乘假设：非高斯残差、特征模糊、拓扑歧义），配准后满足局部线性/噪声一致/拓扑明晰。

## 3. 3.3 表面重建算法设计（PDF 65–69）

- **体素化分层重建框架**三原则：特征尺度解耦（只重建 5–200 µm 目标特征）、结构导向简化（加工工艺先验）、抗差拓扑优化。
- **3.3.1 RANSAC 面基元提取**：
  - 式(3.20) v₁ = P₂−P₁，v₂ = P₃−P₁
  - 式(3.21) n = v₁×v₂ = (a,b,c)，平面方程 a(x−x₁)+b(y−y₁)+c(z−z₁) = 0
  - 式(3.22) 点面距 d_point = |ax+by+cz+d|/√(a²+b²+c²)，阈值 δ 定内点
  - 式(3.23) 迭代次数 N = log(1−p)/log(1−(1−η)³)（s=3）
- **3.3.2 Hough 直线检测**（三维点云投影到 xy 平面后）：
  - 式(3.24) ρ = x·cosθ + y·sinθ（ρ∈ℝ⁺，θ∈[0,π)）
  - 式(3.25) Δρ = √(M²+N²)/K（K 为距离分级数；Δθ = π/180）
  - 式(3.26) 投票 H(ρ_j,θ_k) ← H(ρ_j,θ_k)+1；超阈值 γ 的局部极大值定直线。
- **最小外接圆拟合（盲孔）**：
  - 式(3.27) r² = max_i[(x_i−a)²+(y_i−b)²]
  - 式(3.28) f(a,b) = max_i[...]；L-BFGS-B 求解 min f
  - 式(3.29) 初值取质心 a₀=Σx_i/M，b₀=Σy_i/M
  - 聚类前置（K-means/DBSCAN）按盲孔数 N 分块。

## 4. 3.4 本章小结（PDF 69）

贡献三件套：①双向窗口异常点剔除 + AKF + 改进 BEADS；②运动学约束多级配准（针对半闭环位置缺失）；③RANSAC 面基元 + 聚类 + 优化最小外接圆。

## 5. 对用户课题的直接可用点

1. **静止噪声测量口径可复制**（PDF53–55）：静止 1 s 采集 → σ/峰峰值 → 高斯性检验 → LKF 简化模型（Q=1e-5、R=σ²）→ 滤波后 σ 对比。当前台架 counts 域同样可做"静止噪声基线"，作为传感器+驱动器噪声本底参考。
2. **AKF 残差自适应律（式3.6）**是标准方法，可迁移到 counts 域数据处理；表3.1 给出"降噪率 vs 速度"的实验设计模板（当前已有 50/100/200 Hz 多口径数据，可仿此做速度扫描）。
3. **BEADS+抛物线预校正**：论文对三类基线的敏感性分析（图3.11/3.12）是很好的基准测试设计；当前台架数据若有基线漂移（温漂），可直接套用式(3.7)–(3.10)。
4. **互相关+运动学约束配准（式3.11–3.19）**与用户 x 轴坐标不确定问题同构，且论文给出完整伪代码（算法3.1）和求解器选择（TRF+Huber）——这是可迁移性最高的算法章内容。
5. 注意：论文 3.1 与 3.2 是为"光谱共焦+半闭环三轴"设计的；当前台架是"光栅尺闭环单轴"——配准需求弱（有真实位置），滤波需求强（counts 噪声、SDO 轮询抖动）。
