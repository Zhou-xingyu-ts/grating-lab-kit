## 1. 2.1 系统总体框架与设计目标（PDF 31–32）

- **动机**：商用 CLM（共聚焦激光显微镜，如蔡司 LSM 900）三大局限——轴向扫描效率瓶颈、PZT 扫描范围受限、运动控制与数据采集协同不足。
- **架构**：四模块 = 上位机（数据采集与运动控制集成软件）+ 运动控制器 + 光谱共焦数据采集系统 + 三自由度运动台（图2.2，PDF31）。
- **三大创新主张**：
  1. 光谱共焦色散物镜直接解析轴向位置，省去机械轴向扫描；
  2. 旋转电机+滚珠丝杠替代 PZT，量程到毫米级、速度提升（微米级定位）；
  3. 开放式软硬件接口与总线，兼容多厂商硬件。
- **表2.1 关键指标对比（PDF32）**：

| 指标 | 商用激光共聚焦显微镜 | 本课题光谱共焦系统 |
|---|---|---|
| 扫描范围 | 依物镜最大 6.35×6.35 mm | 受运动台限制最大 20×20 mm |
| 扫描时间 | 18 s/幅（最高分辨率），多幅叠加 | <60 s（10×10 mm） |
| 横向分辨率 | 6144×6144 px | 由传感器采样率+线扫描参数决定 |
| 重建精度 | 最高纳米级 | 亚微米级 |
| 价格 | >100 万元 | <10 万元 |

## 2. 2.2 三轴运动台设计（PDF 32–38）

### 2.1 传动部件选型（PDF 32–35）

- **线扫描指标推导**：y 向步进 10 µm；10×10 mm 区域 <120 s；x 向单次扫描 0.1 s。梯形速度曲线（加/匀速/减各 1/3）：
  - 式(2.1) vmax = L/t_eff = 10 mm / (0.1 s × 2/3) = **150 mm/s**
  - 式(2.2) a = vmax/t_acc = 150 / 0.1 = **1500 mm/s²**
- **丝杠导程选择逻辑**：导程 P=1 mm → 需 9000 r/min（>8000 r/min 常规微型电机极限）→ 改 **P=2 mm → 4500 r/min**。
- **电机选型：鼎智智能 30ZWWC60 空心杯伺服电机**，表2.2（PDF33）：

| 参数 | 值 |
|---|---|
| 极对数 | 2 |
| 反馈方式 | **霍尔元件**（半闭环） |
| 额定功率 | 65 W |
| 额定转矩 | 90 mN·m |
| 额定速度 | 6900 r·min⁻¹ |
| 转矩常数 | 23.38 mN·m·A⁻¹ |
| 转动惯量 | 28 g·cm² |

- 选型理由两条：①无铁芯转子低惯量→机电时间常数短→动态跟踪好；②正弦换向+无齿槽→力矩波动小。
- **反馈策略分工（关键）**：z 轴 = 直线光栅尺**全闭环**（量程 400 µm，动态调节范围 ±200 µm，用于补偿丝杠导程误差/反向间隙/热变形）；x/y 轴 = 霍尔编码器**半闭环**（位移靠导程×转角换算）。→ 这正是第3章配准问题（x 轴坐标缺失）的根源。
- **丝杠选型：米思米 E-KBS0602-70**，表2.3（PDF34）：导程 2 mm、长度 70 mm、**C5 级**（JIS B 1192，40 mm 内综合误差 ≤7 µm）、动载 0.75 kN、静载 1.2 kN、轴向间隙 ≤0.005 mm。约束：y 步进分辨率 20 µm；x/y 行程 40 mm；成本优先。
- **导轨：交叉滚子导轨**（每轴一对，图2.5）：预压装配提刚性；滚动摩擦系数 0.001–0.003；可同时承受径向+轴向载荷。

### 2.2 结构设计与误差分析（PDF 35–38）

- **导轨 5 个误差运动**（图2.6）：角度 α（绕x）、β（绕y）、γ（绕z）+ 直线度 Δx、Δz。
  - 式(2.3) δgeo = Δz·sinα + Δx·sinγ ≈ Δz·α + Δx·γ（时变随机 → 影响重复定位精度）
- **光栅尺误差二分法**：确定性系统误差（光路/电路，可算法校准）vs 非确定性（安装误差）：
  - 式(2.4) δ_installation = δ_abbe + δ_cos
  - 式(2.5) **阿贝误差** δabbe = Lx·tanγ + Lz·tanα ≈ Lx·γ + Lz·α（与轴间距 L 正相关；α/γ 随机 → 高斯分布随机误差，**无法算法补偿**，只能靠减小 L 抑制；文献[39][40]）
  - 式(2.6a/b) 安装夹角 φ1 = arcsin(Δh1/Lscale)，φ2 = arcsin(Δh2/Lscale)
  - 式(2.7) **余弦误差** δcos = l(1/cosφ1 + 1/cosφ2 − 2)（确定性、完全可预测 → 可补偿；第4章实验据此做补偿）
- **结构创新：对称复用式堆叠**（图2.9，xy堆叠设计图/实物图/z轴设计图）：中间层双向复用拓扑 → xy 轴间距 33 mm→24.5 mm（**−25.76%**，减小阿贝误差）；双轴对称布局消除惯性耦合附加力矩偶。
- **限位方案**（图2.10）：夏普 GP1S092HCPIF 光电传感器（4.5×2.6×2.9 mm，响应 <50 µs）+ LM393 比较器（VSSOP-8，开漏驱动）+ 定制 PCB（32×8×1 mm，0603 元件，10 mil 线宽）。

## 3. 2.3 运动控制器设计（PDF 38–48）

### 3.1 分层架构与总线选型（PDF 38–41）

- **分层控制架构**（图2.11）：上位机可视化软件规划路径 → 运动控制器读编码器、算控制律 → 驱动器 FOC 执行。
- **表2.4 总线对比（PDF39）**：

| 总线 | 最大速率 | 实时性 | 成本 | 易实现性 |
|---|---|---|---|---|
| CANopen | 1 Mbps | 微秒级 | 低 | 高 |
| EtherCAT | 100 Mbps | 纳秒级 | 高 | 中（Windows 同步 >50 ms，授权贵） |
| PROFIBUS | 12 Mbps | 微秒级 | 高 | 中 |
| Modbus | 500 kbps | 毫秒级 | 低 | 高 |
| DeviceNet | 500 kbps | 毫秒级 | 中 | 中 |

- **PDO 时序开销（1 Mbps）**：PDO 传输 47 µs（协议处理）+ 64 µs（8 字节数据）= **111 µs**；SYNC 47 µs。PLC 方案三轴总耗时 (111+111)×3+47 = **713 µs**；MCU 定时器方案 111×3 = **333 µs**，效率提升 **53.3%**（图2.12）。
- **主控：STM32H7**（表2.5，PDF41）：Cortex-M7 480 MHz + 双精度 FPU（比 M4 计算时间 −50%）、双 CAN-FD（最高 5 MHz）、CANopenNode 协议栈、STM32Cube 生态（开发周期 −30%、成本为 FPGA 的 20–30%、静态功耗 <200 mW）。
- **协议栈三线程**（图2.13，PDF41）：
  1. 最高优先级：PDO 通信，1 ms 固定周期直连硬件 CAN；
  2. 中等：SDO 配置 / NMT / 心跳，事件触发，最大延迟 5 ms；
  3. 低：错误日志、诊断。

### 3.2 机电系统建模（PDF 41–44，核心公式 2.8–2.11）

- **建模路线**：有限元（精确但高自由度）→ 弃；集总参数 → 高阶（多质量-弹簧-阻尼）→ 弃；**低阶集总参数**（保留一阶扭转+轴向主导模态）。
- **双质量模型**（图2.15，PDF43）：m1（旋转侧等效质量）/m2（工作台侧）、x1/x2、b1/b2、k（轴向等效刚度）、c、d1/d2（扰动）、τ（输入），经导程 P 折算为直线-直线模型。
- **FOC 解耦**（PDF43）：Clark+Park 变换，d 轴控磁链、q 轴控转矩，故只写 q 轴方程：
  - 式(2.8a) **F_e = K_f·I_q**（电枢推力系数）
  - 式(2.8b) **u_q = L_q·dI_q/dt + C_e·v + R_s·I_q**（反向电势系数 C_e，v 为换算线速度）
- **摩擦模型**：式(2.9) **F_f = F_c·sgn(v) + F_v·v**（库仑+黏性）
- **机械子系统**：式(2.10) **M·d²y/dt² + B·dy/dt + K·y = F_e − F_f**（质量-弹簧-阻尼，图2.16）
- **电流环抽象**（图2.17，PDF44）：电流环比例系数 K_c 存在于驱动器内部，动态特性已硬件级优化 → **系统级建模视作系数为 1 的比例环节**。简化后模型 = 期望力矩 → [1/(M s²+Bs+K)] → 位移 y，摩擦力模型外挂。
- 式(2.11) 传递函数 G(s)（PDF45）：**首项印刷为 K s²，疑为 M s²（待核验）**，详见 05 文件。语义上 G(s) = 1/(M s²+(B+F_v)s+K)。
- **表2.6 仿真参数（PDF46）**：M=0.5 kg、B=0.5 N·(m·s⁻¹)⁻¹、K=5、F_v=1×10⁻³ N·s·m⁻¹、Ki=0.2897、Kd=0.6471、N=376.1（**Kp 未给出**）。⚠️ 与 Matlab 源码 m=7.7 冲突（待核验）。

### 3.3 PID 控制器设计（PDF 44–46）

- **三环结构**（图2.18a）：位置环（P 调节器 Kpp，输入=目标位置−光栅尺反馈）→ 速度环（PI：Kvp/Kvi，输入=速度误差）→ 电流环（驱动器内部）。
- **PID 局限性论证**：开环阶跃响应稳态值收敛至 0.2、约 15 s 稳定、稳态误差约 80%（图2.19 绿线）；增大 Kp → 响应变快但超调指数增长+控制量饱和；根本原因：U(s) 只是误差 E(s) 的函数，未利用全部状态信息。
- 图2.19 图例：阶跃信号 / 原始响应 / P=20 / P=44 / P=100（对应 `raw/运动控制仿真/Matlab/250304/response_P=*.mat`，另存 P=30/70/200）。

### 3.4 前馈控制器设计（PDF 46–48，核心公式 2.12–2.17）

- **状态变量**：式(2.12) z1=y，z2=dy/dt；控制输入 u = F_e/M。
- **状态空间**：式(2.13)–(2.14)：
  - A = [[0, 1], [−K/M, −(F_v+B)/M]]，B = [0, 1]ᵀ，C = [1, 0]ᵀ，D = [0]
  - （Matlab `ref/sys.m` 逐项对应：`A=[0 1; -k/m, -(F_v+b)/m]; B=[0;1]; C=[1,0]; D=0` ✓）
- **带前馈的线性状态反馈**（图2.20）：u(t) = **F·z_d + K_e·e(t)**，F·z_d 前馈项把平衡点迁到目标（消稳态误差），K_e·e 反馈项配置闭环极点。
  - 式(2.15) 印刷 F = [−K/M, −(F_v+B)/M]：**符号疑误（待核验）**——Matlab 用正号 `F=[k/m,(F_v+b)/m]`，且式(2.16) 推导要求 A·z_d + B·F·z_d = 0 即 F 为正。
  - 式(2.16) 误差动力学：de/dt = (A − B·K_e)·e，平衡点唯一 [0,0]ᵀ。
- **LQR**：式(2.17) **K_e = argmin J = ∫₀^∞ (zᵀQz + uᵀRu) dt**；Q 量化位移/速度误差代价，R 约束控制能量；增大 Q11 强化位移跟踪，增大 R11 抑制控制幅值防饱和。
- **仿真对比结论（图2.21，PDF48）**：PID 超调 6.6%、5 s 仍未达稳态（≤2%）；LQR 超调 4.5%、1.88 s 达稳态。（Matlab `ref/LQR.m`：Q=diag(100,1)、R=1、m=7.7；`ref/sys.m` 中 Ke=[9.3717, 4.3788]；⚠️ m=7.7 与表2.6 M=0.5 冲突，待核验。）
- 作者自陈局限：LQR 依赖精确动力学参数（M/B/K），强非线性（Stribeck 摩擦、柔性变形）需自适应控制或观测器——**与第5章展望(2)呼应**。

## 4. 2.4 上位机软件设计（PDF 49–50）

- Qt 跨平台；多线程异步：光谱共焦传感器 **RS232 串口 460 800 bps**（匹配 **2 kHz** 采样率）独立线程 + CANopen 状态反馈线程（位置刷新 >10 Hz）；Qt-OpenGL 实时渲染点云高度伪彩+剖面。
- 运动控制模块：扫描速度/加速度/区域（xy 行程、线扫描步进）图形化配置；路径一键生成，CSV 保存/加载；在线调试显示各轴位置误差、电流环输出、温度；急停、软限位、手动微调（步进 1 µm）。

## 5. 2.5 本章小结（PDF 50）

- 三轴运动台选型参数匹配（电机/导轨/丝杠）；
- 定时器触发 PDO 减少总线通信延迟约 53%；
- 全状态反馈（LQR）优于"最优"PID（稳态速度/超调）；
- 模块化上位机完成运动指令/采集/监控集成。

## 6. 对用户课题的直接可用点

1. **选型计算模板**（PDF32）：线扫描速度/加速度推导（式2.1/2.2）→ 导程与电机转速匹配 → 可作为任何丝杠进给系统选型复用的计算框架。
2. **误差分类学**（PDF35–36）：光栅尺误差=确定性（可补偿：余弦）+非确定性（阿贝/高斯随机，不可补偿只可减小 L）——这是当前台架 Ri0040 误差补偿实验设计的直接理论依据（当前 1 count≈0.5 µm 未标定，正缺这类标定口径）。
3. **电流环抽象逻辑**（PDF44）：论文把驱动器内部电流环当比例 1——当前 DS-BVM 整体是黑箱，这一抽象仅作概念参考，不能当实测事实。
4. **三环 PID 结构**（PDF45）：位置 P→速度 PI→电流——DS-BVM 手册同样声称位置/速度/电流三环（见既有审计 phase_B1），论文给出的是"设计者"视角参数，当前台架不可观测内部参数。
5. **LQR+前馈的状态空间建模方法**（PDF46–48）可迁移为当前等效闭环模型的建模框架（输入=Servo Studio 目标，输出=Ri0040 实际位置），但增益、Q/R、状态含义必须重新定义（见 07 台架对照表）。
