## 2. Profile Position Mode（PPM）

| 项目 | 内容 |
|---|---|
| 模式事实 ID | MODE-B1-PPM |
| 外部输入对象 | `0x607A Target Position`；轨迹参数 `0x6081/0x6083/0x6084/0x6086`；状态控制 `0x6040`，并受 `0x607D/0x607F/0x6080/0x6085/0x60C5/0x60C6` 等限制 |
| 驱动器内部轨迹生成 | 有。Target Position 进入内部 profile generator，生成 `0x6062 Position Demand`，以及速度/加速度需求用于前馈 |
| 驱动器保留的控制环 | 位置环、速度环、电流/转矩环 |
| 反馈对象 | `0x6062` 为内部生成的 position demand；`0x6064` 为传感器位置实际值；`0x6041` 表示状态。手册 PPM 输出表明确列 `0x6041/0x6062` |
| 推荐通信方式 | 手册没有把周期 PDO 设为 PPM 的必要条件；对象可经允许的 SDO/PDO 路径配置。点到点动作由 Controlword 触发 |
| 是否要求周期更新 | 否。外部给目标和 profile 参数，轨迹由驱动器内部生成 |
| 是否要求 SYNC/PDO | 手册未要求 |
| 手册是否给出周期保证 | 未给出 PPM 命令最小间隔、闭环周期或 1 kHz 保证 |
| 当前台架是否验证 | 未验证 |
| 对外位置环研究的意义 | 适合作为驱动器内部位置闭环/轨迹能力基线；不适合把外部控制器作为逐周期位置环主体 |
| 标签与官方证据 | E3-REF：`D:\清华\清华-科研横向\光栅尺运动控制调研\90_原始资料\官方手册\DINGS_DS-BVS-BVM_Series_Reference_Manual.pdf`，VER 1.0，PDF pp.29–34，§5.3–5.3.2；PDF pp.154、163，§6.2.96、§6.2.114 |
| 证明了什么 | PPM 的轨迹生成和级联控制主要留在驱动器内部 |
| 没有证明什么 | 不证明当前参数整定、光栅反馈来源、点到点精度或任何实时外环性能 |

## 3. Profile Velocity Mode（PVM）

| 项目 | 内容 |
|---|---|
| 模式事实 ID | MODE-B1-PVM |
| 外部输入对象 | `0x60FF Target Velocity`；`0x6083 Profile Acceleration`、`0x6084 Profile Deceleration`、`0x6086 Motion Profile Type`；状态控制 `0x6040` |
| 驱动器内部轨迹生成 | 有。驱动器内部生成到目标速度的速度 profile |
| 驱动器保留的控制环 | 速度环、电流/转矩环；无外部逐周期位置环语义 |
| 反馈对象 | 速度需求 `0x606B`、速度实际值 `0x606C`、状态 `0x6041`；位置实际值仍是通用对象，但不是 PVM 的控制目标 |
| 推荐通信方式 | 手册未要求周期 PDO；它特意与“每个 PDO 更新周期续写目标”的 CSV 相区别 |
| 是否要求周期更新 | 否。Target Velocity 给定后由内部加减速轨迹发生器处理 |
| 是否要求 SYNC/PDO | 手册未要求 |
| 手册是否给出周期保证 | 未给出 PVM 命令周期、速度环周期或 1 kHz 保证 |
| 当前台架是否验证 | 未验证 |
| 对外位置环研究的意义 | 可用于较低速率的外部位置调节器输出速度命令，但手册没有把 PVM 定义为周期同步外环接口；若研究实时外位置环，CSV 的语义更直接 |
| 标签与官方证据 | E3-REF：`D:\清华\清华-科研横向\光栅尺运动控制调研\90_原始资料\官方手册\DINGS_DS-BVS-BVM_Series_Reference_Manual.pdf`，VER 1.0，PDF pp.35–39，§5.4–5.4.2 |
| 证明了什么 | PVM 保留内部速度轨迹和速度控制 |
| 没有证明什么 | 不证明用 SDO 高频改 `0x60FF` 能获得确定周期，不证明适合 1 kHz 外环 |

## 4. Cyclic Synchronous Position Mode（CSP）

| 项目 | 内容 |
|---|---|
| 模式事实 ID | MODE-B1-CSP |
| 外部输入对象 | `0x607A Target Position`；可选 `0x60B0 Position Offset`、`0x60B2 Torque Offset`；`0x6040/0x6060` 管状态和模式 |
| 驱动器内部轨迹生成 | 无。轨迹发生器位于外部控制设备；驱动器只对相邻位置值做基于插补周期的线性插补，且手册称该插补只在 PDO 通信有效 |
| 驱动器保留的控制环 | 位置环、速度环、电流/转矩环 |
| 反馈对象 | `0x6064 Position Actual`、`0x606C Velocity Actual`、`0x6077 Torque Actual`、`0x6041 Statusword` |
| 推荐通信方式 | PDO；若采用 CANopen 的同步 PDO，则由 SYNC 触发。EtherCAT 可采用 ESI 所列 DC-Synchron，但必须核对实际设备/固件 |
| 是否要求周期更新 | 是。手册称 `0x607A` 在每个 PDO 更新周期更新 |
| 是否要求 SYNC/PDO | PDO 是模式描述中的周期入口；“同步”在 CANopen 上还需把 PDO transmission type 配成 synchronous 并发送 SYNC。手册未说只要选择 CSP 就会自动完成这些配置 |
| 手册是否给出周期保证 | 未给出最小/最大 PDO 周期、同步误差或 1 kHz 稳定运行保证 |
| 当前台架是否验证 | 未验证 |
| 对外位置环研究的意义 | 外部负责轨迹规划，DS-BVM 仍闭合位置环；若光栅尺是 DS-BVM 的位置反馈，可研究外部轨迹与内部光栅位置闭环，但外部控制器并未接管位置控制器本身 |
| 标签与官方证据 | E3-REF：`D:\清华\清华-科研横向\光栅尺运动控制调研\90_原始资料\官方手册\DINGS_DS-BVS-BVM_Series_Reference_Manual.pdf`，VER 1.0，PDF pp.45–47，§5.7–5.7.1；PDF p.173，§6.2.135–6.2.137 |
| 证明了什么 | CSP 把轨迹点生成交给外部，把三级伺服环留在驱动器 |
| 没有证明什么 | 不证明 PDO 已映射、SYNC/DC 已配置、位置反馈来自光栅尺或当前主站能按确定周期发送 |

## 5. Cyclic Synchronous Velocity Mode（CSV）

| 项目 | 内容 |
|---|---|
| 模式事实 ID | MODE-B1-CSV |
| 外部输入对象 | `0x60FF Target Velocity`；可选 `0x60B1 Velocity Offset`；`0x6040/0x6060` 管状态和模式 |
| 驱动器内部轨迹生成 | 无外部目标的完整速度 profile generator；驱动器对相邻速度值进行基于插补周期的线性插补，且只在 PDO 通信有效 |
| 驱动器保留的控制环 | 速度环、电流/转矩环 |
| 反馈对象 | `0x6064 Position Actual`、`0x606C Velocity Actual`、`0x6077 Torque Actual`、`0x6041 Statusword` |
| 推荐通信方式 | PDO；CANopen 同步运行需 synchronous PDO + SYNC |
| 是否要求周期更新 | 是。手册称 `0x60FF` 在每个 PDO 更新周期更新 |
| 是否要求 SYNC/PDO | PDO 是模式描述的周期入口；SYNC 是否触发取决于 PDO communication parameter，不因选择 CSV 自动成立 |
| 手册是否给出周期保证 | 未给出最小/最大 PDO 周期、同步误差或 1 kHz 保证 |
| 当前台架是否验证 | 未验证 |
| 对外位置环研究的意义 | 外部控制器可用独立光栅尺闭合位置环并输出速度目标，DS-BVM 保留速度/电流内环；这是手册语义上最直接的“外位置环 + 驱动器速度内环”接口 |
| 标签与官方证据 | E3-REF：`D:\清华\清华-科研横向\光栅尺运动控制调研\90_原始资料\官方手册\DINGS_DS-BVS-BVM_Series_Reference_Manual.pdf`，VER 1.0，PDF pp.42–44，§5.6–5.6.1；PDF p.173，§6.2.136 |
| 证明了什么 | CSV 将位置环/轨迹规划留给外部，驱动器完成速度与转矩控制 |
| 没有证明什么 | 不证明 STM32 能准时读取光栅并发送 PDO，不证明 DS-BVM 的电机侧速度反馈已经独立存在或正确配置 |

## 6. Cyclic Synchronous Torque Mode（CST）

| 项目 | 内容 |
|---|---|
| 模式事实 ID | MODE-B1-CST |
| 外部输入对象 | `0x6071 Target Torque`；可选 `0x60B2 Torque Offset`；`0x6040/0x6060` 管状态和模式 |
| 驱动器内部轨迹生成 | 无。轨迹发生器位于外部控制设备 |
| 驱动器保留的控制环 | 电流/转矩控制；电机数据用于速度和电流限值。位置环和速度环由外部控制器承担或根本不闭合 |
| 反馈对象 | `0x6064 Position Actual`、`0x606C Velocity Actual`、`0x6077 Torque Actual`、`0x6041 Statusword` |
| 推荐通信方式 | PDO；CANopen 同步运行需 synchronous PDO + SYNC |
| 是否要求周期更新 | 是。手册称 `0x6071` 在每个 PDO 更新周期更新，并以同步方式提供目标转矩 |
| 是否要求 SYNC/PDO | PDO 是模式描述中的周期入口；SYNC/PDO 参数仍需主站配置，不会因选择 CST 自动成立 |
| 手册是否给出周期保证 | 未给出最小/最大 PDO 周期、同步误差、电流环周期或 1 kHz 保证 |
| 当前台架是否验证 | 未验证 |
| 对外位置环研究的意义 | 外部可同时承担位置、速度控制并直接给转矩；控制自由度最大，但对实时性、限位、失联处置、参数辨识和安全链的要求也最高 |
| 标签与官方证据 | E3-REF：`D:\清华\清华-科研横向\光栅尺运动控制调研\90_原始资料\官方手册\DINGS_DS-BVS-BVM_Series_Reference_Manual.pdf`，VER 1.0，PDF pp.39–41，§5.5–5.5.1；PDF p.174，§6.2.137 |
| 证明了什么 | CST 把轨迹、位置和速度控制交给外部，DS-BVM 主要保留转矩/电流控制 |
| 没有证明什么 | 不证明当前硬件有足够安全冗余，不证明外部控制器达到所需确定性，不证明 1 kHz 足够或可达 |
