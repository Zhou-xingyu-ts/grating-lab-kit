# 基于现有证据的架构建议

## 1. 建议结论

这不是不可逆选型，而是一份供人工决策的优先级：

1. **近期验证基线：A，光栅直接进入 DS-BVM，由驱动器完成内部闭环。置信度：高。**
2. **首选研究候选：B，光栅进入 STM32，STM32 外位置环 + DS-BVM CSV。置信度：中。**
3. **备选研究路线：D，光栅继续进入 DS-BVM，STM32 轨迹规划 + CSP。置信度：中偏低。**
4. **现阶段不推荐：C，STM32 位置/速度环 + DS-BVM CST。对“不应首发”的置信度：高。**

## 2. 为什么需要“A基线 + B研究候选”两层结构

若只选 A，工程可行性最高，但控制器内部不可见，论文容易主要堆在自研尺、平台搭建、标定和实验上。若直接跳到 B，控制研究空间明显增大，但当前主站、反馈和安全证据均未闭合。

因此更稳健的课题表述是：

> 先以 DS-BVM 内部光栅闭环建立可重复、可标定的单轴基线；在确认电机侧反馈、STM32 光栅接口、PDO/SYNC 时序和安全条件后，评估外位置环 + CSV 作为主要控制研究路线。三轴与自研光栅尺作为分阶段扩展目标。

这个结构让开题不依赖“开题前已经搭好三轴/完成外环”，也避免把课题压在一个尚无周期保证的架构上。

## 3. 近期验证基线 A

### 推荐理由

- E1 已验证商业光栅直接进入 DS-BVM 的单反馈运动闭环；
- E3 明确支持增量单反馈和内部位置模式；
- 不依赖当前不存在的 CANopen 写控制、PDO/SYNC或外环固件；
- 能优先关闭 counts/mm、方向不对称、参数敏感性和重复性这些真实问题；
- 即使 B 最终不可行，A 仍能支撑平台、自研尺接口、标定与误差补偿工作。

### 研究边界

可研究标定、误差预算、重复定位、方向效应、轨迹参数敏感性、数据采集方法和补偿；不能声称拥有可修改的驱动器内部控制律。

### 置信度限制

“A能工作”置信度高；“A能达到某μm精度”无证据。当前 0.5 μm/count 不是正式标定。

## 4. 首选研究候选 B

### 推荐理由

- CSV的官方控制权边界与“外位置环 + 驱动器速度内环”高度匹配；
- 相比CST，仍把速度/电流内环和换相留在驱动器，显著降低实时控制和安全负担；
- 光栅独立进STM32可绕开“两套增量反馈都进DS”的物理端口冲突；
- 可围绕真实外位置误差建立模型、基础控制器和针对明确现象的一项补偿；
- `h750_demo`能提供RTOS/定时/CANopenNode骨架，虽不能提供主站应用。

### 必须满足的条件

1. DS-BVM 有独立电机侧反馈，能闭合速度/电流环并完成换相；
2. 自研/商业光栅可被 STM32 确定性读取，电气和计数时序明确；
3. DS-BVM 的 CSV、60FF、6040/6041、PDO映射和SYNC在型号/固件上确认；
4. 通过无运动验证得到可接受的周期、抖动、丢帧和超时行为；
5. Quick Stop/STO/限位/目标速度限幅和通信失联策略先于运动实现；
6. 先辨识/验证现有单轴模型，再谈具体控制算法。

### 适合写入开题的研究问题

- 外部光栅位置采样与CANopen目标更新的时序如何影响闭环性能？
- 量化、采样抖动、通信延迟和机械方向效应如何进入外位置环误差？
- 在驱动器速度内环固定的条件下，如何设计和验证外位置控制与前馈/补偿？
- 单轴方法如何扩展到三轴统一时基和自研光栅接口？

这些是研究问题，不是对 PID/DOB/ADRC/MPC 的预选。

### 置信度限制

官方模式支持清楚，故“概念可行”置信度中等；当前硬件和1 kHz性能未验证，故“可直接落地”置信度低。

## 5. 备选 D

### 推荐边界

D只保留“光栅进入DS作为位置反馈，STM32发CSP轨迹”的分支。其优势是保留DS位置/速度/电流环，同时给STM32轨迹和多轴同步控制权；缺点是外部控制器不接管位置控制律，控制创新更偏轨迹规划、轮廓误差和三轴协调。

若B因电机侧反馈、STM32光栅输入或安全复杂度无法关闭，D可作为降低外环风险的备选。但D仍需完整PDO/SYNC/CiA402主站，并且无官方周期保证。

## 6. 不推荐 C 首发

C把位置和速度环均交给STM32，要求可靠速度估计、转矩标定、限幅、实时性、模型和失联安全。阶段A没有外环，B1无周期保证，B2也没有遗留控制器或主站可继承。它会让课题同时承担硬件、通信、实时系统、建模、控制器和安全六类高风险工作。

只有在B路线已完成通信、反馈、模型和安全验证后，且研究确实需要直接转矩控制，才应重新评估C。
