# 四种反馈/控制拓扑统一比较

## 1. 判级

- **当前基线可行**：手册能力与当前 E1 台架均有支撑，但不代表精度完成。
- **研究候选可行**：控制权和接口语义成立，关键依赖尚待确认。
- **备选可行**：可作为轨迹/多轴路线，但对外位置环研究价值较弱或反馈分支需限定。
- **现阶段不推荐**：理论可行，但实时性、安全、模型和接口证据不足以承担首发风险。

## 2. 总表

| 架构 | 等级 | 光栅接入 | DS保留控制环 | STM32负责 | 模式/对象 | 周期要求 | 当前证据 | 主要研究问题 |
|---|---|---|---|---|---|---|---|---|
| A 光栅直接进DS | **当前基线可行** | DS数字/其他受支持反馈口 | PPM时轨迹+位置+速度+电流；CSP时位置+速度+电流 | 无或只做上层命令/监测 | PPM/PRM；也可后续CSP | PPM不要求周期；CSP要求周期PDO | E1+E3最强 | 标定、误差补偿、参数敏感性、重复定位、内部闭环性能边界 |
| B STM32外位置环+CSV | **首选研究候选** | STM32确定性计数口 | 速度+电流/转矩 | 轨迹、位置环、位置安全边界 | CSV，60FF；回读606C/6077/6041等 | 周期PDO/SYNC；具体周期待验证，1 ms仅候选 | E3支持，E4仅骨架，当前未验证 | 外位置环、摩擦/扰动、速度前馈、重复轨迹误差、外环带宽 |
| C STM32位置/速度环+CST | **现阶段不推荐** | STM32 | 电流/转矩 | 轨迹、位置、速度、限幅/安全 | CST，6071；回读6077/606C/6041 | 更严格周期PDO/SYNC；无官方保证 | 仅E3能力，E4无实现 | 完整级联控制、观测器、扰动补偿，但风险和工作量最高 |
| D STM32轨迹+CSP，光栅继续进DS | **备选可行** | 必须优先限定为DS位置反馈 | 位置+速度+电流 | 轨迹规划、三轴同步、轨迹连续性 | CSP，607A；回读6064/606C/6077/6041 | 周期PDO/SYNC；具体周期待验证 | E3支持，E1可支撑反馈分支，E4无实现 | 轨迹规划、同步、轮廓误差、多轴协调；不接管位置控制器 |

## 3. 架构 A：光栅直接进入 DS-BVM

| 比较维度 | 结论 |
|---|---|
| 光栅接入位置 | 当前 Ri0040 经数字编码器接口进入 DS-BVM；未来自研尺可考虑 RS422 A/B(/I)，或按规格选择 Sin/Cos/SSI/BiSS-C |
| 电机侧反馈需求 | 当前单反馈结构下未确认独立电机侧反馈；速度估算和换相来源仍是证据缺口 |
| 换相信号来源 | 可能为 Hall/已配置的电角度机制；当前未确认，不能假定 |
| DS内部环 | 选择 PPM/PRM 时保留内部位置、速度、电流环；驱动器可内部生成轨迹或直接调节位置 |
| STM32职责 | 可无 STM32；若引入，只做监测、实验编排或上层目标，不形成关键安全闭环 |
| 所需模式/对象 | PPM：607A+profile参数+6040/6041；现有 Servo Studio 已能下命令，但 CANopen 写路径未放行 |
| PDO/SYNC | PPM不要求；若改CSP则转入架构D |
| 理论通信周期 | PPM不依赖逐周期网络更新；采集周期可与控制周期解耦 |
| 官方周期保证 | 无需用1 kHz作为该架构成立前提；内部环频率仍未公开 |
| 当前兼容性 | 最高：E1 已有单轴运动闭环记录，E3明确支持增量单反馈 |
| 自研尺输出要求 | 优先 RS422 差分 A/B，可选I；四倍频前≤10 MHz；供电、方向、分辨率、隔离和抗干扰需确认 |
| 三轴扩展 | 每轴独立 DS 内部闭环，上层协调；自研尺需逐轴接口/标定 |
| 改造量 | 最低；主要是标定、参数与实验方法，不是外环固件 |
| 安全风险 | 相对最低，但单反馈故障、方向/尺度错误、换相来源仍需安全核查 |
| 可研究控制问题 | 内部闭环的参数敏感性、误差补偿、重复定位、轨迹/速度设定对跟随误差影响；控制器内部算法可见性弱 |
| 可形成论文工作 | 自研光栅接口与标定、单轴/三轴系统集成、误差预算、补偿与性能实验；控制算法创新空间较小 |
| 证据强度 | **高（当前基线）**：E1+E3；精度与自研尺仍无证据 |
| 必须补充 | counts/mm标定、换相/速度来源、当前参数、外部基准、重复性与安全边界 |

## 4. 架构 B：STM32 外位置环 + DS-BVM CSV

| 比较维度 | 结论 |
|---|---|
| 光栅接入位置 | 独立进入 STM32 定时器/专用计数接口，不占用 DS 的负载侧增量口 |
| 电机侧反馈需求 | DS 必须有独立且足以闭合速度/电流环及建立电角度的电机侧反馈 |
| 换相信号来源 | DS 侧电机反馈/Hall/其他已验证电角度机制；不能由负载侧光栅默认替代 |
| DS内部环 | 速度环、电流/转矩环 |
| STM32职责 | 轨迹、外位置环、位置限幅、目标速度生成、失联处置；可加入后续可证伪的补偿算法 |
| 所需模式/对象 | CSV；RPDO含6040/6060/60FF，TPDO至少6041/606C，按需6077/错误对象；实际映射待设计 |
| PDO/SYNC | 必需；CANopen同步方案需synchronous PDO+SYNC或有证据的等效定时方案 |
| 理论通信周期 | 外位置环要求固定周期，周期应由闭环带宽/总线预算/抖动共同确定；**不预设1 ms必然可达或必要** |
| 官方周期保证 | 未找到；必须通过后续无运动通信测时与低风险台架逐级验证 |
| 当前兼容性 | 模式语义可行；但当前是否存在独立电机反馈、STM32光栅输入和主站均未确认 |
| 自研尺输出要求 | STM32可确定性采集的差分增量/绝对输出；需电平、计数速率、时间戳、丢计数检测和电气隔离规格 |
| 三轴扩展 | 每轴一套位置状态与CSV目标；需统一时基、SYNC、总线负载和分轴安全状态 |
| 改造量 | 中高：主站、CiA402、PDO、光栅驱动、外位置环和安全层基本需重做；可借h750_demo骨架 |
| 安全风险 | 总线超时/目标速度保持、外环发散、计数跳变、限位逻辑错误；需独立Quick Stop/STO/机械限位策略 |
| 可研究控制问题 | 外位置环带宽、摩擦/间隙/扰动影响、速度前馈、重复轨迹补偿、采样抖动与量化误差 |
| 可形成论文工作 | 外位置环建模、确定性采样/通信架构、基础控制器+一项针对明确现象的补偿、单轴到三轴扩展 |
| 证据强度 | **中（研究候选）**：E3清楚；E4仅工程骨架；无E1外环 |
| 必须补充 | 电机侧反馈、STM32输入、自研尺规格、PDO映射、周期/抖动、安全状态、现平台模型与标定 |

## 5. 架构 C：STM32 位置/速度环 + DS-BVM CST

| 比较维度 | 结论 |
|---|---|
| 光栅接入位置 | STM32 |
| 电机侧反馈需求 | DS仍需转矩/电流控制与换相所需电角度；STM32还需可靠速度估计或第二传感器 |
| 换相信号来源 | DS侧已验证电机反馈；必须明确 |
| DS内部环 | 电流/转矩环和驱动保护 |
| STM32职责 | 轨迹、位置环、速度环、转矩目标、限幅、反积分饱和、失联与异常安全 |
| 所需模式/对象 | CST；6040/6060/6071，回读6041/6077/606C及故障对象 |
| PDO/SYNC | 必需且时序要求最严 |
| 理论通信周期 | 需显著快于外部速度环带宽并有低抖动；现证据无法给出数值 |
| 官方周期保证 | 无 |
| 当前兼容性 | 只有模式能力；当前反馈、主站、控制器、安全均不具备 |
| 自研尺输出要求 | 高可靠位置+可支撑速度估计的时序质量；需异常检测和可能的冗余 |
| 三轴扩展 | 总线、计算、同步和安全工作量最高 |
| 改造量 | 最高 |
| 安全风险 | 错误转矩直接致动；速度噪声、模型误差、失联与饱和均可能失控 |
| 可研究控制问题 | 完整级联、状态观测、扰动补偿、自适应；但前置工程会吞噬研究周期 |
| 可形成论文工作 | 理论空间大，但没有先验实物链时失败风险过高 |
| 证据强度 | **低—中（能力层）** |
| 必须补充 | 全部B依赖，另加转矩标定、电流/转矩限制、速度估计、WCET、形式化安全和分级实物放行 |

## 6. 架构 D：STM32 外部轨迹 + DS-BVM CSP

本阶段只保留“光栅继续进入 DS-BVM，作为 DS 位置环反馈”的 D 分支。若光栅只进 STM32，它不会自动成为 CSP 的位置反馈，不能满足“基于光栅反馈”的核心叙述。

| 比较维度 | 结论 |
|---|---|
| 光栅接入位置 | DS-BVM 的位置反馈口；优先沿用当前单反馈分支 |
| 电机侧反馈需求 | 若单反馈，当前换相/速度来源仍待确认；若双反馈，则受型号端口冲突约束 |
| 换相信号来源 | DS侧已配置机制，需确认 |
| DS内部环 | 位置、速度、电流/转矩环 |
| STM32职责 | 周期轨迹点、插补、三轴同步、轨迹连续性和上层安全监控 |
| 所需模式/对象 | CSP；6040/6060/607A，回读6041/6064/606C/6077 |
| PDO/SYNC | 必需；同步PDO+SYNC配置待实现 |
| 理论通信周期 | 需满足轨迹插补和跟随要求；具体值待通信/台架验证 |
| 官方周期保证 | 无 |
| 当前兼容性 | DS端光栅单反馈已有E1；CSP/PDO主站无E1/E4实现 |
| 自研尺输出要求 | 必须兼容DS反馈接口；若为RS422 A/B，满足10 MHz前端上限和电气要求 |
| 三轴扩展 | 天然适合统一轨迹时基与多轴同步，但每轴DS反馈/模式需独立确认 |
| 改造量 | 中：主站/PDO/轨迹规划；无需外位置控制器和STM32光栅读取 |
| 安全风险 | 轨迹跳变、PDO丢失、反馈尺度/方向、同步失配；低于CST但高于PPM基线 |
| 可研究控制问题 | 轨迹规划、同步、轮廓误差、跨轴协调；DS内部位置控制不可见 |
| 可形成论文工作 | 自研尺+驱动内部闭环+STM32三轴同步；控制创新偏规划/协调而非底层控制律 |
| 证据强度 | **中（备选）** |
| 必须补充 | CSP PDO映射、SYNC周期、丢帧行为、当前反馈/换相、三轴总线预算 |

## 7. 结论

- A 应保留为所有后续路线的对照基线和最低风险交付路径。
- B 是当前证据下最值得人工优先评估的“控制研究候选”，但不等于已选定。
- D 是更偏轨迹规划/三轴同步的备选，必须保证光栅仍进入 DS 位置环。
- C 暂不作为首发路线；只有在 B 的通信、反馈、模型和安全证据全部关闭后才值得重新评估。

证据索引见 `00_THREE_WAY_EVIDENCE_CROSSWALK.md` 的阶段 A/B1/B2完整路径和事实 ID。
