# 控制算法适用前提矩阵

## 1. 判定尺度

- `READY`：当前信号与权限原则上满足。
- `DIAGNOSTIC_ONLY`：可用于离线解释/比较，不能闭环部署。
- `BLOCKED_BY_DATA`：采样、同步、标定或状态不足。
- `BLOCKED_BY_PERMISSION`：没有可写控制通道。
- `NOT_A_CURRENT_DIRECTION`：即便理论成立，也偏离当前最小闭环目标。

## 3. 采样率不是单一阈值

算法可用性取决于目标现象最高频率 (f_max)、有效延迟与同步，而不是“达到某个常数就行”。最低应满足：

1. 采样频率远高于目标带宽的 Nyquist 下限，并留出辨识/相位裕量；
2. 命令与反馈同一时基、可确定延迟；
3. 反混叠与滤波已知；
4. 采样抖动、串行轮询偏移和丢样可量化。

当前 50/200 Hz 且对象串行读取，适合秒级/数十毫秒级趋势和慢工况比较；不适合识别通常位于数十至数百 Hz 的轴向共振，也不能支持 1 ms 控制律论证。即使插值到 1 kHz，也不会产生缺失的带宽或同步信息。

## 4. 当前可做与不可做

### 可做

- 统一记录位置目标、实际位置、方向、速度档、行程区间、重复序号和可用状态字。
- 对外部闭环的稳态偏差、重复性、方向差、换向邻域和慢动态做受限诊断。
- 在有限的候选模型间做阶次/工况差异比较，并明确“等效闭环”含义。
- 设计未来需要何种同步、标定、控制写权才能升级到 LPV/ILC/DOB 等方法的证据门。

### 不可做

- 从现有 SDO 数据反推 DS-BVM 电流环、速度环和位置环各自参数。
- 宣称辨识到纯机械 (M/B/K)、摩擦参数或双质量共振。
- 在无写权限时把任何控制算法列为已实施候选。
- 把 7 对象 50 Hz 或 3 对象 200 Hz 写成同步控制周期。
