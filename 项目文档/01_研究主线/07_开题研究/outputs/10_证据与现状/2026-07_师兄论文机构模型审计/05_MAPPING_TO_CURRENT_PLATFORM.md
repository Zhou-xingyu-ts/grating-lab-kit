# 师兄论文模型到当前商业单轴平台的映射

## 0. 当前比较基线

### 师兄论文平台

- 历史三轴机械运动台；
- 论文表 2.2 的 30ZWWC60 电机、表 2.3 的 E-KBS0602-70 丝杠；
- 光栅尺测量工作台位移；
- 抽象控制输入为电磁力 \(F_e\) 或 \(u=F_e/M\)；
- STM32H7 + CANopen PDO + 1 ms 的设计主张；
- 二阶机械对象上的 PID、静态前馈和 LQR 仿真。

### 当前平台

- 当前电机：30ZWWC65TEK5B-1 带刹车空心杯电机；
- Ri0040 光栅进入 DS-BVM，由驱动器闭合位置/速度/电流环；
- 当前运动入口：Servo Studio 相对位置运动；
- 当前 CANopen：Node-ID=1、1 Mbit/s，SDO upload 只读；
- 7 对象动态记录约 50 Hz，3 核心对象约 200 Hz；
- 顺序 SDO 读取，无同步快照；
- 尚未完成外部正式位移标定；
- 当前只能研究外部目标/实际位置等闭环输入输出。

## 2. 机械物理模型

### 可继承

- 从自由体图写牛顿/欧拉方程的方法；
- 导程换算和转动惯量折算公式；
- 用双质量检查第一柔性模态是否进入控制频带的思想；
- 降阶前先做频带比较的原则。

### 必须重建/辨识

- 当前电机、丝杠、联轴器、制动器和工作台的精确物理参数；
- 实际负载与 Z 轴重力；
- 丝杠效率、预紧、回差、方向差；
- 柔性共振是否在当前可观测频带；
- 当前命令模式下“机械阻尼”和“内部速度反馈”的可分性。

论文的 \(M=0.5\) kg、仿真的 7.7 kg、\(B=0.5\)、\(K=5\)、\(F_c/F_v\) 均不能直接放入当前模型。

## 3. 驱动器内部黑箱模型

DS-BVM 官方手册说明：

- 位置、速度和电流环分层存在；
- PPM 内含位置轨迹发生器，并产生速度/加速度需求；
- 速度环有 PI、速度前馈和加速度前馈设置；
- 位置环有数字 PID 设置；
- 电流环有增益/带宽设置；
- CSP/CSV/CST 等模式的上位机接口各不相同。

这些是产品能力，不等于当前配置已知。当前只读对象和 Servo Studio 运动不能回答：

- 当前实际生效的内环参数；
- 内部限幅、滤波、前馈和抗饱和；
- 内部控制周期和采样同步；
- 力/转矩实际波形；
- 哪一部分延迟来自总线、轨迹发生器、内环或机械。

所以当前合理的研究对象是：

\[
\text{相对位置目标/可记录目标量}
\longrightarrow
\text{DS-BVM + 电机 + 机构 + Ri0040 的整体闭环}
\longrightarrow
\text{实际位置}
\]

这不是否认机械机理，而是在当前可观测性下避免不可辨识拆分。

## 4. 传感器模型

| 项目 | 当前状态 | 对建模的影响 |
|---|---|---|
| 反馈位置 | Ri0040 已进入 DS-BVM 内部位置闭环 | 可以观察整体位置响应 |
| 比例 | 约 0.5 μm/count 的工程理解 | 未经外部标定，不能作为绝对精度证明 |
| 零点/方向 | 可从软件运动记录观察相对变化 | 正负方向、坐标原点仍要明确 |
| 同步性 | 轮询对象顺序获取 | 同轮不同对象不是严格同一采样时刻 |
| 内部滤波 | 当前不可见 | 不能把记录噪声直接等同于传感器本体噪声 |
| 延迟 | 仅有整轮读取时刻 | 不能唯一分解传感器延迟和命令延迟 |

论文把 \(y\) 视为连续、同步、无噪声状态；当前数据不能直接满足这一假设。

## 5. 通信和离散模型

### 师兄论文

控制算法假定 1 ms；PPT称 CANopen PDO。PID.slx 确实设 1 ms，但 LQR 跟踪使用连续 ode45。历史固件又缺少完整主站/PDO/SYNC证据。

### 当前平台

- 7 对象动态记录：约 50 Hz；
- 3 核心对象：约 200 Hz；
- 这些是 SDO 只读观测速率，不是驱动器内部控制周期；
- 顺序读取，不是同步采样；
- 当前没有外部 CANopen 写命令。

所以不能把当前 200 Hz 数据简单重采样成论文 1 ms，也不能用其证明 1 kHz 控制可行。若研究带宽接近观测 Nyquist 频率，参数和相位会严重不可靠。

## 6. 控制器模型

### PID

论文 PID 使用理想力对象，当前 PPM 已经闭合位置、速度、电流环。把论文 PID 再包在外面会改变对象边界，并可能与内部速度/位置作用重复。当前既无写入权限，也无严格同步，所以 CURRENT_PLATFORM_APPLICABLE=NO。

### 前馈

论文前馈只对恒定位置平衡有意义；DS-BVM 手册中的速度/加速度前馈属于驱动器内部位置/速度控制结构。两者名称相同，接口和量纲却不同，不能互换。

### LQR

论文 LQR 需要 \(z=[y,\dot y]\) 和 \(u=F_e/M\)。当前只有顺序读取的外部量，且不能直接施加力/加速度命令，所以论文增益不可部署。将来即使开放 CST，也必须重新建立输入缩放、内环带宽、状态估计、采样、限幅和安全边界。

## 7. 当前可以做的“等效闭环研究”

当前阶段理论上可研究但本任务不执行的对象边界是：

- 输入：Servo Studio 已知相对位置目标及其可记录参数；
- 输出：Ri0040/DS-BVM 报告的实际位置；
- 模型：低阶闭环等效模型，明确把内部轨迹、控制器和机械合并为黑箱；
- 结论：只描述当前命令幅值、速度/加速度设置、方向和数据频率覆盖范围内的局部动态；
- 不做：把等效时间常数解释为电机惯量、把等效阻尼解释为导轨摩擦、把 SDO 轮询频率解释为控制周期。

这正是阶段 D1 的模型交接和阶段 E 参数可辨识性矩阵所限定的路线。

## 8. 继承清单

### 可直接作为理论起点

1. 旋转—直线能量/虚功等效；
2. 双质量自由体图与柔性模态概念；
3. 二阶方程到传递函数/状态空间的方法；
4. PID、前馈、LQR分别需要何种模型信息的比较框架；
5. 先核对输入接口和控制权限，再选对象边界。

### 只能保留为历史概念

1. 论文电机/丝杠选型数值；
2. 双质量图中的未给参数；
3. 电流环单位增益；
4. 1 ms CANopen PDO 和三轴闭环主张；
5. 图 2.21 的 PID/LQR性能比较。

### 当前必须重新处理

1. 当前机械几何、质量、惯量、刚度、摩擦；
2. Ri0040 比例、方向和外部标定；
3. 目标—实际位置整体闭环模型；
4. 命令/测量延迟与非同步轮询影响；
5. 若未来开放新的命令模式，再重新定义控制器输入、采样、限幅和安全约束。
