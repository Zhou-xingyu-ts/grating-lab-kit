# 模型简化路径与假设审计

## 0. 核心裁决

论文不是“先建立了可复现的双质量模型，再经过有证据的降阶得到二阶模型”。更准确的描述是：

1. 用图 2.15 引入了双质量机理；
2. 没有写出双质量微分方程、参数或模态；
3. 随后另起一个单质量二阶方程式 2.10；
4. PID、前馈和 LQR 全部基于这个二阶对象；
5. 归档 Simulink 也只实现了二阶对象。

所以双质量模型是概念性理论入口，单质量模型才是实际仿真对象；两者之间缺少可审计的降阶桥梁。

## 1. 为什么先画双质量，最终却用较低阶模型

论文正文给出的理由是：集总参数模型计算量小，适合实时控制，同时希望保留主要低阶振动；PPT还写到“实现旋转部件和直线部件的不完全解耦”和“忽略滚珠丝杠的转动惯量”。

从控制建模常识看，合理的意图可能是：

- 双质量用于解释电机侧与负载侧并非完全刚性；
- 在控制频带远低于第一柔性共振时，用一个等效二阶对象做控制器初步设计；
- 用更少状态换取便于 PID/LQR 分析的模型。

但论文没有给出使该意图成立所需的证据：

- 双质量的 \(m_1,m_2,k,c,b_1,b_2\)；
- 第一共振频率/反共振频率；
- 目标控制带宽；
- 频响或模态实验；
- 低阶模型与双质量模型的频域误差；
- 刚性合并、奇异摄动或模态截断的推导。

因此“计算简化”可以解释作者为什么这样做，不能证明这个简化对历史对象有效。

## 2. 双质量模型保留了哪些机械模态

四状态双质量模型至少保留两类运动：

### 2.1 共同运动模态

两块质量近似同向、同速移动：

\[
x_1\approx x_2
\]

这个模态主要受总等效质量 \(m_1+m_2\) 和对地阻尼影响。

### 2.2 相对柔性模态

两块质量发生相对运动：

\[
q=x_1-x_2
\]

其近似固有频率为

\[
\omega_f\approx
\sqrt{k\left(\frac1{m_1}+\frac1{m_2}\right)}
\]

该模态可以产生负载侧共振、相位快速变化，以及输入端/负载端之间的反共振特征。这正是滚珠丝杠、联轴器和安装链柔性对控制最重要的低阶影响。

论文声称保留“一阶扭转与轴向振动”，但图 2.15 已把旋转侧转换为直线侧，并只画一个耦合弹簧/阻尼。它并没有给出两个可独立识别的“扭转模态 + 轴向模态”；最多可以解释为把多种柔性压成一个相对模态。

## 3. 最终仿真是否仍含双质量共振

不含。

静态读取 mechanical_system.slx 得到：

- 单个 Transfer Fcn；
- 分母参数 [M B K]；
- 外部库仑/黏性摩擦反馈；
- 一个净力饱和块；
- 只有位移输出及其导数。

因此线性机械部分只有一个二阶极点对。它可能有自己的自然频率

\[
\omega_n=\sqrt{K/M}
\]

但没有双质量模型典型的四阶分母，也没有负载侧传函分子 \(cs+k\) 所产生的共振—反共振结构。PID 闭环振荡或摩擦引起的波形变化不能被重新解释为“双质量共振仍在”。

## 4. 忽略丝杠转动惯量的影响

丝杠惯量折算为

\[
m_{J_s}=J_s\left(\frac{2\pi}{p}\right)^2
\]

忽略它会：

1. 低估总等效质量；
2. 高估同样驱动力下的加速度；
3. 高估自然频率和可实现控制带宽；
4. 低估峰值转矩/电流和加减速时间；
5. 改变电机侧与负载侧的质量比，从而移动柔性共振和反共振；
6. 使按名义对象得到的 PID/LQR 增益偏激进；
7. 在 2 mm 小导程下造成特别明显的折算放大。

表 2.2 的电机转子惯量按 2 mm 导程折算已约为 27.6 kg，而仿真质量是 7.7 kg、表 2.6 又是 0.5 kg。即使暂不计丝杠，参数链也不闭合；因此“忽略丝杠惯量”不能被看成一个已证明影响很小的近似。

## 5. 电流环/FOC 简化为单位增益的前提

设驱动器从力/电流命令到实际力的闭环为 \(G_i(s)\)。用 1 代替它，至少需要在研究频带 \([0,\omega_b]\) 内满足：

\[
|G_i(j\omega)|\approx1,\qquad
\angle G_i(j\omega)\approx0
\]

并且：

- 电流环带宽明显高于外层速度/位置/机械带宽，通常需要约 5—10 倍频带分离；
- PWM、采样、计算和通信延迟在该频带内足够小；
- 未触发电流、转矩、速度、加速度、母线电压或热保护限制；
- FOC 角度、极对数、电阻、电感、反电势和转矩常数配置正确；
- 命令确实进入电流/转矩接口，而不是先经过内部位置轨迹发生器。

DS-BVM 官方手册说明其内部具有位置、速度和电流环；PPM 的目标位置先进入内部轨迹发生器，随后形成位置、速度/加速度需求。当前实际使用的是 Servo Studio 相对位置运动，不是论文中的理想力或归一化加速度命令。因此当前不能把整个驱动器当成“单位电流环”接在论文机械对象前。

## 6. 是否重复建模内部速度环、机械阻尼和显式控制器

存在明显风险。

论文一处描述“位置 P—速度 PI—内部电流环”三环，另一处却用单 PID 直接包围力到位移机械对象。如果单 PID 的输出是力命令，而且历史驱动器只闭合电流环，这种模型尚可作为理想化外环；如果驱动器内部速度环也在工作，则：

- 机械阻尼 \(B\) 与内部速度反馈形成的等效阻尼可能被同时计入；
- 外部 PID 的微分/速度作用与内部速度 PI 重叠；
- 对象不再是 \(1/(Ms^2+Bs+K)\)，而是驱动器已闭合的速度或位置对象；
- LQR 的输入 \(F_e/M\) 不再是可直接施加的控制量。

当前 DS-BVM 平台在位置模式下明确包含内部位置、速度、电流环和轨迹发生器。当前只读数据只能观察目标/实际位置等外部闭环量，不能把内部环参数与机械 \(B\) 分开。阶段 D1/E 的保守结论——先研究等效闭环，而不拆解内部环——与该可辨识边界一致。

## 7. 能否解释换向、低速爬行和方向差异

论文模型只能部分、定性地表示换向：

- \(F_c{\rm sgn}(v)\) 会在速度过零时翻转；
- \(F_vv\) 表示随速度线性变化的耗散。

它不能充分解释：

- 静止阶段的粘着与起动阈值；
- Stribeck 低速区和爬行；
- 丝杠预紧、间隙、滚珠回流和方向性效率；
- Z 轴重力及制动器释放过程；
- 电机相序、换相、霍尔/编码器方向；
- 驱动器内部轨迹发生器、限流和抗积分饱和；
- 线缆拖曳、导轨不均匀、温度与润滑；
- 采样顺序、通信延迟及“同轮非同步”。

所以当前观察到的正反向差异不能仅用论文 \(F_c,F_v\) 归因，更不能在只有位置记录时把摩擦、重力、内环和时延唯一分离。

## 8. 仿真输入与 DS-BVM 命令接口断层

| 层级 | 论文/仿真输入 | DS-BVM 手册中的实际接口 | 当前已放行状态 | 断层 |
|---|---|---|---|---|
| 机械对象 | 力 \(F_e\) | 驱动内部实际形成的电磁力/转矩，不是当前上位机直接量 | 不可直接命令/观测 | 输入层不同 |
| 状态空间 | \(u=F_e/M\)，单位 m/s² | 无“归一化加速度”对象接口 | 无 | 纯数学输入 |
| PID.slx | 位置误差经 PID 产生理想力 | PPM/PRM/CSP 等目标位置接口会经过内部环 | 当前 Servo Studio 相对位置 | 控制器和对象边界不同 |
| LQR/sys.m | 连续状态反馈、无饱和 | 真实模式有采样、轨迹、限幅和内部控制 | 未部署 | 时间与权限不同 |
| CANopen 设想 | 1 ms PDO | CSP/CSV/CST 可通过 PDO，但需完整主站、同步与 CiA 402 状态机 | 当前仅 SDO upload 只读 | 当前没有写入/同步闭环 |

官方手册表明：

- PPM：目标位置进入驱动内部轨迹发生器；
- CSP：控制器需按 PDO 周期给目标位置，驱动可做线性插值；
- CSV：按 PDO 周期给目标速度；
- CST：按 PDO 给目标转矩；
- PRM/VRM/TRM/CRM 分别直接进入位置/速度/转矩/电流相关控制层。

论文没有把 \(F_e\) 或 \(u\) 映射到一个确定的 DS-BVM 模式、对象字典、缩放、限幅和周期。当前又没有开放 CANopen 写入，所以这个接口断层是实质性的，不是简单改一个增益即可跨越。

## 9. PID/LQR 对比是否公平

不公平，现有材料不足以支持“LQR 在同一对象、同一约束下优于 PID”的严格结论。

| 比较维度 | PID.slx | LQR.m / sys.m / Tracking.m | 是否一致 |
|---|---|---|---|
| 名义 \(M,B,K,F_v\) | 7.7、0.5、5、\(10^{-3}\) | 同组 | 基本一致 |
| 库仑摩擦 | \(F_c=10\) | 无 | 否 |
| 力限幅 | ±100 | 无 | 否 |
| 时间实现 | 1 ms 离散 PID + 连续机械块 | ode45 连续变步长 | 否 |
| 目标序列 | +5、0、−5、0 | 同类分段目标 | 大体一致 |
| 控制器输出约束 | 对象前有净力限幅 | 无 | 否 |
| 噪声、量化、延迟 | 无 | 无 | 同为缺失 |
| 性能指标 | 图中超调/调节时间 | 图中超调/调节时间 | 无控制能量、峰值力和统一容差 |
| 调参依据 | PID Tuner 痕迹，无完整调参记录 | Q/R 主观给定 | 不可比较“最优程度” |

当 LQR 面对的是无摩擦、无限幅、连续对象，而 PID 面对强库仑摩擦和限幅时，超调和调节时间的差异混合了对象差异，不能只归因于控制律。

## 10. 历史实物是否闭合

目前证据只能支持：

- 论文和 PPT 存在机械、PID、LQR、1 ms、CANopen/PDO、三轴设计叙述；
- 归档中存在二阶 Simulink、PID、LQR/跟踪 Matlab 文件和 MAT 绘图数据；
- 历史 STM32 工程中存在 CANopen 协议栈、定时器和部分 SDO/PDO 静态结构；
- 某些工程有编译成功日志。

不能支持：

- 双质量模型在历史实物上被辨识；
- PID、前馈或 LQR 被烧录进固件并调用；
- STM32 已作为 DS-BVM 的完整 CiA 402 主站；
- 1 ms SYNC/PDO 在总线上连续运行；
- 三轴由该固件同步控制；
- 论文图 2.21 曲线来自历史实物而非仿真；
- 历史定位数据与具体固件、控制增益和时间戳形成同一次实验链。

编译记录、源码存在、Simulink 曲线和论文性能叙述必须分别标记，不能互相替代。
