- D1 是当前最有希望的论文候选主线；D2–D4 是其支撑层，不是四条并列必做路线。
- `1 count≈0.5 μm` 仍是工程换算，不是正式标定精度。
- STM32/CANopen、EtherCAT、外部位置环、自研尺和三轴均未因文档设计而成为已实现事实。
- 分析结论区分"已确认 / 初步观察 / 待验证"；不将观测性结论写成正式标定或设备性能声明。
