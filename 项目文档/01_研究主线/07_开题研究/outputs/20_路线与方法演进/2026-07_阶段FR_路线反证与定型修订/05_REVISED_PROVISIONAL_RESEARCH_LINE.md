# 阶段 FR：修订后的暂定研究主线

## 1. 文档定位

本文给出阶段 F 经反证后的**暂定研究主线**。它不是最终架构冻结单，也不意味着新的研究阶段已经开始。

当前最合理的做法，是先沿现有商业器件单轴链路完成可复核的测量、建模和现象归因；总线控制器、自研光栅尺和三轴平台均按独立条件分支管理，不再串成一条默认必经路线。

## 2. 已冻结的基础边界

以下内容可以作为后续工作的稳定边界，但不等于性能结论：

1. 当前唯一完成原始运行证据闭环的链路是：商业 Ri0040（现场索引写作 Ri0040A00B）作为 DS-BVM 的位置反馈，DS-BVM 运行内部单反馈位置环，Servo Studio 通过 USB/COM 完成运动；`motion_acquisition/logs/` 的 CSV+manifest 只支持 Node 1、1 Mbps 的 SDO upload，未支持 CAN 写控制。
2. `0.5 µm/count` 仍是 Ri0040 理论值与用户 `10000 counts≈5 mm` 口述相互吻合的临时工程换算。师兄旧平台虽有干涉仪定位/重复数据，但不能迁移为当前标定。
3. 当前真实CSV观察到正反向差异，但该差异随速度和Accel/Decel/Jerk设置变化，300降到150后正向稳态表现显著改善；因此只能记为工况相关、可重复性待验证的现象，不能直接归因为摩擦、反向间隙、制动器、驱动参数或光栅误差中的单一因素。
4. 阶段 D1 和阶段 E 的模型、敏感性和实验协议均属离线或协议级结果；它们没有把 CANopen、EtherCAT、外部闭环或三轴平台变成已实现事实。
5. 任何新总线路线仍受读写权限、PDO/SYNC 或分布式时钟、对象字典、时延、安全回路和真实设备型号证据约束；当前 DS 精确 FETC/FCAO 后缀仍未由铭牌/identity/固件导出闭合。
6. 当前采集不能把 `estimated_rate_hz` 当实际采样率：Scope约10 Hz，7对象运动约50 Hz，7对象静止处理容量约100 Hz，3对象约200 Hz；同一轮对象共用轮次开始时间戳但依次SDO读取，不是同步快照。

## 3. 强候选近期主线

### 3.1 主线表述

> 基于现有商业光栅尺—DS-BVM 单轴闭环平台，建立可追溯的位移测量与统一时间语义；在不改变核心控制硬件的前提下，完成外部等效动力学或参数规律辨识，复核正反向差异的重复性和因果边界，并对一种模型或补偿方法进行独立验证，或给出严谨的负结果与适用边界。

### 3.2 为什么它是当前最合理候选

- 它复用现有唯一已完成事实闭环的链路，新增依赖最少。
- 它能直接关闭当前最关键的证据缺口：标定、时间语义、重复性、现象归因和独立验证。
- 即使补偿无显著收益，仍可形成可证伪的模型边界、参数规律或负结果，不依赖新控制器按期落地。
- 它不预设 CANopen、EtherCAT、自研光栅尺或三轴平台一定成功，避免把外部依赖写成毕业前提。

### 3.3 建议证据链

1. 商业光栅尺尺度、方向、零点和重复性标定。
2. 指令、驱动内部状态、外部测量及事件标记的时间语义说明；同时区分请求周期、实际轮次、处理容量和轮内串行读取偏移。
3. 在限定行程、速度、负载和安全条件下形成可复现实验集。
4. 识别外部可观测的等效模型或参数规律，并报告辨识区间和失配区域。
5. 设计能区分摩擦、间隙、迟滞、制动器状态、参数设置和测量误差的对照实验。
6. 对一种补偿或建模方法使用独立测试集验证；若无改进，报告统计不确定度和失败边界。

## 4. 条件性系统扩展

下列分支相互独立。任何一个分支成立，都不能自动推出另一个分支成立。

### 4.1 自研光栅尺替换

进入条件：

- 已有可用样机及接口、电源、输出格式和分辨率说明；
- 已完成相对商业尺的尺度、非线性、重复性、方向性和温漂标定；
- 能进入现有链路且不破坏驱动反馈和安全边界；
- 数据具有明确时间戳或可验证的同步关系。

在上述证据关闭前，自研光栅尺只属于 `EXTERNAL_INFO_REQUIRED`，不能写成既定主线。

### 4.2 STM32H743 + CANopen CSP

进入条件：

- 固件实现并验证 NMT 主站、目标 DS-BVM 型号的 CiA 402 状态机、有效 PDO 映射和 SYNC；
- CAN 收发器、CANH/CANL/GND、终端电阻、节点 ID、波特率和总线错误处理均有证据；
- 建立端到端周期、抖动、丢帧和故障停机测试；
- 证明相对 Servo Studio 路线新增的研究收益大于开发和安全成本。

当前可见板卡是 `STM32H743IIT6`；归档中另有 H743 与 H750 多个互不等价工程。一个历史H743工程有成功编译记录，H750工程有FreeRTOS/timer变体，H743工程有SDO client辅助函数；但没有烧录成功或实物运行，且未找到NMT Master、有效DS-BVM RPDO、SYNC producer、CiA 402或三轴调度。它们只证明局部历史静态/编译基础，不证明当前固件身份、最优控制器或上述进入条件已完成。

### 4.3 EtherCAT CSP

进入条件：

- 确认现场 DS-BVM 精确型号、EtherCAT 接口和匹配 ESI；
- 明确实时主站、网卡、许可证、布线和实验室支持条件；
- 实测分布式时钟或等效同步、周期、抖动和故障恢复；
- 证明其对后续多轴同步或数据一致性的收益是论文必要项。

当前DINGS接口板上 `ECAT IN/ECAT OUT` 可见，工作区也有系列ESI（Profile 402、PDO、DC）和历史GM1 Modbus TCP上位机代码；这些材料使EtherCAT不再只是“可能存在的资料”。但当前设备identity与ESI匹配、GM1/主站工程、扫描、PDO/DC和现场日志均未找到，因此仍不等于当前设备已具备可用EtherCAT路线。工作区没有证据表明EtherCAT被技术排除；其状态是未实施、未放行。

### 4.4 其他确定性控制器

若实验室已有 PLC、运动控制卡或实时工业 PC，可与 STM32、EtherCAT 主站并列比较。全工作区未找到已承诺可借设备、型号或时间窗口；进入条件仍包括设备可用性、开放接口、确定性时间能力、可采集证据、许可成本、安全维护和论文可解释性。不得因“可能已有设备”直接跳过端到端验证。

### 4.5 三轴平台

进入条件：

- 应用任务给出三轴行程、速度、精度、载荷和轨迹指标；
- 三个机械轴和安全回路分别完成单轴放行；
- 建立统一时间基准、空间几何基准和轨迹误差定义；
- 证明三轴扩展能回答单轴无法回答的研究问题。

师兄历史归档确有三轴设计/爆炸/实物图、论文应用叙述、旧定位数据和GM1 2D静态代码；但未找到当前项目的三轴CAD/BOM/装配、当前需求指标、STM32三轴调度或协调多轴运行数据。在这些条件未关闭前，历史材料不能迁移为当前三轴可用性，三轴只属于系统扩展候选，不是单轴研究成立的必要条件。

## 5. 条件增强路线：外部位置环

通过 CANopen CSV 或 EtherCAT CSV 把位置环移到外部控制器，理论上可扩大算法开放度，但当前应归为 `REJECTED_FOR_NOW`，保留为未来条件增强项。

重新评估至少需要：

- 驱动器内部速度、电流环的正式接口和带宽证据；
- 外部光栅尺的确定性采样和与命令周期的同步证据；
- 命令延迟、测量延迟、量化和丢帧的端到端实测；
- 外环离散模型、稳定裕度、约束和故障停机设计；
- 有效 PDO/SYNC 或 EtherCAT 分布式时钟配置；
- 不依赖猜测的 STO、制动器、限位和通信故障处理。

只有当外部位置环回答一个现有内部位置环无法回答、且值得承担风险的研究问题时，才应把它升级为主路线。

## 6. 最小毕业闭环候选

下面是一条可供导师评审的**最小毕业闭环候选**，不是已完成事项：

1. 使用现有商业光栅尺和 DS-BVM 内部单轴位置环；
2. 建立可追溯尺度标定、统一时间语义和可复现实验协议；
3. 得到在限定工况下有效的外部等效模型或参数规律；
4. 对正反向差异完成重复性复核、竞争性原因比较和适用边界说明；
5. 对一种补偿或建模改进使用独立数据验证，或者形成有统计依据的负结果；
6. 把原始数据、处理方法、参数、指标和结论边界连接成可复核论文证据链。

这条闭环的价值来自证据质量和问题回答，而不是控制器数量、总线数量或轴数。

## 7. 路线升级判据

| 分支 | 可升级为论文主线的必要信号 | 暂停或退出信号 |
|---|---|---|
| 自研光栅尺 | 样机、接口、标定和时间证据齐全，且能形成独立测量贡献 | 样机/接口长期不确定，或精度无法独立验证 |
| STM32/CANopen CSP | 当前固件身份、NMT Master、DS对象/PDO、SYNC、CiA 402 和端到端时序均通过只读到受控写入的分级放行 | 仅停留在历史节点/SDO client静态函数或编译记录；安全和维护成本高于收益 |
| EtherCAT CSP | 精确型号与identity/ESI匹配、主站工程、扫描、DC 和实验室资源齐全，多轴价值明确 | 只有物理口、系列ESI或历史GM1静态代码，没有当前现场闭环证据 |
| 三轴 | 应用指标、三轴机械基线、统一时基和轮廓指标同时成立 | 单轴尚未闭环，或三轴没有新增研究问题 |
| 外部位置环 | 内环接口、时延模型、稳定性和安全证据齐全，且开放外环是核心研究需要 | 仅为“更自研”而迁移，无法证明性能或学术收益 |

## 8. 暂定论文结构

1. 问题、平台与证据边界；
2. 位移测量标定、时间语义与实验设计；
3. 单轴外部等效模型或参数规律；
4. 正反向差异的竞争性解释、验证和边界；
5. 补偿/建模方法的独立验证或负结果；
6. 条件扩展（仅纳入实际完成且通过证据门的分支）。

章节 1—5 构成不依赖新总线或三轴平台的核心候选。第 6 章不得用计划替代结果。

## 9. 当前结论

当前最合理候选仍是“现有商业单轴原始运行链路 + 标定与时间语义 + 等效模型/参数规律 + 方向差异因果边界 + 独立验证”。全工作区溯源增强了当前基线，具体下调了STM32遗留资产能力，并确认EtherCAT具有物理口/系列ESI/历史GM1静态资料但尚未现场可用。STM32/CANopen、EtherCAT、自研光栅尺和三轴平台仍是有独立进入条件的并列分支。阶段 FR 到此只修订证据与暂定路线，不启动任何分支实施。
