# 版本与冲突登记表

## 1. 裁决原则

1. 冲突按“适用台架—实验时间—代码/配置版本—证据类型”裁决，不按文件数量或修改时间多数表决。
2. 当前运行记录可替代同一台架的早期猜测，但不能抹除历史事实；历史源码也不能覆盖当前实物。
3. 手册/ESI 对产品能力有效，对当前配置无直接效力；论文/PPT 对作者声明有效，对固件/实物运行无直接效力。
4. `motion_acquisition` 的 manifest 没有 git commit（`git_commit=null`），因此当前运行只能绑定包版本 `0.2.0`、命令、配置和文件时间，不能绑定提交哈希。

## 4. 版本裁决后的四条稳定表述

1. **当前事实：**2026-07-12 的商业单轴采用 Servo Studio USB/COM 发运动、PC USB-CAN/Python 对 Node 1、1 Mbps 做 SDO upload；运动与采集已有配对原始数据。
2. **历史资产：**师兄归档同时含 H743/H750 多工程、一次 H743 成功编译、论文/答辩/运动台数据和 GM1 2D 上位机代码；没有能闭合 STM32 主站—DS-BVM—三轴实物运行的证据。
3. **EtherCAT边界：**当前接口板可见ECAT口，工作区有系列ESI和历史GM1资料；当前设备身份、匹配ESI、主站工程及现场运行仍为空。
4. **未闭合外部条件：**自研尺一级资料、当前外部长度标定、当前三轴需求/机械、可借实时控制器和完整安全配置仍未找到或仅部分支持。
