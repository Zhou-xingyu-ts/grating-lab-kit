# 阶段F状态修正

## 1. 修正结论

阶段F不再被视为最终路线裁决。其准确状态改为：

> **基于当前有限证据形成的开题主线候选稿和学习组织稿。**

阶段F原8份文件保持原样，作为一次阶段性收束的可追溯记录；阶段FR不删除、不覆盖它们。本文件及阶段FR其他文件对其“定型、冻结、最终、创新”措辞作上位勘误。

## 2. 为什么必须降级

阶段F正确整理了当前F1+C0事实、标定/时间语义和证据边界，但把若干彼此独立的外部依赖串成了近似必然的毕业链：自研光栅→STM32+CSP→三轴同步/轮廓。核心交接证据并不支持这种必然性：

- 当前只有F1+C0商用光栅单轴内部位置闭环是实物事实；CANopen写控制、PDO、SYNC、CSP均未在当前台架验证。
- DS-BVM手册能证明模式和接口能力，不能证明当前型号/固件、配置、周期、同步误差或现场安全已经满足。
- 遗留STM32只有1 ms定时、RTOS和CANopenNode节点骨架；没有NMT主站、有效PDO映射、DS-BVM CiA 402链、三轴调度或控制算法。
- 自研光栅的接口、完成度和可用日期未知；三轴机械、应用场景和目标指标未知。
- 有限文献反查显示，负载侧反馈、滚珠丝杠摩擦/换向补偿、EtherCAT/CANopen同步、轮廓误差和交叉耦合均有成熟先例，阶段F四项“可能创新”不能仅靠内部推演成立。

## 3. 逐项措辞修正

| 阶段F措辞 | 阶段FR修正 | 原因 |
|---|---|---|
| 架构定型 | 架构分类框架与候选集 | F/C二维分类有用，但不能排除工控机/EtherCAT或其他确定周期控制器 |
| 冻结后的论文主线 | 暂定分层研究路线 | 自研尺、CSP和三轴不存在必然先后或可用性保证 |
| 毕业主线按F1+C1闭合 | F1+C1是条件性系统扩展 | 当前PDO/SYNC、主站、周期、安全均未闭合；最小论文闭环可停留在F1+C0单轴 |
| 自研光栅替换 | 自研光栅条件性接入与对照 | 可用时间、接口、性能和兼容性均需外部信息 |
| STM32+CSP周期轨迹 | 一种候选周期位置目标实现 | 遗留资产不能证明主站成熟，也不能证明相对EtherCAT/其他控制器最优 |
| 三轴同步与轮廓为末级必达 | 条件性多轴扩展 | 三轴机械、应用价值、统一时基和每轴条件均未确认 |
| 四项可能创新 | 四项待文献和实验共同证成的贡献假设 | 组成要素已有大量先例；必须证明具体差异、效果和适用边界 |

## 4. 仍可保留的阶段F成果

以下内容经反证后仍成立，但需避免“最终”措辞：

1. F/C两个维度能清楚区分反馈闭环位置与命令/协调方式。
2. 当前台架可称F1+C0商用光栅单轴基线；它既是对照，也可能成为最终实施范围。
3. 正式count—位移标定、事件级时间语义和证据等级是任何物理性能主张的共同前提。
4. 方向差异只能先称现象或等效项，不能自动命名为摩擦。
5. 合成模型、源码存在、手册能力和真实台架验证必须分层。
6. F2+C2外位置环在关键安全和反馈条件未闭合时不进入实施。

## 5. 新的决策口径

阶段FR只回答三件事：当前什么最可信、哪些扩展值得保留、每项扩展何时才允许进入。它不替导师/用户作采购和最终架构决定。

- **已冻结基础：**当前F1+C0事实、正式标定需求、时间语义需求、证据边界。
- **强候选近期主线：**无需新增核心控制硬件即可推进的单轴标定、等效动态与方向误差研究。
- **条件性系统扩展：**自研尺、STM32/CANopen CSP、EtherCAT CSP、其他周期控制器、三轴同步/轮廓分别独立设门。
- **条件增强：**F2+C2或EtherCAT CSV外位置环，当前不实施。
- **最小毕业闭环：**商用光栅F1+C0下完成可追溯标定、局部等效建模、方向现象的可证伪分析及一项经留出验证的误差处理/参数规律；这是候选完成定义，不代表已经完成。

## 6. 阶段F的后续使用规则

- 可继续使用其学习组织、证据边界、标定和时间语义表述。
- 引用其路线时必须同时引用阶段FR的新分类和进入条件。
- 不再直接复制“最终研究主线”“冻结后的七级推进链”“毕业主线按F1+C1闭合”等句子到开题材料。
- 四项创新只能写成“待反查和实验验证的贡献假设”，不能写成已确认创新。
