# 开题问题—目标—内容—创新链

## 1. 工程问题

现有Z轴平台已能在商用驱动器内部位置环下完成运动，但负载侧位移尺度尚未正式标定，动态与方向差异缺少可辨识、可复现的证据链；从上位机参数化点到点升级到实时周期轨迹和三轴协调时，还面临时基、通信生效语义、单轴误差向轮廓误差传播以及安全责任边界不清的问题。

## 2. 控制问题

在不假设商用驱动器内部算法已知的条件下，需要：

1. 建立可追溯的负载侧位移测量与统一数据/时间语义；
2. 以外部输入—输出等效模型描述限定工况下的单轴动态，并区分可独立辨识量与组合量；
3. 建模方向、位置、速度等条件相关的重复误差，形成有留出验证的补偿；
4. 在保持驱动器内部位置环的F1拓扑下，将命令层从C0升级到C1，研究周期轨迹和多轴同步；
5. 将轴向跟踪误差映射到几何轮廓误差，形成可比较的协调控制评价方法。

## 3. 可检验的研究问题

| 编号 | 研究问题 | 可检验方式 | 不能越过的解释边界 |
|---|---|---|---|
| RQ1 | count—位移映射在行程、方向、温度和装夹条件内是否稳定？ | 外部基准、多点双向重复、独立验证点和不确定度预算 | count步长不等于绝对精度 |
| RQ2 | 黑箱单轴在限定工况下需要何种最低阶等效动态才能预测未参与拟合的轨迹？ | 多幅阶跃/持续激励训练，冻结参数后用异类轨迹验证并检查残差 | 不反推未经证实的驱动器内部结构 |
| RQ3 | 观察到的正反向差异能否形成跨重复、位置和速度稳定的误差映射？ | 随机化方向、同条件重复、改变速度/负载/线缆条件做对照 | 方向项不自动等同摩擦 |
| RQ4 | 方向相关补偿能否在留出点和留出轨迹上降低误差，而不恶化反向或换向核心段？ | 冻结映射，对独立工况比较RMS、峰值、稳态、回程和换向指标 | 空核心段或不可比工况报告N/A |
| RQ5 | F1+C1相对F1+C0能否提供可量化的周期轨迹与同步能力？ | 记录计划、发送、总线和反馈事件，比较抖动、漏更新、跟踪和重复性 | 主机时间戳不等于驱动器锁存/生效时刻 |
| RQ6 | 三轴单轴误差、同步误差和几何轮廓误差之间如何关联，何种协调方法在约束内有效？ | 每轴先验收，再以统一参考轨迹比较独立轴控制、同步/交叉耦合控制 | 未有三轴机械和外部参考前只做理论定义 |
| RQ7 | 自研光栅替换后，系统级结果与商用光栅相比发生何种变化？ | 相同机械、控制、轨迹和外部基准下重新标定并对照 | 标称分辨率不能替代系统级测量 |

## 4. 论文目标

提出并验证一套面向光栅反馈精密运动平台的分层方法：以可追溯位移标定为尺度基础，以局部等效辨识和方向误差补偿为单轴核心，以统一时基的周期位置目标为实时升级，并以同步误差和轮廓误差为三轴评价对象；所有参数、性能和适用域均由训练—验证分离、事件级时间语义和明确风险回退支撑。

## 5. 研究内容

1. F1+C0商用光栅单轴平台的坐标、数据、标定与基线实验规范。
2. 黑箱条件下的等效动态结构选择、参数可辨识性分析和留出轨迹验证。
3. 方向相关误差的条件分解、映射模型、补偿策略和失效域判定。
4. 自研光栅接口确认、独立标定与同条件替换对比。
5. F1+C1的STM32+CSP周期轨迹、PDO/SYNC时间合同、约束和异常保持策略。
6. 三轴坐标与参考轨迹、同步误差/轮廓误差定义、协调控制及实验对照。
7. 条件允许时研究F2+C2外部位置环；否则保留为后续扩展，不影响主线闭合。

## 6. 可能创新点

下列创新均以最终实验结果为准，开题阶段使用“拟研究/可能形成”：

1. **证据约束的分层建模—标定方法。**把位移尺度、事件时间语义、结构/实际可辨识性和留出验证纳入同一证据链，避免把商用驱动器黑箱内部参数、通信延迟和机械误差错误分解。
2. **面向换向与条件变化的误差建模补偿方法。**不把方向差异先验归因于单一摩擦，而是在方向、位置、速度及工况对照下建立可证伪映射，并用匹配核心段和独立轨迹评价收益与失效域。
3. **从单轴等效误差到三轴轮廓误差的统一验证方法。**在F1反馈拓扑不变的前提下，以CSP统一时基连接单轴标定/模型与多轴同步/轮廓评价，区分单轴跟踪、轴间同步和几何轮廓三类误差来源。
4. **自研光栅的系统级可替换验证。**在同一机械、控制、外部基准和数据合同下与商用光栅对照，给出可追溯性能差异及适用边界，而非仅比较分辨率指标。

PID、CANopen、三轴机构和高分辨率器件本身不作为创新；只有由上述方法得到、可重复且可证伪的系统结论才构成论文贡献。

## 7. 技术路线

**F1+C0单轴安全基线 → 正式标定 → 输入/输出与时间合同 → 等效动态辨识及留出验证 → 方向相关误差映射与补偿 → 自研光栅同条件替换 → F1+C1周期位置目标与时序验证 → 三轴同步和轮廓误差控制。**

理论分析、离线代码和合成数据在返校前完成；物理参数、性能数字和路线放行必须由返校后的真实实验给出。

## 8. 风险与回退

| 风险 | 影响 | 回退策略 |
|---|---|---|
| 外部高精度位移基准暂不可用 | 不能形成绝对精度和正式count—位移结论 | 先保留counts域和低成本量级核验；不发布精度，等待借用/采购基准 |
| 输入带宽或采样率不足 | 动态参数相关、延迟与时间常数混淆 | 报告组合量/候选集，缩小模型有效域，不强行唯一辨识 |
| 方向差异不稳定或因果不明 | 补偿不可泛化 | 保留现象统计和对照实验，停止物理归因；论文贡献转为误差边界与验证方法 |
| 自研光栅延期或接口不明 | 替换对照推迟 | 商用光栅完成全部单轴方法链；自研器件列为待接入验证，不虚构结果 |
| CSP/PDO/SYNC条件未闭合 | 不能实施F1+C1或证明实时性 | 先冻结协议和离线轨迹；保留F1+C0完成单轴论文证据，返校后逐门验证 |
| 三轴机构/行程/外部参考不足 | 无法做完整空间轮廓实验 | 从双轴平面轨迹或三轴时间同步指标起步，明确降级范围，不声称完整三轴轮廓能力 |
| F2+C2安全或反馈条件不满足 | 外部位置环不能实施 | 不进入该路线；毕业主线按F1+C1闭合 |
