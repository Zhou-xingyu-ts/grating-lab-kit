# 六周用户学习工作簿

> 目标：在不依赖台架的六周内，补齐开题答辩和返校实验设计所需的控制、辨识与多轴基础。每周的自测题先独立作答，再到文末核对答案要点；不要边看答案边做题。

## 使用方法

每周按“概念梳理→手推公式→平台映射→自测→论文推导→只读代码练习→形成报告制品”完成。只读代码练习允许阅读、画调用链、手算和写旁注，不运行、不修改程序，也不连接硬件。建议每周保存一页推导、一张图和一个可直接放进导师汇报的制品。

## 第1周：三环伺服与控制权

### 必会概念

电流/转矩环、速度环、位置环；带宽分离；串级控制；传感器位置与控制权；内部位置环和外部位置环；CSP/CSV的功能边界；黑箱等效模型。

### 必须能解释的公式

1. 位置外环的最简速度命令：$u_v=K_p(r-y)$，说明$K_p$为何是$1/s$。
2. 等效速度子系统：$\dot v=(K_vu_v-v)/\tau_v$，说明$K_v$和$\tau_v$分别控制什么。
3. 串级闭环：$T(s)=C_p(s)G_v(s)/[1+C_p(s)G_v(s)]$，指出测量点、命令点和控制权。

### 映射到当前平台

- F1+C0：光栅进入DS-BVM，驱动内部闭合位置环，Servo Studio给点到点/参数化轨迹。
- F1+C1：仍由DS-BVM闭合位置环，STM32以CSP周期发送位置目标。
- F2+C2：STM32读取独立负载侧光栅并闭合位置环，以CSV给DS-BVM速度目标；仅为条件增强。

### 自测题

1. 为什么F1+C1不是新的反馈拓扑？
2. CSP和CSV分别把哪一级控制权留在驱动器、交给外部控制器？
3. 若只有目标位置和实际位置，为什么不能反推出驱动器内部三个环的全部参数？
4. F2+C2在失联时比F1+C1多承担了什么安全责任？

### 一篇论文推导任务

选一篇“串级伺服/负载侧反馈”论文，只复现其框图到闭环传递函数的推导：标出每个反馈传感器、控制器、被控对象和扰动入口；再把论文框图改写成F1与F2两版，列出哪些内部环在本项目中不可见。

### 只读代码练习

阅读D1的B、D模型入口，画出`reference → controller → constrained command → delayed/applied command → plant → delayed measurement`调用链；找出anti-windup使用的是本地限幅输出，而非延迟后的对象输入。

### 本周报告制品

一张“F/C二维架构与控制权”图，能直接放进开题PPT，图下注明当前、主线升级和条件增强。

### 脱离硬件完成判据

能在5分钟内不看资料画出F1+C0、F1+C1、F2+C2三张框图，并准确解释每个环由谁闭合、为什么旧D不是独立反馈路线。

## 第2周：离散控制、采样与延迟

### 必会概念

采样、保持、ZOH、离散积分、量化、整数/非整数延迟、测量延迟与命令延迟、抖动、deadline、时钟域和事件时间戳。

### 必须能解释的公式

1. ZOH离散化：$x_{k+1}=e^{AT_s}x_k+\int_0^{T_s}e^{A\tau}B\,d\tau\,u_k$。
2. 纯延迟的频率响应：$e^{-j\omega dT_s}$，说明其相位为何随频率线性下降。
3. 周期抖动：$j_k=t_{start,k}-t_{scheduled,k}$，以及P95/P99与平均周期的区别。
4. 实际轮次率：$f=(N-1)/(t_{N-1}-t_0)$。

### 映射到当前平台

现有SDO同轮对象是顺序读取，共享轮次入口时间，不能称同步采样。未来F1+C1必须区分计划时刻、计算完成、命令提交、总线帧、驱动目标生效、传感器锁存和反馈可用。

### 自测题

1. 同一`cycle_id`下的两个SDO对象为什么不一定对应同一物理时刻？
2. 平均循环1 ms为什么不能证明最坏情况下1 kHz硬实时？
3. 测量延迟$d_y$和命令延迟$d_u$各自需要哪些事件证据？
4. 为什么命令历史默认零与“重复第0拍命令”在非零初始目标时不同？
5. ZOH模型能说明外部目标保持，但为什么不能证明驱动内部插值算法？

### 一篇论文推导任务

选一篇网络化/采样控制论文，从连续一阶或二阶对象推导含一拍命令延迟的离散状态方程；手推无延迟与一拍延迟的特征方程，并解释稳定裕度变化。

### 只读代码练习

阅读D1延迟历史和阶段E时间合同，手工列出前5拍的`source_index`、`u_tx`、`u_applied`和测量来源，分别使用零历史与非零可配置历史；不运行代码。

### 本周报告制品

一张“计划—计算—发送—生效—锁存—可用”的事件时序图，并附当前SDO能证明/不能证明清单。

### 脱离硬件完成判据

能手推一阶系统ZOH更新，解释整数延迟的显式历史语义，并设计至少6个时间字段而不把主机时间冒充设备时间。

## 第3周：系统辨识与可辨识性

### 必会概念

结构可辨识性、实际可辨识性、持续激励、训练/验证分离、模型阶次、残差、自相关、参数相关、组合可辨识、局部有效域。

### 必须能解释的公式

1. 最小二乘：$\hat\theta=(\Phi^T\Phi)^{-1}\Phi^Ty$及$\Phi^T\Phi$病态的含义。
2. 一阶频响：$G(j\omega)=K/(1+j\omega\tau)$，说明低频输入为何难辨识$\tau$。
3. 延迟与时间常数相位：$\angle G=-\arctan(\omega\tau)-\omega dT_s$。
4. B模型中的$F/M$，说明为什么没有独立质量或力证据时二者不能分开。

### 映射到当前平台

正式标定前，count尺度会与控制增益混淆；只有位置参考—反馈时，$d_y$、$d_u$和部分动态只能表现为总延迟。A/F1+C0先做外部等效模型；D1/E合成恢复只验证方法，不是台架参数。

### 自测题

1. 结构可辨识与实际可辨识的失败各举一个当前平台例子。
2. 为什么一条很慢、很平滑的S曲线不足以唯一辨识二阶动态？
3. 训练RMSE最低为什么仍可能给出错误延迟和时间常数？
4. 残差与输入显著相关通常说明什么？
5. 什么情况下应报告组合量、区间或N/A，而不是一个最优数值？

### 一篇论文推导任务

选一篇一阶/二阶伺服系统辨识论文，复现回归矩阵或频域估计式；列出其输入频带、采样率、训练/验证拆分和参数置信方法，再判断这些条件能否直接迁移到当前SDO数据。

### 只读代码练习

阅读阶段E参数矩阵，为`count比例、Kv、tau_v、dy、du、KD_dc、omega_n、zeta、方向项`逐一标注“独立/组合/不可辨识”，并写出让等级提升所需的最小新增字段或实验。

### 本周报告制品

一页“参数—激励—输出—混淆—验证”矩阵，作为开题方法可行性和返校实验输入表。

### 脱离硬件完成判据

## 第4周：轨迹规划、前馈与约束

### 必会概念

梯形/S曲线、位置/速度/加速度/jerk连续性、速度和加速度前馈、限幅、速率限制、anti-windup、可行轨迹、C0参数轨迹与C1周期目标。

### 必须能解释的公式

1. $v_{k+1}=\operatorname{clip}(v_k+a_kT_s,\pm v_{max})$。
2. $u=K_pe+K_i\sum eT_s-K_d\hat v+K_{ff,v}v_r+K_{ff,a}a_r$及各项量纲。
3. 回算式anti-windup：$\dot I=e+K_{aw}(u_{con}-u_{raw})$，说明为什么使用本地约束输出。
4. 路径时间缩放关系：$\dot q=q'(s)\dot s$，$\ddot q=q''(s)\dot s^2+q'(s)\ddot s$。

### 映射到当前平台

C0的Velocity/Acceleration/Deceleration/Jerk由驱动器参数化轨迹产生；C1必须由STM32生成满足周期、量化、速度/加速度/jerk和行程约束的位置目标。两者对比需使用同一路径和明确可实现约束。

### 自测题

2. 速度前馈和加速度前馈分别补偿什么类型的滞后？
3. anti-windup为什么应比较`u_con`与`u_raw`，而不是延迟后的`u_applied`？
4. 一条几何路径满足行程限制，为什么仍可能不是动态可行轨迹？
5. 比较C0与C1时必须冻结哪些条件？

### 一篇论文推导任务

选一篇S曲线或时间最优轨迹论文，推导一个对称点到点轨迹各阶段的时间、位移和峰值速度关系；再加入本项目的速度、加速度、jerk和小行程限制，写出可行性检查顺序。

### 只读代码练习

### 本周报告制品

## 第5周：方向相关误差与补偿

### 必会概念

回程误差、重复性、方向条件、换向瞬态、稳态核心段、位置/速度条件映射、重力/间隙/拖链/换相混淆、因果对照、前馈补偿与查表验证。

### 必须能解释的公式

1. 方向统一超调：$M_p=\max[0,\max_k\{d(x_k-r_f)\}]$，$d=\operatorname{sign}(r_f-r_0)$。
2. 回程差：$e_h(x)=\bar y_+(x)-\bar y_-(x)$。
3. 条件误差映射：$e=\phi(x,v,d,\text{condition})+\epsilon$。
4. 补偿留出收益：$\Delta J=J_{before,test}-J_{after,test}$。

### 映射到当前平台

现有材料只支持“观察到方向差异”，不能直接命名为摩擦。正式实验必须在相同位置/速度下双向重复、随机化顺序，并记录负载、温度、线缆姿态和时间对齐；换向正反核心段不能形成匹配时指标写N/A。

### 自测题

2. 什么实验能区分方向项与随时间温漂？
3. 为什么在训练点误差降低不能证明查表补偿有效？
4. 正反向核心段不匹配时，为何应返回N/A而不是0？
5. 如何避免把线缆拖曳或重力误写成库仑摩擦？

选一篇摩擦/回程/轮廓误差补偿论文，复现其误差状态或补偿律；把“物理摩擦参数”和“数据驱动方向等效项”分栏，指出当前平台需要哪些附加实验才可采用物理命名。

## 第6周：多轴同步与轮廓误差

### 必会概念

共同参数时间、轴向跟踪误差、同步误差、轮廓误差、切向/法向分解、最近点投影、交叉耦合控制、轴间约束、坐标标定和统一时基。

### 必须能解释的公式

1. 参考路径$q_r(s)=[x_r(s),y_r(s),z_r(s)]^T$及轴向误差$e=q_r-q$。
2. 局部法向轮廓误差近似：$e_c\approx n^Te$（平面路径）或法平面投影$e_c=(I-tt^T)e$。
3. 同步误差示例：$e_{ij}=\alpha_ie_i-\alpha_je_j$。
4. 交叉耦合控制：$u_i=C_i e_i+C_{c,i}e_c$，说明单轴稳定与耦合稳定需分别检查。

### 映射到当前平台

F1+C1提供统一周期位置目标的协调层，但不自动保证三轴同步。每轴必须先完成方向、尺度、动态和安全验收；三轴机械行程、坐标变换、目标轨迹和外部参考未确认前，只能做理论与数据合同准备。

2. 轮廓误差与同步误差有什么区别？
3. 为什么三轴实验前必须每轴单独通过标定和安全门？
4. 圆轨迹局部法向如何由切向量得到？
5. 若只有主机发送时刻，没有各驱动锁存/反馈时刻，能证明什么、不能证明什么？

### 一篇论文推导任务

选一篇轮廓误差估计或交叉耦合控制论文，从参数曲线推导局部切向、法向和轮廓误差；用圆或空间螺旋作一个手算点，并列出该方法在曲率突变/最近点不唯一时的失效条件。

# 自测题答案要点（完成题目后再看）

## 第1周

1. F1+C1没有改变光栅进入DS-BVM及驱动器内部位置闭环，只改变目标生成和发送方式。
2. CSP通常保留驱动器位置/速度/电流环；CSV把位置环交给外部，但速度/电流环仍在驱动器。
3. 外部输入输出只给等效闭环，内部环参数存在多组等价分解。
4. 外部位置环需自行处理测量失效、命令限幅、失联、稳定和停止，并与STO/制动/限位协调。

## 第2周

1. 顺序SDO的请求/响应时刻不同，设备内部采样时刻也未知。
2. 平均值掩盖P99、连续超期和最坏时延，Windows主机时间也不是硬实时证明。
3. $d_y$需锁存/反馈可用/控制采用事件；$d_u$需计算/发送/总线/驱动生效事件。
4. 零历史表示对象在延迟窗内接收零；重复第0拍会把尚未生效的新命令提前施加。
5. 外部ZOH只定义发送序列，驱动内部可保持、插值或另行滤波，需总线和高率响应证据。

## 第3周

1. 结构失败如$F$与$M$只以$F/M$出现；实际失败如输入远低于二阶拐点，$\omega_n/\zeta$多组近似等价。
2. 频带和变化阶次不足，主要暴露直流增益，动态/延迟可互相补偿。
3. 训练误差可由错误延迟、额外自由度或过拟合降低，必须看留出轨迹和残差。
4. 说明仍有输入相关动态、非线性、延迟或预处理错误未解释。
5. 独立辨识条件、单位、时间语义、SNR或匹配核心段不满足时。

## 第4周

1. jerk主要影响过渡激励，最终误差还受闭环、摩擦/回程、积分、量化和等待判据影响。
2. 速度前馈补偿随速度的跟踪滞后，加速度前馈补偿惯性/加速度需求；实际含义取决于对象。
3. anti-windup修正本地控制器饱和差；命令延迟不是本地执行器饱和，会错误改变算法语义。
4. 还可能违反速度、加速度、jerk、带宽、周期和安全限制。
5. 机械/传感器、路径、初态、行程、动态约束、标定、工况、时间语义和评价窗口。

## 第5周

1. 负向越过目标时$actual-final$为负，必须用运动方向统一符号。
2. 随机化方向顺序、交错重复并记录时间/温度，可破除方向与时间的共线。
3. 可能只是记住训练点；必须冻结补偿后在留出位置、轨迹或日期验证。
4. 0会被误读为“无误差”，N/A才表达指标没有定义域。
5. 改变姿态、负载、线缆约束等做因果对照；证据不足只称方向等效项。

## 第6周

1. 各轴误差方向组合可能主要投影到路径法向，即使单轴幅值小也会偏离轮廓。
2. 同步误差描述轴间时间/比例关系；轮廓误差描述实际点到几何路径的偏离。
3. 未标定或不安全的单轴会把尺度、方向和故障带入耦合系统，无法解释结果。
4. 由单位切向$t$构造法向；平面可旋转90°，空间使用法平面投影$I-tt^T$。
5. 可证明主机计划/发送相对时序；不能证明驱动锁存、设备同步、反馈同相或硬实时最坏界。
