## 1. 通用安全前置

- [ ] 限位、STO、Quick Stop、刹车、heartbeat/失联策略按路线验证
- [ ] 主电源/控制电/共地/编码器/相序等适用项有当前证据
- [ ] 明确正常停止、异常停止和断电顺序

- [ ] 先做静止采集和低风险方向确认
- [ ] 任一错误码、异常噪声、不可解释方向、时间戳倒退或跟随误差超阈值立即停止

## 2. 正式标定准备

- [ ] 外部基准类别、校准状态、量程和不确定度已记录
- [ ] 光路/探头与运动轴对准，阿贝臂和余弦误差可估
- [ ] 预热开始/结束、温度、气压/湿度（适用时）、负载、线缆姿态已记录
- [ ] 正方向有实物和软件双重标记
- [ ] 原始counts和外部位移都保留，不覆盖原始列
- [ ] 训练点与独立验证点预先分开

## 3. count—位移标定执行

- [ ] 零点首测
- [ ] 至少11个覆盖行程的位置点
- [ ] 每点正向到达≥5次、反向到达≥5次
- [ ] 正反向序列随机化/交错，统一等待判据
- [ ] 零点末测并计算漂移
- [ ] 分别拟合正向、反向、合并线性模型
- [ ] 报告斜率、截距、残差、回程、重复性和不确定度
- [ ] 冻结映射后检查独立验证点
- [ ] 写明count—mm映射的方向、位置、温度、负载和安装适用范围

## 4. 时间合同检查

- [ ] `cycle_start_ns`和`scheduled_cycle_start_ns`均记录
- [ ] 每对象`request/response/feedback_available`时刻均记录；缺失不伪造
- [ ] `command_compute_ns/command_tx_ns`按实际层级记录
- [ ] `object_sequence_in_cycle`明确
- [ ] 实际轮次率按首末`cycle_start`计算
- [ ] 起点迟到、完整轮次miss、对象deadline分别统计
- [ ] 周期抖动给出均值、RMS、P95、P99和最大值
- [ ] 同轮SDO对象只称顺序读取，不称同步采样
- [ ] PDO/SYNC实验另有总线时间戳和时钟映射

## 5. A路线辨识顺序

- [ ] 静止噪声/漂移基线
- [ ] 小幅双向阶跃，多幅、每幅≥5次
- [ ] 五次S曲线至少两种时长
- [ ] 恒速正反向至少3个速度，每方向≥5次
- [ ] Velocity/A/D/J单变量或因子化设计，随机顺序
- [ ] 安全和采样率允许后才扩展多正弦/扫频/PRBS
- [ ] 完整实验段拆分训练/验证
- [ ] 方向误差只报告现象，因果需姿态/负载/线缆对照

## 10. 停止条件

任何安全门未通过、外部基准失效、时间合同关键字段缺失、目标/反馈方向不一致、异常跟随误差、失联、错误码、不可解释振动/噪声或停止路径不可靠时，立即停止，不通过“降低阈值继续跑”绕过。
