# A/B/D参数可辨识性矩阵

> “可辨识”是指在给定模型结构、输入、输出、时间语义和实验带宽下，数据能否把参数唯一或足够稳定地分开。E1表示现有台架证据，E2表示当前源码/文档证据，H表示假设，R表示待辨识。合成数据只验证方法，不提升真实参数证据等级。

## 2. 六个必须固定的判断

1. **$M$与方向残余力：**D1 B方程中的数据作用项是$F/M$。合成案例用$(0.10\,N,0.8\,kg)$和$(0.20\,N,1.6\,kg)$得到逐样本完全相同输出；没有独立质量或力证据时只能报告等效加速度，不得分别给出精确$F$和$M$。
2. **$K_v$与`Kp_pos`：**若只记录外部位置参考和实际位置，闭环尺度可被`Kp_pos`、$K_v$、count—m比例共同改变。要分开$K_v$，必须知道实际送入速度子系统的命令尺度并完成位置标定；否则只报告组合闭环增益。
3. **只有位置记录的$d_y$与$d_u$：**不能独立分离。闭环位置响应通常只暴露总相位/总延迟；必须增加测量可用事件和命令发送/总线到达/对象生效事件。
4. **$\tau_v$与总延迟：**都增加相位滞后和上升时间。低带宽合成案例中真实$\tau_v=35$ ms、延迟3拍，却由6拍、约8.0 ms和5拍、约10.5 ms两组候选取得仅3%差异的一步RMSE，说明“最优”不等于可靠分离。
5. **`KD_dc`、$\omega_n$、$\zeta$：**宽带无噪声合成数据可唯一恢复；0.08/0.18 Hz输入远低于20 Hz固有频率时，20 Hz/$\zeta=0.8$与35 Hz/$\zeta=1.1$候选在约1.00/1.24 μm RMSE下都能拟合，参数不能宣称唯一。
6. **方向差异：**现有E1只证明现象。重力、间隙、线缆拖曳、换相、负载、控制器记忆和时间对齐误差都能产生方向项；需改变姿态/负载/线缆约束并随机化方向顺序，才能逐步作因果区分。

## 3. 报告规则

- 独立辨识条件未满足时，报告组合量、区间、候选集或N/A。
- 参数置信度必须同时考虑结构唯一性、实际SNR、输入带宽、时间戳和留出验证。
- 训练误差小但留出误差大，或残差与输入相关，视为模型不足，不用调参掩盖。
- 合成恢复只证明代码在受控真值下能工作，不把真值或估计值写成台架参数。
