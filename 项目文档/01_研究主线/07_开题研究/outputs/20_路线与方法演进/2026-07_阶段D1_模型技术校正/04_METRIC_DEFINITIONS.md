# 轨迹分型指标定义

## 1. 通用定义

设$e[k]=r[k]-y[k]$，轨迹行程尺度：

$$L=\max(r)-\min(r)$$

所有轨迹输出：

$$e_{max}=\max|e[k]|$$

$$e_{RMS}=\sqrt{\frac{1}{N}\sum e[k]^2}$$

$$e_{max,n}=e_{max}/L,\qquad e_{RMS,n}=e_{RMS}/L$$

CSV同时保留物理单位μm和无量纲归一化误差。$L$来自H轨迹，不是正式标定长度。

## 2. 点到点轨迹

轨迹生成结束时刻$t_e$由轨迹元数据给出，不通过输出反推。

| 指标 | 定义 |
|---|---|
| 到位误差 | $e(t_e)$，即参考轨迹刚结束时的误差 |
| 轨迹结束后稳定时间 | 从$t_e$起，输出最后一次离开`max(2%行程, 2 μm)`带之后的时间；仿真窗内未稳定为N/A |
| 超调 | $t\ge t_e$后超过最终目标的最大有向位置量：$\max\{0,\max[d(x-x_f)]\}$，$d=\operatorname{sign}(x_f-x_0)$ |
| 保持段平均误差 | $t\ge t_e$的误差均值，用于检查统计窗和慢卸载 |
| 最大/RMS跟随误差 | 全轨迹通用定义 |

不再把“从仿真开始到最终目标的稳定时间”用于S曲线，也不把最后15%均值单独称为稳态精度。

## 3. 恒速扫描

恒速核心区间由`scan_core_start`和`scan_core_end`定义，排除加减速段。

| 指标 | 定义 |
|---|---|
| 平均跟随滞后 | 核心段$\operatorname{mean}(e)$，保留正负号 |
| 扫描RMS误差 | 核心段$\sqrt{\operatorname{mean}(e^2)}$ |
| 速度波动 | 核心段真实模型速度的标准差 |
| 速度RMS误差 | 核心段参考速度与模型速度之差的RMS |

速度波动单位为μm/s；它只描述模型状态，不等于真实测速带宽。

## 4. 换向轨迹

换向时刻$t_r$和窗口半宽0.12 s来自轨迹元数据。

| 指标 | 定义 |
|---|---|
| 换向窗口最大误差 | $[t_r-0.12,t_r+0.12]$内$\max|e|$ |
| 恢复时间 | 从$t_r$后第一次连续50 ms进入`max(2%行程, 2 μm)`误差带所需时间；未恢复为N/A |
| 正反向误差幅值差 | 在正/反向各自速度≥峰值80%的匹配核心段，比较两段平均有符号误差的绝对值差 |
| 正/反向有符号均值 | 分别保留，防止幅值差掩盖误差方向 |
| 滞回面积 | 将正/反向误差按同一参考位置插值，积分$\int|e_+(x)-e_-(x)|dx$，单位μm² |

方向幅值差刻意排除低速起步、换向窗口和停留，以减少控制器历史/瞬态对“方向参数不对称”的污染；换向瞬态由独立窗口指标报告。极限测试在$F_c^+=F_c^-$、无积分记忆、无延迟/噪声时验证该指标接近零。

若速度阈值筛选后无法同时形成正向和反向核心段，则正/反向有符号均值、幅值差和滞回面积统一返回NaN/N/A，不对空数组求均值或极值。

## 5. 约束与anti-windup附加指标

所有B结果额外输出：

- 未饱和命令峰值；
- 速度限幅后命令峰值；
- 加速度约束后实际外部命令峰值；
- 命令延迟后对象输入峰值；
- 速度饱和比例；
- 加速度约束比例；
- 积分冻结比例；
- 积分状态峰值。

因此PI/PID结果必须同时说明是否发生约束，不能只报告误差。

## 6. D附加指标

D结果额外输出成功目标更新数、漏更新数、漏更新占计划更新比例和对象实际目标峰值。D不输出B控制器的饱和/积分字段。

## 7. N/A规则

- 某轨迹不适用的指标不创建该字段，而不是填入有误导性的数值；
- 仿真窗内未满足恢复/稳定条件时写NaN/N/A；
- NaN表示定义条件未满足，不表示脚本失败；
- B与D命令单位不同，不用“控制输入峰值”互相排名。
