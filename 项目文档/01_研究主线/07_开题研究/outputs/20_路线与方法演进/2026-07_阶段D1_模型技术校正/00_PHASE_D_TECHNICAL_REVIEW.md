# 阶段D最小模型V0定点技术审查

> 审查范围仅限`2026-07_阶段D_研究主线与模型V0/`中的指定模型、控制器、指标、脚本、测试和交接文档。未重新审计阶段A—C，未扫描工作区其他资料，未扩展研究方向。

## 1. 审查结论

阶段D的研究边界、安全守卫、E/L/R/H证据意识和A/B/D条件化路线可以保留，但模型V0存在会影响数值解释的结构性问题。旧代码仍作为阶段D原始版本保存；D1在新目录中给出校正版本V0.1。阶段D旧仿真的绝对数值和基于旧模型的参数趋势不再作为后续技术依据。

## 2. 问题与处置

| ID | 阶段D问题 | 影响 | D1处置 |
|---|---|---|---|
| TR-01 | B同时写一阶速度环与机械方程，并在等效控制力中加入`+Bv`，与机械方程`-Bv`完全抵消 | `viscous_n_s_m`看似参与模型，实际对结果无作用；质量/摩擦解释易被误读 | 删除B参数，直接使用`x_dot=v`、`v_dot=(Kv*u-v)/tau-(Ff+Fd)/M` |
| TR-02 | 一个`communication_delay_steps`同时代表测量、计算、PDO命令和驱动生效 | 无法分别验证光栅链和命令链；可能把命令延迟误实现为测量延迟 | B分为`measurement_delay_steps=d_y`与`command_delay_steps=d_u`，并记录各自源索引 |
| TR-03 | 速度/加速度前馈系数由手工H值给出，未从速度模型推导 | 前馈缺少维度与模型对应关系 | 从`tau_v*v_dot+v=Kv*u`推导`Kff_v=1/Kv`、`Kff_a=tau_v/Kv`，仍标H/R理论初值 |
| TR-04 | 积分器只有固定状态限幅，没有根据实际速度/加速度约束做anti-windup | 饱和时可能继续积累；无法判断PI偏差与约束关系 | 使用条件积分；先计算三阶段命令，再依据最终约束命令冻结或允许反向卸载积分 |
| TR-05 | PID直接差分位置误差 | 参考变化产生derivative kick，位置量化/噪声被高频放大 | 改为负的测量位置dirty derivative，即滤波速度反馈；记录滤波速度 |
| TR-06 | D仅有二阶黑箱和单一延迟，未显式建模CSP目标更新 | 默认目标每积分步连续变化，隐含插值/连续目标假设 | 加入目标更新周期、目标量化、零阶保持、命令延迟和可选漏更新；不假设DS插值 |
| TR-07 | 单位表不完整，`Kff`和控制器各项维度没有逐项核查 | 方程虽可运行，但技术交接难以审计量纲 | 新增完整单位表和逐项量纲检查 |
| TR-08 | 一套指标跨点到点、恒速和往返使用 | 稳定时间、超调等在往返/扫描中含义不清；方向指标混入换向瞬态 | 按轨迹类型分别实现，并统一输出物理量及相对行程归一化误差 |
| TR-09 | 测试只覆盖有限性、轨迹边界和字段存在 | 无法证明逆模型前馈、延迟分离、anti-windup、ZOH和量化零步长 | 新增10项极限/安全测试，覆盖目标列出的7个必测条件 |
| TR-10 | 路线文字将D称为“毕业保底”、将方向现象称“摩擦补偿” | 把条件性候选写得过于确定，并提前作因果归因 | D改为控制权限更保守的相对低风险候选；改称方向相关误差建模与补偿；A允许成为最终路线 |

## 3. 可保留内容

- 方案A/B/D的控制权限边界及B的硬件前提；
- 方案D不反推DS-BVM内部算法；
- 所有模型参数均为H/R时不宣称台架性能；
- `simulation_only=True`、`hardware_disabled=True`安全守卫；
- 不实现DOB、ADRC、ILC、MPC、CST或交叉耦合；
- 点到点、恒速扫描和正反向轨迹作为最小离线输入集合；
- 图表必须标注“离线模型结果，不代表真实台架性能”。

## 4. 旧结果处理规则

阶段D旧报告中的B数值由含抵消项、单一延迟、无约束anti-windup和误差直接微分的旧模型生成。D1不删除、不覆盖这些文件，但做如下降级：

1. 旧绝对μm数值不用于后续控制器选择；
2. 旧质量/摩擦/时间常数趋势不与D1拼表；
3. D1只比较同一校正模型内部的相对变化；
4. B与D仍不得依据H模型数值互相排名；
5. 真实系统结论仍需标定、辨识和实物时序证据。

## 5. 审查后的最小软件结构

- `src/model_v01.py`：B校正模型、B双延迟、D黑箱+ZOH/漏更新、三类轨迹；
- `src/controllers.py`：前馈推导、dirty derivative、条件积分anti-windup；
- `src/metrics.py`：轨迹分型指标与命令约束统计；
- `scripts/run_corrected_baselines.py`：15个基线、35个定点扫描、5张图；
- `tests/test_model_v01.py`：10项极限与安全测试。

## 6. 结论边界

D1证明的是“校正后的最小模型在其H/R假设下维度一致、延迟分离、约束可追踪且测试覆盖更充分”。它不证明真实DS-BVM速度/位置环参数、不证明1 kHz可行、不证明当前方向差异的摩擦因果，也不决定B或D的最终硬件路线。
