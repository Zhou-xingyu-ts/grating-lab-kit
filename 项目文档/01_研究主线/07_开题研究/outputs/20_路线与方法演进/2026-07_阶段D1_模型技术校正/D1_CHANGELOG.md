## 2. 代码变更

| 区域 | 阶段D | 阶段D1 |
|---|---|---|
| B对象 | 一阶速度环+会被抵消的机械黏性项 | 直接等效速度环+方向力/质量，无黏性参数 |
| B延迟 | 单一`communication_delay_steps` | `measurement_delay_steps`与`command_delay_steps`分离 |
| 前馈 | 手工`kv=1, ka=0.018` | `1/Kv`与`tau_v/Kv`函数推导 |
| 积分 | 仅积分状态夹紧 | 条件积分anti-windup+状态夹紧 |
| 命令记录 | 只记录最终速度命令 | 未饱和/速度限幅/加速度约束/对象输入四阶段 |
| 微分 | 无滤波误差差分 | 低通测量位置微分，负速度反馈 |
| D输入 | 每拍参考+单一延迟 | 更新周期、目标量化、ZOH、命令延迟、可选漏更新 |
| 指标 | 一套统一字段 | 点到点/恒速/换向分型+归一化通用指标 |
| 测试 | 7项基础测试 | 15项极限与安全测试（含本次最小修补新增5项） |

## 6. 2026-07-14最小代码修补

- 点到点超调改为统一方向式`max(0, max(direction * (actual - final_target)))`，新增正/负方向对称测试；
- B测量延迟、B命令延迟和D命令延迟改用显式可配置预采样历史，默认0；历史区间的源索引统一为`-1`，不再隐式重复第0样本；
- B数值步进表述修正为“在本周期残余等效扰动分段常值假设下，对线性速度子系统进行解析ZOH更新”；
- D新增积分步长、全轨迹时间基、阻尼比、闭环增益、噪声标准差和两类量化步长检查；
- `commit_anti_windup()`参数改名为`constrained_command_m_s`，明确它是命令延迟前的本地限幅器输出，算法未变；
- 换向正/反向核心不完整时，四项方向核心指标返回NaN，不再对空数组求均值或极值；
- `simulation_only=True`与`hardware_disabled=True`双安全守卫保持不变。

验证结果：D1单元测试15/15通过。最小回归只在内存中重算15条原基线，没有运行35条敏感性扫描，也没有重写CSV或图片。对同一给定实际轨迹，正方向超调公式输出不变；但默认B命令延迟的首拍对象输入由旧实现的`constrained[0]`改为显式零历史，因此B正向点到点记录值出现确定性小差异，所核对五项核心指标的最大绝对变化为1.0 μm；D正向点到点五项无变化。现有`results/*.csv`和图片仍是修补前生成物，保留不改以遵守本次文件范围。
