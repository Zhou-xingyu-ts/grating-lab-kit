# A基线、B主候选与D保底路线

## 1. 决策结论

采用“一条基线、两条条件化研究分支”：

| 路线 | 阶段D角色 | 外部控制器权限 | 光栅位置 | 当前结论 |
|---|---|---|---|---|
| A：DS内部单反馈闭环 | 真实实验基线与共同对照 | 低频命令/监测 | DS-BVM | 已有运动基线，不代表精度完成 |
| B：外位置环+CSV | 主要研究候选 | 轨迹、位置环、速度目标、位置安全边界 | STM32/实时控制器 | 条件化模型成立，硬件路线未放行 |
| D：轨迹规划+CSP | 低风险保底与三轴协调路线 | 周期位置目标、轨迹、同步、上层安全 | DS-BVM | 黑箱模型成立，PDO/SYNC仍待实物验证 |

方案B只有在全部关键前提关闭后才从“研究候选”升级为“实施路线”。阶段D不采购、不接线、不写PDO、不执行CSP/CSV运动。

## 2. 方案A的任务与退出条件

方案A承担三项任务：

1. 建立counts—位移、方向、零点、重复性和不确定度基线；
2. 建立统一轨迹、时间戳和指标口径；
3. 观察方向差异、低速扫描和参数敏感性，为B/D提供真实问题。

从A进入B或D，不以“能运动”为条件，而以“尺度、时序、机械边界和安全状态可复现”为条件。若B/D前提失败，A仍可承载自研尺接口、标定、误差补偿和多轴平台集成论文内容。

## 3. 方案B的升级门槛

以下门槛必须全部闭合：

| 门槛 | 必需证据 | 失败含义 |
|---|---|---|
| B-G1 独立电机侧反馈 | 参数备份、接线/厂商证据、只读状态，证明DS不依赖负载侧光栅也能完成换相和速度反馈 | B停止，转D或A |
| B-G2 光栅独立进入实时控制器 | 输出制式、电平、最大频率、隔离、计数器、Index、溢出和锁存设计 | B停止，转D或A |
| B-G3 CSV对象与PDO映射 | 型号/固件匹配资料，60FF、6040/6041、606C等映射表 | 不进入写控制 |
| B-G4 周期与同步 | 无运动抓包得到周期、抖动、deadline、丢帧和恢复统计 | 只能保持离线模型 |
| B-G5 安全闭环 | 限位、急停/STO、Quick Stop、heartbeat、目标越界、失联目标行为 | 不得Servo On或发送目标 |
| B-G6 单轴对象模型 | 正式标定、逐对象时刻、低速/正反向/多参数数据和辨识结果 | 只用参数范围，不定最终控制器 |

若B-G1或B-G2不可满足，直接切换到D；若B-G3至B-G5不能满足，保持A，不用SDO写控制代替实时PDO。

## 4. 方案D的升级门槛

| 门槛 | 必需证据 | 失败含义 |
|---|---|---|
| D-G1 光栅仍是DS位置反馈 | 当前参数/接口证据确认6064等位置状态来源 | 核心“光栅反馈”叙述不成立 |
| D-G2 CSP与PDO/SYNC | 607A、6040/6041、6064等帧表与无运动时序证据 | 不进入周期运动 |
| D-G3 黑箱动态可辨识 | 安全S曲线、小幅多周期测试得到等效带宽/阻尼范围 | 只能做宽范围敏感性 |
| D-G4 轨迹与安全约束 | 速度、加速度、Jerk、限位、失联和目标跳变规则 | 不发送周期目标 |
| D-G5 三轴预算 | 每周期帧数、仲裁/重发、处理时间和统一时钟设计 | 先保留单轴 |

方案D不反推或宣称DS-BVM内部位置算法，只辨识从周期位置目标到位置输出的等效闭环动态。

## 5. 分阶段路线

### 阶段1：离线与方案A基线

- 完成模型V0、指标、参数证据注册表和实验设计；
- 返校后只恢复正式标定、重复定位、时间戳和方向隔离实验；
- 不以1 ms作为预设结论。

### 阶段2：通信与反馈前提验证

- 先只读/回环验证PDO、SYNC、heartbeat和时间预算；
- 分别核查B的独立电机反馈/STM32光栅输入，或D的CSP反馈来源；
- 任一安全项不闭合，不进入运动。

### 阶段3：单轴最小运动

- D优先可做CSP最小安全运动，验证周期目标与黑箱动态；
- B只有在速度内环和安全前提闭合后再做CSV外位置环；
- 始终用A的同轨迹、同负载、同指标作对照。

### 阶段4：增强控制与三轴

- 单轴现象可重复后，最多加入一个方向/摩擦补偿；
- 三轴硬件明确后加入统一时基和交叉耦合/轮廓评价；
- 不在单轴未通过前并行扩展三轴。

## 6. 路线切换规则

```text
若B-G1和B-G2成立
  -> 继续关闭B-G3至B-G6
  -> 全部成立才进入B最小CSV验证
否则
  -> 检查D-G1至D-G4
  -> 成立则进入D最小CSP验证
否则
  -> 保持A，研究标定、误差补偿、自研尺接口与平台集成
```

路线切换是证据驱动，而不是根据某次仿真绝对误差或算法“先进程度”决定。

## 7. 三轴扩展接口

无论B或D，每轴至少暴露：

```text
axis_state = {
  timestamp, position, velocity, target_position,
  following_error, command, saturation_state,
  communication_state, limit_state, fault_state
}
```

三轴协调层只读取这些标准状态并输出有速度/加速度/Jerk约束的目标。B中每轴输出速度目标，D中每轴输出位置目标；同步误差和轮廓误差在协调层定义。STO、制动和硬件限位仍由独立安全链负责，不能由交叉耦合控制替代。

## 8. 阶段D停止边界

- 不把B写成最终接线方案；
- 不调用CAN、串口、USB或EtherCAT；
- 不修改`motion_acquisition`；
- 不实现CST、MPC、ADRC、DOB、ILC或三轴控制代码；
- 阶段D只交付模型、离线基线、选择依据和未来验证顺序。
