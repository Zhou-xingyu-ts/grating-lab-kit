# 返校后最小验证计划

> 本文件是未来执行顺序，不是当前放行单。所有真实操作仍须回到`02_实验与现场/01_当前执行/`的39/40/46/59/60链路，按现场安全规则单独放行。

## 总顺序与停止规则

```text
尺度标定 -> A基线 -> 时间戳 -> 方向隔离
-> PDO/SYNC无运动 -> D/CSP最小运动
-> B/CSV前提 -> 自研尺接口
-> 单轴通过后才扩展三轴
```

任何一步触发限位、异常噪声、失联、未解释位置跳变、制动/STO不确定或目标越界，立即停止，不用软件补偿绕过硬件问题。

## 1. counts—位移正式标定

- 目的：关闭counts/mm、方向、零点、重复性和不确定度。
- 设备：激光干涉仪优先；若不可用，使用有溯源证书且分辨率足够的外部长度基准、安装支架、环境记录。
- 输入变量：多位置点、正反双向、至少3次重复、低速小行程。
- 观测量：光栅counts、外部位移、时间戳、方向、回程差、环境和装夹状态。
- 风险：外部基准未对准、余弦误差、行程/方向设错、线缆干涉。
- 通过条件：给出线性换算、残差、双向重复性和不确定度；不再使用单点`10000 counts≈5 mm`作正式尺度。
- 失败转向：只以counts报告后续结果；修正基准安装/对准，不调控制器掩盖标定误差。

## 2. 方案A重复定位和跟踪基线

- 目的：建立真实对照组，定义同轨迹、同负载、同指标的基准分布。
- 设备：现有单轴台、Servo Studio、已验证只读采集、外部基准（若可用）、急停/限位。
- 输入变量：S曲线、往返、低速恒速；至少3档速度、2档加速度、双向多次重复。
- 观测量：目标/实际位置、跟随误差、速度、状态字、错误码、外部位移和操作时间线。
- 风险：现有安全缺口、行程越界、参数混淆、USB/SDO时基误读。
- 通过条件：每种工况至少3次可重复；保存原始数据、参数备份、指标定义和失败记录。
- 失败转向：保持方案A排障；不进入PDO/CSP/CSV。

## 3. 采样时间戳和逐对象读取时刻改进

- 目的：区分轮次吞吐、对象实际读取时刻和控制/反馈延迟。
- 设备：只读USB-CAN、PC高分辨率时钟；条件允许时增加独立CAN抓包。
- 输入变量：7对象与3对象、静止与低速运动、多个请求周期。
- 观测量：每个请求发送/响应时间、轮次起止、抖动、超时、对象间偏移。
- 风险：误把同轮对象称同步采样；采集负载影响运动或UI链路。
- 通过条件：每对象有时间戳；明确实际轮次率、工作段overrun和全周期deadline口径。
- 失败转向：只使用严格单对象/少对象数据；不做相位或实时外环结论。

## 4. 正反向不对称隔离实验

- 目的：区分摩擦/重力、间隙、线缆、负载、加速度和控制器收敛的贡献。
- 设备：方案A台架、可调负载（若安全）、统一数据采集、外部基准。
- 输入变量：正反向、多速度、多加速度、不同停留、可能的姿态/负载对照，一次只改一个变量。
- 观测量：方向平均误差差、RMS、最大误差、稳态窗口、速度与加速度、饱和状态。
- 风险：变量未隔离、温漂或装夹变化、反向间隙导致突跳。
- 通过条件：至少一种方向效应跨重复稳定，且能排除明显限幅/时间错位；允许结论仍是“复合方向效应”。
- 失败转向：不选择摩擦补偿，转向更通用的标定/重复误差研究。

## 5. PDO与SYNC最小只读/回环验证

- 目的：在无运动条件下关闭对象映射、周期、抖动、丢帧、heartbeat和失联行为。
- 设备：型号匹配EDS/手册、CAN主站/抓包工具、终端和隔离确认、驱动器保持不使能。
- 输入变量：候选0.5/1/2/5 ms周期、1轴后再估计3轴帧表；只读TPDO或安全回环。
- 观测量：COB-ID、transmission type、SYNC、时间戳、抖动、deadline、错误帧、恢复和总线负载。
- 风险：错误映射或状态机导致意外写入/使能；终端/接地错误。
- 通过条件：全程无运动、无控制字/目标写入；帧表和统计可复现，失联行为已书面确认。
- 失败转向：保持SDO只读或方案A；不以1 ms定时器源码替代总线证据。

## 6. CSP最小安全运动验证

- 目的：验证方案D的周期位置目标、黑箱动态和丢帧处理。
- 设备：安全链闭合的单轴台、已验证PDO/SYNC主站、硬件限位/急停、低速小行程放行单。
- 输入变量：极小位移、低速S曲线，从保守周期开始；逐级而非直接1 ms。
- 观测量：目标/实际位置、跟随误差、状态字、错误码、PDO时间戳、限幅和停止行为。
- 风险：目标跳变、尺度/方向错误、失联保持旧目标、限位或STO未生效。
- 通过条件：可重复启动/停止；无异常状态；失联/越界按预案进入安全状态；得到等效带宽/阻尼范围。
- 失败转向：退回方案A；修正时序/轨迹/安全，不转CST。

## 7. CSV外位置环前置条件验证

- 目的：决定方案B是否能从候选升级为实施路线，不在本步直接调高性能。
- 设备：独立电机侧反馈证据、STM32/实时控制器光栅输入链、已验证PDO/SYNC、完整安全链。
- 输入变量：先静态/回环速度目标，再零或极低速度；验证限幅和失联目标行为。
- 观测量：电机侧速度反馈/换相状态、光栅计数、60FF/606C、状态字、周期/抖动、目标清零/Quick Stop。
- 风险：DS失去有效速度/换相反馈、外位置环正反馈、速度目标保持、计数跳变。
- 通过条件：B-G1至B-G5全部有证据；方向、尺度、限幅和失联均通过独立测试。
- 失败转向：切换方案D；若D也不成立则保持A。

## 8. 自研光栅尺接口、电气和时序验证

- 目的：确认自研尺能否替换商业尺进入B或D，而不是先追求控制精度。
- 设备：接口规格、示波器/逻辑分析仪、隔离/电平转换、计数器测试平台、独立位移基准。
- 输入变量：静止、已知方向/速度、小行程、多频率；断线/跳变模拟仅在隔离测试平台进行。
- 观测量：输出制式、电平、供电、最大频率、边沿质量、方向、Index、丢计数、锁存时刻、噪声和异常状态。
- 风险：电平/供电不兼容、直接连接损坏、共地/隔离不当、计数溢出。
- 通过条件：接口规格和原理图闭合；计数、方向、Index、溢出、异常检测和时间戳均可复现。
- 失败转向：保留商业尺代理平台；先修接口，不把通信/控制算法作为补救。

## 9. 单轴通过后扩展三轴

- 目的：验证统一时基、总线预算、同步误差和轮廓误差，不只是三台轴同时运动。
- 设备：三轴机构/驱动/反馈、安全链、统一主站、几何标定工具。
- 输入变量：逐轴单独、两轴同步、三轴低速直线，再到允许的圆/空间轨迹。
- 观测量：每轴状态、目标/反馈时间戳、同步误差、轮廓误差、总线负载、故障传播。
- 风险：一轴故障拖动其他轴、坐标/方向错误、总线拥塞、机构碰撞。
- 通过条件：各轴先独立通过；统一时基和总线预算有余量；单轴故障能安全解耦；轮廓指标可重复。
- 失败转向：退回单轴/两轴；不以降低采样或取消安全帧掩盖总线预算问题。

## 采购前必须回答的问题

1. 自研尺输出制式、电平、供电、最大频率、Index/绝对协议和隔离要求是什么？
2. DS-BVM当前型号/固件能否在负载光栅不作为唯一反馈时保持电机侧换相和速度闭环？
3. 型号匹配EDS、PDO映射、CSP/CSV丢帧和heartbeat行为是否有官方资料？
4. STM32板上是否已有合规CAN收发器、隔离、终端和光栅差分接收电路？
5. 三轴各轴的电机、驱动器、反馈、行程、限位、制动和STO是否同构？
6. 实验室是否可提供激光干涉仪、逻辑分析仪/示波器和独立CAN抓包？
7. 哪些器件已有库存、哪些确实缺失、采购是否有型号兼容证据？

在这些问题关闭前不形成具体采购单。
