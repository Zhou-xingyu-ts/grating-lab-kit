## 相位问题怎么定位：先拿波形，不先选校正电路

向师姐拿现成的两路同屏示波器波形或 CSV，以及整形部分电路图。若需要新测量，另行明确测量安排和硬件授权；本页不执行或放行测量。

最小资料包：两路测点名称、时间刻度/采样率、电压单位、当时速度与运动方向；原始模拟信号（若存在）和最终 A/B 方波尽量对应同一工况。不要只有一个“75°”读数。

| 观察结果 | 优先检查什么 | 下一步最小动作 |
|---|---|---|
| 原始模拟两路已经偏离正交 | 传感/光学几何、前端通道、原始信号偏置与正交关系 | 先与尺端负责人定位源头；如果原始信号适合，再评估模拟正交校正或已有采样链上的数字校正。 |
| 原始模拟接近正交，整形后才偏 | 比较器阈值、直流偏置、迟滞、占空比、两路滤波/传播延迟 | 对照整形前后边沿，校正已定位的环节；不凭相位读数直接换板或指定阻容值。 |
| 两路角度偏差随频率明显变化 | 两通道延迟/带宽差、测量通道时间偏差 | 同时看时间差与周期；固定延迟造成的角度误差随频率变化，但相关性本身不等于根因确认。 |
| 边沿抖动、重复跳变或相位不稳定 | 信噪比、阈值附近抖动、接线/供电以及原始信号质量 | 先定位异常跳变，不能用平均相位掩盖。 |

同一近似匀速周期内，`相位差 = 360° × 对应边沿时间差 / 周期`。应同时检查两路占空比、上升/下降沿及相邻四个有效边沿的间距；正反向记录谁领先，不把反向时的领先关系翻转算成故障。加减速段不能直接套一个全局周期。

**为什么十几度值得处理，但不代表一定不能计数：**以两路占空比都为 50%、相差 75°且无抖动为例，四个边沿间隔会交替为 75°/105°，仍可能按正确顺序计数，但四倍频计数对应的空间间隔不均匀，边沿裕量也改变。这是示意推导，不是你这把尺的实测结论。需要兼顾驱动器允许的最小边沿间隔、最高实际频率与电气条件，不能自行宣布“±15°合格”。

**不建议先加固定 RC 延时“补 15°”。**如果误差来自空间相位偏差，所需时间修正会随速度改变，固定时间延迟只可能在部分工况凑巧对上。若根因是两通道固定传播延迟不一致，则应针对那一环节匹配；两种情况不能混同。

若两路是模拟正余弦，再用比较器整形，应另核实输出是否经过细分。简单过零整形只得到每个模拟周期的粗 A/B 边沿，不会自动保留原有高分辨率位移解算能力。

RS-422 是另一项要求：最终是 A+/A−、B+/B− 两对差分输出。相位校正与单端转差分是两件事，普通线驱动器不负责修正原始正交误差。手册的 5VDC 是编码器供电，不可当作 A/B 差分幅值结论。

上述诊断依据：[TI 正交信号说明](https://www.ti.com/document-viewer/lit/html/SBOA200)；[TI TIDA-00176 正余弦接口与细分设计](https://www.ti.com/lit/ug/tidua05a/tidua05a.pdf)。这些用于说明信号处理原理，不是推荐采购或照搬整套参考设计。

## 接下来按这个顺序推进

1. **当前第一步：**拿上述已有波形和电路信息，给出相位、占空比、边沿间隔及异常跳变的诊断，选最小修正方案。没有原始信号资料时，不承诺具体校正电路。
2. **若师姐已有连续位移输出：**可以先保留商业尺闭环，让自研尺独立测量同一轴。最省的是分别导出带时间信息的数据；接口确定后才考虑加一个简单导入/显示功能。无同步依据时先比较静止驻留点，不把人工时间对齐后的动态差值当作精度。此阶段只能称自研尺测量接入，不能称其参与了闭环。
3. **信号就绪后：**先验证自研尺的计数、方向与尺度，再安排小行程闭环接入。反馈替换会影响现有位置环的尺度、方向及参数，不能因为插头/信号名称相同就直接替换使能。具体硬件动作另行确认。
4. **演示验证：**沿用简单往返并做少量同条件重复，记录反馈源与参数。它是可用性检查；正式精度结论还需独立位移基准和相应实验设计。

## motion_acquisition 现在要不要继续优化

已有固定单轴直控、停止/Disable、记录、回放和分析，足以支撑下一步信号接入研究。暂不新增 STM32/GM1 路线、外部位置环、通用插件、复杂界面或高级控制算法，也不重做已有图表管线。

本次代码静态核对发现独立直控窗口仍默认填入历史 `data/20260801`，而主窗口已使用本地数据根；下次实际运行前应明确本次保存目录。界面轨迹也固定为 ±5000 counts，不能把它当成任意小行程已可配置。若下一次明确需要更短行程，再只增加该参数并验证。发布 EXE 与源码是否一致应按实际使用的版本检查，不为这次资料诊断自动重新打包。

**本次不修改软件代码。**A/B 波形偏差发生在进入驱动器前；对驱动器已经计数后的数据做上位机滤波，不能恢复漏掉或错误解释的硬件边沿。
