# 技术现状综述：光栅尺反馈闭环运动控制

> 生成日期：2026-06-01。用途：开题报告“国内外研究现状”和“技术路线论证”。

## 1. 测量端：高精度光栅尺不自动等于高精度运动控制

近年光栅干涉仪和多自由度光栅编码器文献表明，光栅测量端已经能覆盖纳米计量、多自由度位移/姿态测量和紧凑化集成。2025 年 Sensors 综述《Precision Nanometrology》将光栅干涉仪与激光干涉仪、时栅传感器并列为纳米计量关键技术；2025 年多自由度光栅编码器综述则说明光栅编码器已从单轴位移扩展到多自由度空间测量。

但这些文献主要证明“能测”，不直接证明“能控”。运动控制还必须解决实时采样、控制周期、反馈噪声、执行器带宽、机械模态、几何误差和外部基准验证。开题中必须把“光栅尺测量精度”“闭环重复性”“外部基准下定位精度”分开，不能用自研光栅尺反馈自证最终定位精度。

## 2. 平台端：单轴/XY 平台是硕士课题最现实入口

纳米定位平台文献大致分三类：柔性铰链/压电短行程平台、直线电机/龙门长行程平台、6D/多自由度复合平台。2024 年 NPS6D200 展示了 6D 长行程闭环纳米定位平台的高目标形态，但其系统复杂度明显高于硕士开题初期可承诺范围。2024 年 XY 柔性微定位平台结合激光测量与 ADRC，则更接近本课题可参考的“二维平台 + 外部位移反馈 + 控制算法验证”路径。

因此，正式课题不宜一开始承诺完整多自由度闭环。最稳路线是：先做单轴外部全闭环，证明自研光栅尺可以作为负载侧反馈；随后扩展到 XY 二维平台，做多轴同步、轮廓误差和几何补偿。

## 3. 控制端：外部全闭环是核心，而不是算法名词堆叠

精密平台通常已有电机编码器、驱动器内环或速度/电流环。自研光栅尺的价值在于作为负载侧真实位移反馈，补偿丝杠、导轨、装配、热漂移和摩擦造成的电机端反馈不可见误差。合理控制架构是分层闭环：驱动器负责电机侧稳定控制，光栅尺参与外部位置环或上位机/控制器外环。

这意味着本课题真正问题不是“用不用最新算法”，而是：自研光栅尺输出能否被控制系统实时、同步、可靠读取；外环控制周期能否匹配平台动态；外部反馈如何避免噪声放大和正反馈失控。

## 4. 误差补偿：比单纯闭环更像论文贡献

赖建君系统和多轴轮廓误差文献都说明，光栅尺闭环不能自动消除全部误差。余弦误差、阿贝误差、丝杠周期误差、导轨几何误差、热漂移和摩擦仍会进入最终定位结果。可重复误差适合查找表/误差表补偿，重复轨迹适合 ILC/学习前馈，多轴轮廓误差适合交叉耦合或轮廓误差估计补偿。

因此，论文主线可以从“闭环链路打通”提升为“光栅尺负载侧反馈下的建模、控制与误差补偿”。

## 5. 实验评价：必须建立三层指标

| 层级 | 指标 | 可宣称内容 |
|---|---|---|
| 反馈质量 | 静止噪声、刷新率、延迟、丢计数、方向、单位换算 | 光栅尺反馈能否用于控制 |
| 闭环性能 | 阶跃响应、稳定时间、超调、重复定位、低速跟踪误差 | 控制链路是否有效 |
| 外部基准精度 | 激光干涉仪/商业传感器下的定位误差 | 真实定位精度 |

没有外部基准时，只能报告“闭环重复性/反馈一致性”；有外部基准后才适合报告“定位精度”。这是开题和答辩时必须守住的边界。

## 6. 对六个研究问题的当前回答

| 问题 | 当前研究结论 |
|---|---|
| 自研光栅尺最适合作为什么反馈？ | 开题阶段先作为单轴负载侧位置反馈；正式主线扩展到 XY 二维反馈；多自由度姿态反馈作为升级方向。 |
| 已有技术通常采用什么平台？ | 短行程高精度多用压电/柔性平台；长行程/多轴多用直线电机、龙门或复合平台；评价常用外部干涉仪或高精度位移传感器。 |
| 真正技术空白是什么？ | 不是单纯 PID，而是自研光栅尺实时接入控制器、外部全闭环架构、误差补偿和从单轴到多轴的同步扩展。 |
| 哪个方向最适合硕士开题？ | 方向 B：自研光栅尺反馈二维 XY 精密运动平台闭环控制；以方向 A 单轴闭环作为保底路径。 |
| 哪些算法能落地？ | PID/前馈/误差表最先落地；DOB/ADRC 适合抗扰；ILC 适合重复轨迹；MPC/学习前馈作为进阶或展望。 |
| 开题题目如何定？ | 稳妥题目用“基于自研光栅尺反馈的精密运动平台建模与闭环控制方法研究”；若资源明确，再升级为“二维/多轴”。 |
