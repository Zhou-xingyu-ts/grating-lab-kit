# 控制系统设计

## 控制对象

论文控制对象是两平移一旋转的平面运动台：

```text
q = [x, y, theta]
```

其中 `x`、`y` 是平移位移，`theta` 是旋转角。论文用电磁铁电流驱动平台，用 3 个非接触 gap sensors 反馈平台状态。相关位置：PDF第3页、PDF第6页。

## 动力学模型

线性化后的动力学方程见式 (1)，可概括为：

```text
M * x_ddot + Cx * x_dot - Kx * x = Kix * ix - F_friction
M * y_ddot + Cy * y_dot - Ky * y = Kiy * iy - F_friction
I * theta_ddot + Ctheta * theta_dot - Ktheta * theta = Kitheta * itheta - r * F_friction
```

相关位置：PDF第4页。

参数含义：

- `M`：运动台质量。
- `I`：运动台转动惯量。
- `C`：阻尼系数。
- `K`：gap-force factor。
- `Ki`：current-force factor。
- `F_friction`：摩擦力。

这些 gap-current-force 曲线由实验和 MAXWELL 12.0 仿真共同确定。相关位置：PDF第5页。

## 电磁线圈电压-电流关系

式 (2) 描述控制电压和线圈电流之间的关系：

```text
Vx = Lx * i_x_dot + Rx * i_x + Kvx * x_dot
Vy = Ly * i_y_dot + Ry * i_y + Kvy * y_dot
Vtheta = Lx * i_theta_dot + Rx * i_theta + Kvx * theta_dot
```

相关位置：PDF第5页。

这说明论文不是把执行器看成理想力源，而是把线圈电感、电阻和反电动势因素纳入模型。对当前实验，电机/驱动器也不应完全黑箱化；至少要知道控制输入到底是速度、位置、脉冲、模拟电压还是电流。

## 控制结构

PDF 正文明确写：控制系统包括 regulator 和 PI compensator，二者分别设计。X 方向控制框图见 Fig. 6；Y 和 Theta 方向类似。相关位置：PDF第5页。

旧速读材料把它概括为 PID+feedforward（PID+前馈）。这个概括可以帮助理解“反馈稳定 + 补偿动态”的控制思想，但严格引用时建议写：

```text
regulator + PI compensator
```

不要把 feedforward 当成论文逐字术语。

## Regulator 设计

论文使用极点配置法设计 regulator。X 方向从参考 `Xr(s)` 到输出 `X(s)` 的传递函数见式 (3)，再通过定义正极点 `p`，让闭环特征多项式满足式 (4)：

```text
characteristic polynomial = (s + p)^5
```

随后求解式 (5)，自动得到 `a1x`、`a0x`、`b2x`、`b1x`、`b0x` 等参数。相关位置：PDF第5-6页。

## PI 补偿器设计

论文说明 PI compensator 用于消除稳态误差，`Kc` 和 `Kp` 由试错实验和仿真确定。相关位置：PDF第6页。

这体现了一种务实工程路线：

1. 模型用于确定初值和结构；
2. 试验用于修正参数；
3. 最后以阶跃、轨迹和频响验证。

## 对当前实验的控制启示

- 控制器设计前先明确对象模型：质量、阻尼、刚度、执行器增益、传感器噪声。
- 第一版可以线性化，但必须记录非线性来源，比如摩擦、饱和、死区和迟滞。
- 不要只给 PID 参数，要给测试结果：阶跃响应、稳态误差、超调、上升时间、带宽。
- 当前单轴最小闭环可以先做 P/PI/PID 外环；后续再把模型辨识和前馈补偿加进去。
