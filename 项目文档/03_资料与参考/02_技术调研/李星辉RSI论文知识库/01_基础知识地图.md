# 基础知识地图

## 1. 磁流体润滑

磁流体（magnetic fluid, MF）是含磁性颗粒的流体。论文用它替代传统润滑油，目的有两个：一是降低运动台与导轨表面之间的滑动摩擦，二是通过磁场约束流体，避免润滑油泄漏和污染。相关位置：PDF第2-4页。

论文使用的磁流体型号为 MF P-306，物性参数见表 I：密度 1.20e3 kg/m3，黏度 105-395 mPa s，饱和磁化 31.1 mT，颗粒体积分数 35%。相关位置：PDF第4页。

## 2. 悬浮式滑动平面运动台

论文提出的是 suspension type sliding planar motion table：运动台仍靠滑动导向，但通过电磁铁吸引力使运动台从导轨表面“部分悬浮”，从而降低法向接触力和摩擦。相关位置：PDF第2-3页。

它不是传统气浮平台，也不是完全非接触磁悬浮平台。它的特点是：用悬浮减小摩擦，用磁流体保持润滑膜和密封，用电磁铁进行定位驱动。

## 3. 三自由度平面运动

论文平台的运动自由度是两平移一旋转：

```text
X, Y, Theta
```

其中 X/Y 是平面内平移，Theta 是绕垂直方向的旋转。论文使用 3 个非接触 gap sensors 测量运动台的位移状态，再换算成 X/Y/Theta。相关位置：PDF第3页、PDF第6页。

对当前光栅尺课题的意义：多自由度系统也可以拆成少数可测状态和少数执行器的闭环问题。你当前做单轴时，可以先把这一套方法简化为：

```text
目标位置 -> 位移传感器 -> 控制器 -> 执行器 -> 平台 -> 位移传感器
```

## 4. 电磁铁执行器

论文里有三类电磁铁执行器：

- EM-S：suspension electromagnets，用于产生悬浮力。
- EM-MF：magnetic-fluid sealing electromagnets，用于产生磁场约束磁流体。
- EM-P：positioning electromagnets，用于 X/Y/Theta 定位驱动。

相关位置：PDF第3-4页。

外部核查：Ansys Maxwell 官方资料说明 Maxwell 是低频电磁场仿真工具，可用于电机、执行器等机电装置的磁场、力和瞬态行为分析。这与论文用 MAXWELL 12.0 求电磁铁 gap-current-force 曲线的用途一致。

## 5. 非接触位移传感器

论文使用 three non-contact displacement sensors；实验设置处进一步明确为 3 个 eddy current-type gap sensors，型号 PU-07，AEC Corp.，量程 0-3 mm，分辨率 1 µm。相关位置：PDF第2页、PDF第6页。

涡流式位移传感器适合测金属目标的间隙，优点是非接触、响应快；缺点是测量对象材料、温度、安装几何和电磁环境会影响结果。对当前光栅尺实验，它可作为“负载侧传感器进入闭环”的早期样例，但不等于光栅尺测量原理。

## 6. 摩擦与 Stribeck 非线性

论文把摩擦力写成：

```text
F_friction = mu * F_N
```

其中 `mu` 是摩擦系数，`F_N` 是运动台与导轨之间的接触力。论文指出摩擦系数随滑动速度变化，符合从边界润滑到混合润滑、再到流体动力润滑的 Stribeck 曲线过渡，具有非线性。相关位置：PDF第5页。

但论文第一阶段为了研究基本性能，采用线性化控制系统，并在仿真中把摩擦系数设为静态值 `mu0 = 0.4`。相关位置：PDF第5页。

## 7. Regulator + PI 控制

论文正文的精确表述是：控制系统包括 regulator 和 PI compensator，二者分开设计。regulator 使用极点配置法设计；PI compensator 用于消除稳态误差；部分参数通过试错实验和仿真确定。相关位置：PDF第5-6页。

旧速读材料把它概括为 PID+feedforward（PID+前馈）。作为学习时可以这么理解“反馈 + 补偿”的工程框架，但严格引用时应写“regulator + PI compensator”，不要把 feedforward 当作论文逐字术语。

## 8. 带宽

论文的带宽目标来自激光切割镜头振动补偿需求：在 50 µm 范围内，两平移方向带宽不小于 100 Hz。实验最终得到 X=101 Hz，Y=105 Hz，Theta=168 Hz。相关位置：PDF第2页、PDF第8页。

对当前单轴闭环实验，带宽的迁移结论是：不要只说“控制周期多少”，要用阶跃响应、正弦扫频或至少不同频率跟踪误差来验证闭环动态能力。
