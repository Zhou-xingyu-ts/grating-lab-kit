# 机械结构与磁流体润滑

## 机械设计目标

论文设计的核心矛盾是：激光切割镜片驱动需要紧凑、大行程、高响应的平面运动机构，但传统方案各有缺点。弹性铰链机构结构简单但行程小；气浮轴承精度和响应好但需要供气系统；完全磁悬浮复杂度较低但支撑刚度不足。论文提出的折中方案是“磁悬浮减摩 + 磁流体润滑/密封 + 滑动平面运动”。相关位置：PDF第2-3页。

## 悬浮减摩原理

传统滑动平台的摩擦力来自运动台自重导致的法向接触力。论文通过 EM-S 电磁铁产生悬浮吸引力，抵消一部分自重，从而减小运动台与导轨表面之间的接触力。摩擦力关系写作：

```text
F_friction = mu * F_N
```

其中 `mu` 为摩擦系数，`F_N` 为接触力。相关位置：PDF第5页。

实验中，运动台重量为 18.4 N；为达到 3.3 N 接触力，需要 21.7 N 吸引力悬浮运动台。论文最终给出摩擦降低 82.1%。相关位置：PDF第6页。

## 磁流体密封/润滑

论文使用 EM-MF 电磁铁产生磁场，把磁流体限制在目标表面附近，既防止润滑油泄漏，又帮助形成润滑膜。相关位置：PDF第3-4页、PDF第7页。

## 摩擦非线性与线性化

论文指出摩擦系数随滑动速度变化，符合 Stribeck 曲线，从边界润滑到混合润滑再到流体动力润滑，因此具有非线性。相关位置：PDF第5页。

但作为研究第一步，论文先采用线性化控制系统，仿真中将摩擦系数设为静态值 `mu0 = 0.4`。相关位置：PDF第5页。这一点对当前实验很重要：第一版闭环不必把所有非线性都建进去，但必须承认非线性存在，并通过实验数据界定它的影响。

## 对当前课题的机械启示

1. 精密定位问题不只是控制器问题，摩擦、间隙、刚度、润滑和传感器安装都会决定闭环表现。
2. 论文先做线性化模型，再用实验验证基本性能；这比一开始追完整非线性模型更务实。
3. 82.1% 减摩结论说明机械改造可以显著降低控制难度；当前单轴实验若平台摩擦大，PID 调参不会从根上解决问题。
4. 论文把需求、结构、模型、实验结果串成闭环论证，这比单独堆参数更有导师沟通价值。
