# 自研光栅尺反馈多轴运动控制研究计划简明版

> 版本：2026-06-01  
> 用途：与李星辉沟通正式硕士课题研究计划。  
> 定位：当前 Z 轴恢复实验只是前置验证；正式研究计划面向“自建运动平台 + 实验室自研高精度增量式光栅尺 + 高精度闭环运动控制”。

## 1. 总体判断

我对李星辉意向的理解是：课题不应停留在复现赖建君旧平台，也不只是把现有 Z 轴接起来跑通，而是要围绕实验室自研光栅尺，搭建一个可验证的精密运动控制平台，证明自研高精度增量式光栅尺可以作为负载侧位置反馈进入闭环控制系统，并提升平台定位或跟踪性能。

正式课题可以概括为：

```text
自研光栅尺 -> 实时位置反馈 -> 多轴运动控制平台 -> 高精度闭环定位/跟踪
```

当前 Renishaw/Z 轴实验的作用是降低近期风险：先用现成硬件跑通“光栅尺反馈进入运动闭环”的最小链路，摸清接线、控制器、驱动器、反馈方向、数据记录和安全问题。它不是最终研究计划本体。

## 2. 建议课题题目

首选题目：

```text
基于自研增量式光栅尺反馈的多轴精密运动平台闭环控制方法研究
```

更稳妥的开题题目：

```text
基于自研光栅尺反馈的精密运动平台建模与闭环控制方法研究
```

如果后续平台确认为 X/Y/Z 或 X/Y/theta 多轴，可在开题或论文中明确为：

```text
基于自研光栅尺反馈的多轴精密运动平台建模、控制与误差补偿研究
```

## 3. 研究目标

### 3.1 工程目标

搭建一套面向实验室自研光栅尺的精密运动控制实验平台。平台至少具备单轴闭环验证能力，进一步扩展到二维或三轴联动控制。系统应包含：

- 自研增量式光栅尺反馈链路；
- 多轴运动平台机械本体；
- 运动控制器或实时控制系统；
- 驱动器、执行器和限位/安全链路；
- 上位机数据采集、参数配置和实验记录程序。

### 3.2 控制目标

建立光栅尺负载侧反馈下的闭环控制方法，实现高精度定位和低速轨迹跟踪。研究重点不是重新开发光栅尺光学结构，而是解决：

- 自研光栅尺输出信号如何进入控制器；
- 光栅尺反馈与电机编码器反馈如何分层协同；
- 多轴同步采样和控制周期如何影响精度；
- 机械误差、安装误差、摩擦、热漂移和测量噪声如何进入闭环；
- 如何通过控制参数整定、前馈、误差补偿提升运动精度。

### 3.3 论文目标

形成一条完整证据链：

```text
需求分析 -> 平台设计 -> 信号接入 -> 系统建模 -> 控制方法 -> 实验验证 -> 误差分析与补偿
```

最终论文不只证明“线接通了”，而要证明自研光栅尺反馈对运动控制性能有可量化贡献。

## 4. 拟研究内容

### 4.1 自研光栅尺反馈信号建模与接口方案

首先明确实验室自研增量式光栅尺的可用输出形态。当前可能存在几种情况：

| 输出形态 | 控制接入方式 | 研究关注点 |
|---|---|---|
| A/B/Z 增量脉冲 | 高速计数输入或运动控制卡辅助编码器口 | 计数频率、四倍频、方向、回零、同步采样 |
| 数字位移值 | 串口、USB、EtherCAT、DAQ 或实时总线 | 刷新率、延迟、时间戳、丢包、单位换算 |
| 模拟 sin/cos | 插补盒或模拟编码器接口 | 细分倍数、噪声、相位误差、接口成本 |
| FPGA 内部解算结果 | 与光栅尺小组协同定义输出协议 | 实时性、分辨率、控制器兼容性 |

这一部分的研究目标是把“测量端的高分辨率”转化为“控制系统可实时使用的位置反馈”，并量化输出刷新率、噪声、延迟和量化误差对闭环性能的影响。

### 4.2 多轴运动平台总体方案设计

正式平台建议按“两级目标”推进：

第一阶段：单轴或二维平台。  
先实现 X 或 Z 单轴闭环，再扩展到 X/Y 二维平面运动。目标是尽快形成稳定实验对象，避免一开始就陷入全机械设计和多轴耦合风险。

第二阶段：多轴联动平台。  
在单轴/二维闭环稳定后，再根据自研光栅尺实际自由度扩展到 X/Y/Z 或 X/Y/theta。若自研光栅尺本身支持多自由度测量，则重点研究多轴同步采样、坐标解耦和联动控制。

平台设计需要明确：

- 行程：微米到毫米级；
- 目标精度：先微米级或亚微米级，再争取更高；
- 执行器：直线电机、音圈电机、压电平台、丝杠模组或组合方案；
- 导向结构：交叉滚子导轨、气浮/柔性铰链/商用位移台等；
- 控制器：运动控制卡、实时控制器、PLC/EtherCAT、DAQ + 实时系统；
- 外部基准：激光干涉仪、商业光栅尺或高精度位移传感器用于标定。

### 4.3 光栅尺外部全闭环控制架构

建议采用分层控制结构：

```text
电机编码器/驱动器内部反馈 -> 电流环/速度环/换相
自研光栅尺负载侧反馈 -> 外部位置环
上位机/运动控制器 -> 轨迹规划、同步控制、误差补偿
```

这样可以把电机本体稳定控制和平台真实位移控制分开。电机编码器保证电机侧可控，自研光栅尺负责观察负载侧真实位置，补偿丝杠、导轨、装配、摩擦和热漂移带来的误差。

核心问题包括：

- 光栅尺反馈闭环放在控制器内部，还是由 PC/实时系统做外环；
- 控制周期能否匹配光栅尺刷新率；
- 多轴光栅尺读数是否能同步采样；
- 外环增益如何避免噪声放大和机械共振；
- 电机编码器位置与光栅尺位置如何标定和对齐。

### 4.4 控制算法与误差补偿

控制方法不宜一开始追求复杂算法。建议按以下层级推进：

1. P/PI/PID 位置闭环：完成方向、比例、稳定性和到位误差验证；
2. 速度/加速度前馈：改善低速跟踪和阶跃响应；
3. 陷波或低通滤波：抑制机械共振和测量噪声；
4. 误差表补偿：补偿周期误差、丝杠误差、导轨误差或光栅安装误差；
5. 多轴解耦补偿：处理 X/Y/theta 或 X/Y/Z 之间的几何耦合；
6. 进阶算法比较：DOB、ADRC、ILC、MPC 等作为后续扩展，不作为第一轮跑通前置条件。

论文重点可以放在“光栅尺反馈下的控制性能提升机制”，而不是声称提出全新控制算法。

### 4.5 实验评价体系

实验需要从一开始就按论文证据链设计，而不是只做演示。建议评价指标包括：

| 类别 | 指标 |
|---|---|
| 反馈质量 | 静止噪声、分辨率、刷新率、延迟、丢计数/跳数 |
| 单轴定位 | 到位误差、重复定位误差、稳定时间、超调 |
| 轨迹跟踪 | 低速匀速误差、阶跃响应、正弦跟踪误差 |
| 多轴联动 | 圆轨迹误差、轮廓误差、同步误差、轴间耦合 |
| 误差补偿 | 补偿前/后定位误差、重复性、残差分布 |
| 稳定性 | 长时间漂移、温度影响、负载变化、振动敏感性 |

重要区分：

- 没有外部基准时，只能说“闭环重复性”或“反馈一致性”；
- 有激光干涉仪或商业高精度传感器标定后，才适合说“绝对定位精度”；
- 自研光栅尺作为控制反馈时，还需要独立基准验证其测量误差，否则容易形成自证循环。

## 5. 阶段计划

### 阶段 0：近期前置验证，跑通现有 Z 轴最小闭环

时间：当前至近期。

目的：用 Renishaw 光栅尺和现有 Z 轴平台验证闭环链路，不把它作为最终论文平台。

输出：

- 光栅尺进入控制器的接线和计数流程；
- 驱动器、电机、刹车、安全链路的调试经验；
- 命令、电机编码器、光栅尺三者的方向和比例对账方法；
- 第一份闭环收敛曲线和 CSV 记录；
- 对正式平台设计有用的风险清单。

### 阶段 1：自研光栅尺信号规格确认与接口方案确定

关键任务：

- 找光栅尺小组确认输出信号类型；
- 确认分辨率、噪声、刷新率、延迟、最大速度对应频率；
- 确认是否有 A/B/Z、数字位置、sin/cos 或 FPGA 输出；
- 选定控制器接口：高速计数、运动控制卡、实时 DAQ、EtherCAT 或插补盒；
- 做信号链路仿真，判断在目标速度和控制周期下是否可行。

阶段输出：

- 自研光栅尺接口说明；
- 控制器选型依据；
- 信号精度和闭环性能的初步仿真结果。

### 阶段 2：多轴运动平台方案设计与采购/搭建

关键任务：

- 明确平台自由度：优先 X/Y 二维或 X/Y/Z 三轴；
- 明确行程、负载、目标速度和目标精度；
- 选择执行器和导向结构；
- 选择驱动器、控制器和数据采集系统；
- 设计光栅尺安装方式，控制阿贝误差、余弦误差和热漂移；
- 设计限位、急停、线缆管理和上电安全流程。

阶段输出：

- 平台总体方案图；
- BOM 和采购清单；
- 控制系统框图；
- 接线与安全设计；
- 实验台搭建计划。

### 阶段 3：单轴闭环与模型辨识

关键任务：

- 先完成单轴闭环定位；
- 采集阶跃响应、低速匀速响应、往复定位数据；
- 建立电机-驱动器-平台的简化模型；
- 识别摩擦、刚度、阻尼、延迟和噪声参数；
- 对比电机编码器闭环与光栅尺外部全闭环。

阶段输出：

- 单轴闭环实验数据；
- 系统辨识模型；
- PID/前馈参数整定依据；
- 开环、半闭环、全闭环对比结果。

### 阶段 4：多轴联动控制与误差补偿

关键任务：

- 扩展到二维或三轴联动；
- 建立坐标变换和轴间耦合模型；
- 做圆轨迹、矩形轨迹或栅格扫描实验；
- 建立误差表或补偿模型；
- 分析光栅尺安装误差、平台几何误差和同步误差。

阶段输出：

- 多轴联动闭环实验；
- 轮廓误差和同步误差分析；
- 补偿前后对比结果；
- 可写入论文的核心实验图表。

### 阶段 5：论文整理与成果固化

关键任务：

- 固化实验平台和操作流程；
- 汇总控制器参数、光栅尺参数和平台参数；
- 完成论文结构：系统设计、建模、控制、补偿、实验；
- 准备开题、中期和毕业答辩材料；
- 若数据充分，整理投稿或组内技术报告。

## 6. 当前需要李星辉确认的问题

下一次沟通不建议只问“我该怎么做”，而应带着这个研究计划请他确认边界：

1. 正式课题是否按“自建多轴运动平台 + 自研增量式光栅尺 + 闭环控制”作为主线；
2. 多轴平台最低做到二维还是三轴，是否需要 theta 自由度；
3. 最低验收指标先定微米级、亚微米级，还是必须向纳米级靠近；
4. 自研光栅尺当前能提供哪种输出接口、刷新率和样机；
5. 平台机械、驱动器、控制器由我主导选型采购，还是已有组内方案；
6. 是否能使用激光干涉仪或商业传感器做外部标定；
7. 近期 Renishaw/Z 轴验证结果是否可作为正式平台搭建前的阶段性成果。

## 7. 对李星辉的简明汇报口径

可以这样说：

> 李老师，我理解正式课题不应该只停留在恢复赖建君旧系统，而是围绕实验室自研的高精度增量式光栅尺，搭建一个精密运动控制平台，把自研光栅尺作为负载侧反馈接入闭环，实现高精度定位和多轴联动控制。
>
> 我的计划是分两步走。第一步先用现有 Z 轴和 Renishaw 光栅尺跑通最小闭环，解决光栅尺读数、驱动器控制、反馈方向、安全上电和数据记录这些基础问题。第二步再面向正式课题，设计和搭建二维或三轴运动平台，接入组内自研光栅尺，做建模、PID/前馈控制、误差补偿和多轴联动实验。
>
> 论文主线我想放在“自研光栅尺反馈下的精密运动平台建模与闭环控制”。创新点不是我重新做光栅尺硬件，而是把组里的光栅尺测量能力接入运动控制闭环，形成可量化的定位、跟踪和误差补偿结果。

## 8. 我当前的判断

这条路线比“只复现现有 Z 轴”更像正式硕士课题，也更接近李星辉长期想做的事情。但风险也更高，关键不确定项是：

- 自研光栅尺样机什么时候能给；
- 输出接口是否适合实时控制；
- 多轴平台是采购现成台体还是自己搭；
- 控制器是否支持多轴同步采样和外部光栅尺全闭环；
- 是否有外部高精度基准验证最终精度。

因此当前最合理的推进方式是：

```text
近期：Renishaw/Z 轴最小闭环验证
并行：自研光栅尺接口和正式平台方案确认
中期：搭建单轴/二维正式平台
后期：多轴联动、误差补偿和论文实验
```
