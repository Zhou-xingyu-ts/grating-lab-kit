# Servo Studio 参数卡与首次点动记录表

> 资料定位：这是 GM1 + EtherCAT + DS-BVM 候选路线中的 DS-BVM/Servo Studio 低风险验证表，不是当前现场已放行接线方案。  
> 适用场景：DINGS DS-BVM-FETC 驱动 `30ZWWC65TEK5B-1` 带刹车空心杯电机，电机增量编码器接 DS-BVM J201，GM1 通过 EtherCAT 后续给命令。本文只管“驱动器本体参数和第一次低速点动”，不替代 GM1 EtherCAT 主站配置，也不替代光栅尺 HSC0 验证。

这一步的目标不是让轴跑得快，也不是把电机调得很顺。目标只有一个：**在不猜参数、不冒险释放 Z 轴的前提下，让 DS-BVM 能安全识别电机、读到编码器、短时 Servo On，并完成一次可解释的极小点动。**

> **安全提醒：没有机械支撑，不允许 Servo On。**  
> Z 轴带刹车电机不是桌上的小风扇。刹车释放、电机出力方向错误、U/V/W 相序错误、编码器方向错误、极对数错误，都可能让平台突然下落或冲击。第一次操作必须有人守断电，点动距离和速度必须很小。

> 📎 DINGS 驱动器配套软件官方页：[DINGS Servo Studio](https://www.dingsmotion.cn/software/110-1.html#)  
> 请重点看软件安装包和 Servo Studio Manual。现场使用前确认软件版本、驱动器能否 USB 连接、参数是否能导入/导出。

> 📎 DINGS 驱动器手册官方页：[DINGS manual download](https://www.dingsmotion.cn/manual/109-2.html)  
> 请重点看 DS-BVM-FETC Hardware Manual 的 J201 编码器口、J101 U/V/W、J1 电源、J13 I/O，以及 DS-BVS/BVM Reference Manual 的 CiA 402 对象。

> 📎 DS-BVM-FETC 硬件手册直链：[DS-BVM-FETC Hardware Manual](https://www.dingsmotion.cn/uploadfile/2022/0509/20220509031426706.pdf)  
> 重点看 J201 digital encoder pin、J101 motor power、J13 digital I/O。它能证明端子名，但不能替你确认这台电机的极对数。

> 📎 DS-BVS/BVM 参考手册直链：[DS-BVS/BVM Series Reference Manual](https://www.dingsmotion.cn/uploadfile/2022/0509/20220509031529520.pdf)  
> 重点看 `0x6040/0x6041`、`0x6060/0x6061`、`0x6064`、`0x607D`、`0x607F`、`0x6081`、`0x6083`。这些对象后续 GM1 通过 EtherCAT 也要用。

## 先说清楚 Servo Studio 在这个项目里管什么

GM1 是主站，后面会通过 EtherCAT 给 DS-BVM 发命令。但第一次调驱动器时，咱们先用 USB 连 Servo Studio，因为它能直接看到驱动器参数、反馈、报警、Enable/Disable、Jog 和 Scope。

你可以这样分工：

| 工具/设备 | 在这一步做什么 | 不做什么 |
|---|---|---|
| Servo Studio | 设置电机类型、额定电流、极对数、编码器类型/CPR、低速 Jog、查看报警 | 不做 GM1 外闭环逻辑 |
| DS-BVM | 读电机编码器、驱动 U/V/W、报告 `0x6064` | 不读取平台光栅尺 |
| GM1 | 本阶段可不上 EtherCAT 或只做后续对账 | 不直接驱动 U/V/W |
| Renishaw 光栅尺 | 后续对账平台真实位移 | 不参与电机换相 |

师傅会提醒你：Servo Studio 里能点动，只能证明“驱动器和电机内环有机会工作”。它不能证明平台闭环已经完成。真正闭环要等 GM1 光栅尺计数也对上。

## 上软件前，先把硬件放行条件写出来

| 条件 | 为什么必须满足 | 证据填哪里 |
|---|---|---|
| DS-BVM 控制电源稳定 | 软件连接和参数读写依赖它 | `../../../../02_实验与现场/01_当前执行/40_逐线验收记录表.md` |
| 驱动器主电压按电机低风险策略给定 | 当前电机额定 24 V，首次不直接上 48 V | 本文件“电源卡” |
| U/V/W 三相无短路、对壳绝缘正常 | 防止一使能烧驱动器 | `40` 或现场绝缘记录 |
| 编码器 J201 pin 1-8 接线正确 | DS-BVM 必须知道电机位置 | `34/44/40` |
| 刹车独立 24 V 释放/抱闸已验证 | Z 轴不能靠猜 | `50` |
| Z 轴机械支撑和限位到位 | 防止下落/撞限 | 现场安全记录 |
| 极对数、编码器 CPR、额定电流有证据 | 参数错会抖动、报警、冲击 | 本文件参数卡 |

当前项目里，**极对数仍是未闭合项**。这意味着：可以连接 Servo Studio、导出参数、查看对象、检查编码器手转反馈；但在极对数和关键电机参数没有厂家/图纸证据前，不应把“正式 Servo On + 点动”当作已放行项目。

## 参数卡：先填表，再点按钮

不要打开软件就到处点。先把下面这张卡填完。

### 电机本体参数

| 参数 | 当前值 | 证据来源 | 是否允许用于首次 Servo On |
|---|---:|---|---|
| 电机型号 | `30ZWWC65TEK5B-1` | 电机/CAD/聊天资料 | 是 |
| 电机类型 | 待填：Sinusoidal PM BL / Trapezoidal PM BL / 其它 | 电机厂家或 DINGS 建议 | 未确认前不放行 |
| 额定电压 | `24 V` | 已有电机参数/照片证据 | 可作为首次低压上电边界 |
| 额定电流 | ____ A | 电机参数表/厂家 | 未填不放行 |
| 峰值电流/最大电流 | ____ A | 电机参数表/厂家 | 未填不放行 |
| 极对数 Pole Pair | ____ | 完整图纸或厂家确认 | 未填不放行 |
| 额定转速 | ____ rpm | 电机参数表/厂家 | 用于限速参考 |
| 刹车电压 | `24 V` | 现有资料 | 可做独立刹车测试 |
| 刹车电阻/电流 | ____ ohm / ____ A | 现场实测 | 未测不释放 |

DINGS Servo Studio 手册里 Motor Setting 说明 `Pole` 是永磁体磁极数，`Pole Pair` 是极对数，并举例 `8 Pole Motor -> Pole Pair = 4`。注意，这只是示例，不是本项目电机参数。你不能因为例子是 4，就把这台电机也填 4。

### 编码器反馈参数

| 参数 | 当前值 | 证据来源 | 判断 |
|---|---:|---|---|
| 反馈类型 | Incremental Encoder with Index | 电机编码器 A/B/I 差分线已接 | 初步可用 |
| 编码器供电 | 5 V | DS-BVM J201 pin 1/2，现场测量 | 必测 |
| A 相 | J201 pin 3/4 | 电机线色与 DS-BVM 手册 | 必接 |
| B 相 | J201 pin 5/6 | 电机线色与 DS-BVM 手册 | 必接 |
| I/Z 相 | J201 pin 7/8 | 电机线色与 DS-BVM 手册 | 建议接 |
| CPR | ____ counts/rev | 编码器说明书/电机图纸 | 未填不放行 |
| Hall | 第一轮不选 | `HALL-` 接法未闭合 | 不接入 |

Servo Studio 手册明确说，使用 Incremental Encoder 时，分辨率按 CPR: Count per Revolution 设置；如果手册只给 PPR，通常 `CPR = PPR * 4`。这里也不能猜。比如看到“500 线”时，要问清它是 PPR、line count 还是已经是 CPR。

## Servo Studio 连接和备份

1. DS-BVM 控制电源上电。
2. USB 连接电脑和 DS-BVM。
3. 打开 Servo Studio。
4. 点击 `Connect`。
5. 先导出当前参数文件，命名建议：

```text
DS-BVM_30ZWWC65TEK5B-1_before_first_setup_YYYYMMDD.dss
```

6. 截图记录驱动器型号、固件版本、通信状态、当前报警。

为什么先备份？因为你不知道驱动器里有没有前一任调试人员留下的参数。备份不是为了以后照抄，而是为了出问题能回到“改之前是什么样”。

## Motor 页面怎么填

进入 `Drive Setup -> Motor`。

| 项目 | 首次建议 | 为什么 |
|---|---|---|
| Motor Type | 按厂家确认选择，未确认不保存 | BLDC/PMSM 类型影响换相和控制 |
| Rated Current | 填电机额定电流，首次可再限小 | 过大会过热，过小可能动不了但安全 |
| Maximum Current | 按电机/驱动允许值保守填 | 不能让驱动器无限出力 |
| Pole Pair | 只填厂家/图纸确认值 | 极对数错会导致电角度错误 |
| Torque/Back-EMF 常数 | 有证据再填 | 没证据先不要编 |

设置原则：

1. 有厂家数据的参数才填。
2. 不确定的参数宁可留待确认，不用“经验值”硬上。
3. 第一次只 `Apply`，不要立刻 `Save` 到 Flash。
4. 如果软件要求必须填某项才能继续，停下来找证据，不用随机值。

## Feedback 页面怎么填

进入 `Drive Setup -> Feedback`。

| 项目 | 首次建议 |
|---|---|
| Feedback mode | Single Feedback |
| Feedback type | Incremental Encoder with Index |
| Resolution | 填确认后的 CPR |
| Hall Sensor | 不选 |
| Direction Invert | 先不改，手转和点动后再判断 |
| Dual Feedback | 第一轮不启用 |

这里再次强调：平台光栅尺不在 DS-BVM Feedback 页面里配置。它已经接到 GM1 高速计数。DS-BVM 只用电机编码器做电机内环。

## 手转编码器检查：还不让电机出力

在 U/V/W 不使能、Servo Off 的状态下，做编码器体检。

1. DS-BVM 控制电源上电。
2. 编码器 5 V 在 J201 pin 1/2 实测正常。
3. Servo Studio 连接。
4. 打开能显示位置实际值的页面，或后续通过对象 `0x6064` 观察。
5. 手轻轻转电机轴或在机械允许范围内微动。
6. 观察位置值是否连续变化。
7. 正反两个方向都试。

| 现象 | 判断 |
|---|---|
| 手转位置连续增加/减少 | 编码器基本可读 |
| 位置不变 | 编码器供电、A/B/I、反馈类型或软件监视项有问题 |
| 位置跳变很大 | A/B 差分对、屏蔽、线序或分辨率配置有问题 |
| 正反方向不能稳定区分 | A/B 相序或读取方式异常 |

如果这一步不过，不允许 Servo On。驱动器连电机位置都看不清，出力就是风险。

## Phase Auto Tuning 和 Current Tuning：什么时候可以碰

DINGS Servo Studio 手册说明 Phase Auto Tuning 会自动寻找电机 UVW 相位，并且会启动电机；Current Tuning 也会让电机按设定动作或注入电流。因此第一次不能把它当成普通按钮随便按。

允许条件：

| 条件 | 说明 |
|---|---|
| Z 轴有机械支撑 | 防止调谐动作造成下落 |
| 刹车释放策略明确 | 刹车抱住时硬调谐可能报警或伤机构 |
| U/V/W、编码器反馈已通过死电和手转检查 | 否则调谐结果没有意义 |
| 极对数、额定电流、CPR 已确认 | 参数错误会让调谐动作危险 |
| 行程限位和断电手段明确 | 调谐可能产生运动 |

第一次项目验证更稳的路线是：先参数检查、手转反馈、短时 Servo On 稳定性，再做极小 Jog。调谐放在这些基础通过之后。

## 首次点动参数建议

第一次用 `Profile Velocity` 里的 Jog，原因是 Servo Studio 手册说明 Jog 勾选后，按住 `<` 或 `>` 才按输入速度运动，松开停止。这比连续运动列表更容易控制。

| 参数 | 首次建议 | 原因 |
|---|---|---|
| Operation Mode | Profile Velocity / Jog | 手按才动，松开停 |
| Speed | 极低速，先按电机/机构允许值保守设 | 方向未验证 |
| Acceleration | 很小 | 减少冲击 |
| Jog 时间 | 每次不超过 0.3-0.5 s | 不让错误扩大 |
| 电流限制 | 尽量保守 | 保护电机和机构 |
| 行程 | 只允许肉眼可控的小位移 | 方向/比例未闭合 |

不要用 Motion List 做第一次点动。Motion List 适合已经验证过的动作序列，不适合第一次探方向。

## 点动后怎么判断“可以进入 GM1 联调”

只有满足下面条件，才进入 `52_EtherCAT主站导入与PDO联调作业指导_GM1_DS-BVM.md` 的 PPM 小步：

| 条件 | 证据 |
|---|---|
| Servo Studio 能稳定连接 DS-BVM | 连接截图/记录 |
| 参数文件已导出备份 | 文件名记录 |
| 电机参数和反馈参数有证据 | 本文件参数卡 |
| 手转编码器计数连续 | 记录 |
| Servo On 短时无抖动、无未解释报警 | 记录 |
| 两个方向极小 Jog 都可停止 | 点动记录表 |
| DS-BVM 位置和 GM1 光栅计数方向关系已记录 | 三本账 |
| 刹车和机械支撑策略稳定 | 现场记录 |

如果只做到“软件连上了”，那还不能点动；如果只做到“电机转了”，那还不能闭环；如果只做到“驱动器位置变了”，但光栅尺没对上，那还不能说平台闭环跑通。

## 参数保存规则

Servo Studio 手册里 `Save` 是写入驱动器 Flash。第一次调试时遵守这个规则：

| 阶段 | 是否 Save 到 Flash |
|---|---|
| 刚填参数，还没验证 | 不 Save，只 Apply |
| 手转编码器通过，但未点动 | 暂不 Save |
| 首次 Servo On 稳定、Jog 方向可解释 | 可以考虑导出参数文件，仍谨慎 Save |
| 多次上电重复验证通过 | 再 Save 到 Flash |
| 有任何报警、抖动、方向疑问 | 不 Save |

为什么这么保守？因为错误参数写进 Flash 后，下次上电可能直接沿用。现场新人最容易忘记“上一次试错参数还在驱动器里”。

## 本文件当前未闭合项

| 项目 | 当前状态 | 关闭证据 |
|---|---|---|
| 极对数 | 未闭合 | 电机完整图纸或厂家确认 |
| 电机类型 | 未完全闭合 | DINGS/电机厂家确认 |
| 额定/峰值电流 | 需要以最终参数表核对 | 电机参数表 |
| CPR | 需要以编码器说明书/图纸核对 | 编码器说明书 |
| Phase Auto Tuning 是否需要 Hall | 未闭合 | DINGS 明确答复 |

这几个缺口不影响你用 Servo Studio 做连接、备份、参数页面学习、编码器供电检查和手转反馈检查；但它们会影响正式 Servo On、调谐和点动放行。工程上要把“能看软件”和“能让轴动”分开。

最后再复述一次现场准则：

> 参数有证据，编码器先手转，Z 轴先支撑，刹车先独立验证，Jog 先小到可以随时停。极对数、CPR、额定电流没闭合前，不把正式点动当作完成项。
