## 当前证据等级

| 项目 | 判断 |
|---|---|
| 赖建君原系统采用 STM32H7 + CANopen + PDO | 高置信 |
| 当前台架存在 STM32H743 板 | 高置信可见事实 |
| 当前台架由 STM32H743 通过 CANopen 控制 DINGS | 低置信，未闭合 |
| 当前可按 CANopen 直接现场接线 | 未放行 |

## 升级为当前台架方案前必须补齐

- 当前 STM32 板到 DINGS CAN 口的线缆照片、端子定义、CANH/CANL/GND/终端电阻。
- 当前 STM32 固件版本、工程源码、CANopenNode 配置和对象字典。
- CAN 收发器型号、供电、波特率、节点 ID 和实测 CANopen 报文。
- DINGS 驱动器 CANopen 对象读写、状态机、报警和使能逻辑。
- 共享硬件底座已放行：DS-BVM、电机 U/V/W、编码器、刹车、STO、电源和关键电机参数不能因切换到 STM32 而跳过。
