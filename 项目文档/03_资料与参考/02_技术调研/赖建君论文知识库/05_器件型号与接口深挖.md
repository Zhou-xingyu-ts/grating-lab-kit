# 器件型号与接口深挖

## 可信度标注

- 本 Markdown 文件本身是 AI 整理稿，不能作为一手证据。可信度标注评的是其背后所引用的原始资料，不评 Markdown 文字本身。
- 高：赖建君学位论文/毕业答辩 PPT 明确，且用于描述赖建君原系统；若外部官方资料也一致，则可作为器件型号/参数的强证据。
- 中：论文/PPT明确 + 外部资料找到同系列或高度相近型号，但存在型号位数、厂商字段或版本差异。
- 低：论文未给型号，或仅找到第三方资料。

说明：论文/PPT对“原系统用了什么、怎么做实验”具有高置信度；外部资料主要用于解释型号体系、接口定义和当前接线，不应把论文/PPT信息简单视作 AI 推测。

当前台架另设一套置信度：照片、铭牌、纸质接线页和现场测量优先于论文/PPT，因为它们描述的是现在手上的实物；论文/PPT只在确认“这就是赖建君原系统原件”时才可直接迁移到当前台架。凡是由接口匹配推出来的链路，只能写成工程推测，不能写成已接线事实。
