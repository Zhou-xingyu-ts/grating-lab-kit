# 对我实验的可用结论

## 目标定位

赖建君论文对当前实验最大的价值，不是提供一个可以照抄的三轴平台方案，而是给出一套工程上可信的闭环运动验证路径：先把运动轴的误差测出来，再区分确定性误差、周期误差和随机误差，最后用闭环控制和误差补偿把定位结果拉到微米级。

你当前目标是 2026-06-15 前完成单轴、低速、微米级最小闭环演示。这个目标与论文第 4.1 节高度同构，但尺度要收缩：论文做 -10 mm 到 10 mm 全行程、0.5 mm 步进和亚微米结果；你先做 0-100 µm 或 ±50 µm，再扩到 0-500 µm 或 0-2 mm。

## 第一优先级：闭环链路跑通

最小闭环不要从“控制算法先进性”开始，而要从信号链路开始：

```text
目标位置 -> 运动命令 -> 平台运动 -> 光栅尺读数 -> 误差计算 -> 修正命令 -> CSV日志
```

只要这条链路跑通，就已经证明“自研光栅尺可进入运动控制闭环”。这正好对齐李星辉给出的创新锚点：自研光栅尺反馈，而不是算法原创。

## 当前台架先按实物链路排查

2026-05-28 的现场照片显示，当前更可操作、置信度更高的排查方向不是“先找 STM32 程序”，而是优先确认：

```text
PC/工程软件 -> Panasonic GM1 CSEC16T -> EtherCAT -> DINGS 驱动器 -> 30ZWWC65TEK5-1 电机
```

DINGS 驱动器按伺服驱动器角色负责电流环/换相/电机反馈，Panasonic GM1 更像运动主站。STM32H743 板目前只能作为“可能的采集/转接/控制板”记录，不能作为上电接线前提。

因此现场推进顺序应调整为：

1. 先确认 GM1 供电、工程软件、EtherCAT 工程和 DINGS 从站是否能扫描到。
2. 再确认 DINGS 主电源、M4 U/V/W、M6 编码器/霍尔、M9 Enable/STO/限位。
3. 电机参数按图纸录入：24 V、3.85 A、6900 rpm、2 极对、1000 CPR、90 mN·m。
4. STM32 板只有在确认其线缆、固件和接口后再纳入控制链路。

当前最不能猜的是 DINGS 的 M4/M5/M6/M9 pinout 和主电源规格；这些缺失前不应带电试电机。

按置信度重排后的现场行动原则：

| 事项 | 置信度 | 行动 |
|---|---|---|
| 电机型号和基础参数 | 高 | 可先用于 DINGS/GM1 参数录入准备，但不等于可以直接上电 |
| DINGS 是驱动器接口/功率组件 | 高 | 围绕 M4/M5/M6/M9 查 pinout 和安全链路 |
| GM1 是 EtherCAT 运动控制器 | 高 | 先找 GM1 供电、软件项目、EtherCAT 扫描入口 |
| `GM1 -> DINGS` 是当前主链路 | 中-高 | 优先排查，但需扫描结果和工程文件确认 |
| STM32H743 是当前主控 | 低 | 暂不作为接线前提，只作为后续核验对象 |
| 本目录 Markdown 的旧链路判断 | 低 | 只用于列问题，不用于接线 |

## 第二优先级：先低速短行程

论文的高速扫描设计来自 10 mm x 10 mm 区域和 120 s 扫描时间约束，因此 x 轴最大速度推到 150 mm/s。这不是你第一阶段要复制的工况。你的第一轮实验应压低速度和行程：

- 首轮行程：0、+10、+50、-10、-50 µm。
- 线性测试：0、20、40、60、80、100 µm。
- 扩展测试：0、100、200、300、400、500 µm。
- 若平台和光栅稳定，再做 0-2 mm，观察一个丝杠导程周期。

这样能避免一开始被平台惯性、限位、接口延迟和安装风险拖住。

## 第三优先级：把误差当作实验对象

论文第 4.1 节最值得迁移的是误差处理顺序：

1. 用外部基准测定位误差。
2. 看误差是否随位置单调变化。
3. 先补偿余弦误差或低阶趋势项。
4. 再看残余误差是否有丝杠导程周期。
5. 若残余误差可重复，用查找表 + 线性插值补偿。

如果没有激光干涉仪，也可以先做“自洽版”：

- 记录光栅尺反馈下的闭环到位误差。
- 做同一目标点多次重复。
- 做正向/反向到达对比。
- 做静止漂移。
- 等有基准后再补绝对误差。

不要把没有外部基准的数据包装成“定位精度”，可以称为“闭环重复性”“反馈稳定性”“相对定位一致性”。

## 光栅尺相关实验问题

赖建君论文显示，光栅尺即使用于闭环，也不能自动消除全部定位误差。余弦误差、阿贝误差和丝杠周期误差仍然存在。对你来说，光栅尺部分必须问清：

- 输出是数字位移值、TTL A/B/Z、模拟 sin/cos，还是专用协议？
- 读头和尺身是否一套？是否需要插补器？
- 供电电压、电流和地线隔离要求是什么？
- 实际输出刷新率是多少？
- 安装间隙、偏摆、读头姿态容差是多少？
- 光栅尺读数轴和平台运动轴的偏置距离是多少？
- 上位机或 SDK 能否导出 timestamp + displacement？

论文中 `RCLC A-9404-2030` 的外部证据指向 Renishaw RCLC 玻璃尺，但论文写成 HEIDENHAIN。这个冲突提醒你：在自己的实验里必须拍实物铭牌、记录读头型号、插补器型号和线缆接口，不能只记录“光栅尺”三个字。

## 控制策略建议

6 月 15 前建议采用三阶段控制：

### 阶段 1：开环运动

目标是确认平台能按小位移命令运动，不撞限位、不丢通信。记录每次命令后光栅尺变化量。此时不追误差，只确认方向、比例和重复性。

### 阶段 2：低速 P/PID 外环

用光栅尺读数计算目标误差，低频发送修正命令。控制周期可以先从 50-100 ms 级开始，目标是稳定到 ±10 µm，再逐步提高频率和收敛速度。

### 阶段 3：误差表补偿

当闭环能稳定后，做多点误差表。若误差可重复，用线性插值做前馈补偿，再由闭环做残差修正。这个阶段比直接上 LQR 更适合最小演示。

LQR 和全状态反馈可以作为后续研究内容。论文的 LQR 结论依赖模型参数，当前不应成为演示前置条件。

## 实验记录模板

每次实验必须留下可复盘数据：

```text
date, axis, mode, target_um, command_um, grating_um, error_um,
direction, settle_ms, loop_period_ms, gain, filter, notes
```

如果接入基准：

```text
reference_um, grating_minus_reference_um
```

每次改变控制参数、滤波、步进死区、机械安装，都要记录版本。否则后面无法判断“变好”来自控制，还是来自安装。

## 可引用论点

后续和导师沟通或写综述时，可以从论文中提炼这些论点：

- 高精度运动平台不能只看电机端反馈，负载侧光栅尺反馈能直接观测真实位移。
- 光栅尺全闭环仍受安装误差和机械误差影响，需要标定和补偿。
- 余弦误差属于确定性误差，可通过标定模型补偿。
- 阿贝误差与测量轴线偏置相关，主要靠结构和安装降低。
- 丝杠周期误差可通过重复标定、查找表和线性插值补偿。
- 先做微米级最小闭环，再升级控制器和模型，是工程上合理的路线。

## 风险项

最可能拖慢实验的不是 PID，而是接口和安装：

- 光栅尺输出接口不清，无法实时读数。
- 读头、尺身、插补器不是一套。
- 平台控制器不支持小位移相对运动。
- 光栅尺安装偏角或偏置太大，误差曲线不可重复。
- 上位机没有可靠时间戳，无法分析闭环响应。
- 限位和急停没有先验证，实验范围不敢放开。
- 当前台架把论文链路误当实物链路，例如误以为 STM32H7 一定是主控、误以为 DINGS 当前一定走 CANopen。
- DINGS 主电源、电机相线、编码器/霍尔和 Enable/STO pinout 未确认就上电。

因此下一次找李星辉或平台负责人时，重点不应问“用什么算法”，而应带着接口、实物、线缆、刷新率、安装容差和最小运动命令的确认表去锁定资源。
