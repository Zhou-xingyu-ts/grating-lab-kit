# 接线检查表

> 对照此表逐段检查接线。每完成一项打 ✅。
> 来源：`32_Z轴单轴闭环执行清单.md` + `31_DINGS_DS-BVM_接线梳理.md`

---

## 段①：读数头 → 插补器

- [ ] 读数头 ATOM2T1-050 的白色塑料接头已插入 Ri0040
- [ ] 接头方向正确、无弯针
- [ ] 插补器面板标注 "Readhead" / "Input" / "Encoder In" 确认

## 段②：插补器 → 控制器

- [ ] D-sub 15针/9针屏蔽线已连接 Ri0040 输出口
- [ ] 另一端已连接 AGMICSEC16T 的编码器输入口
- [ ] 两侧螺丝已拧紧
- [ ] 确认输出信号类型：RS422 A/B/Z / BiSS / 串行协议（标注：________）

## 段③：控制器 → 驱动器（EtherCAT / CANopen）

- [ ] 控制器 RJ45/端子实际协议已确认：EtherCAT / CANopen / 其他（圈一个）
- [ ] 若为 EtherCAT：控制器 TX± 接 DS-BVM M11 Rx±，控制器 RX± 接 DS-BVM M11 Tx±
- [ ] 若为 EtherCAT：控制器接 DS-BVM `M11 Input`，不是 `M10 Output`
- [ ] 若为 CANopen：CANH 对 DS-BVM CAN HIGH，CANL 对 DS-BVM CAN LOW，GND 对 GND
- [ ] 若为 CANopen：控制器端 120Ω 终端电阻：已开启 / 跳线帽已插 / 外接（圈一个）
- [ ] 若为 CANopen：驱动器端 120Ω 终端电阻：已开启 / 跳线帽已插 / 外接（圈一个）
- [ ] 总线线缆为双绞屏蔽线，屏蔽层单端接地

## 段④：驱动器 → 电机

- [ ] 动力线 U/V/W 三相：颜色 → 端子 —— U(___色) V(___色) W(___色)
- [ ] 霍尔/编码器反馈线：排针接头已插入，方向正确
- [ ] 电机端航插已拧紧
- [ ] 确认电机型号为 `30ZWWC65TEK5B-1`（带刹车版），动力/反馈线不与刹车线混接

## 段⑤：刹车电源 → 带刹车电机

- [ ] 刹车线圈已用万用表确认，线色/端子记录：________
- [ ] 刹车电源为独立 24 V，不接 DS-BVM U/V/W、电机反馈 5V 或编码器口
- [ ] 已确认释放逻辑：通电释放 / 断电释放 / 待确认（圈一个）
- [ ] Z 轴释放刹车前已有机械支撑、限位或防坠措施
- [ ] 首次释放刹车时采用限流/串保险，并有人值守急停
