# 方向符号确认表

> 每次重新接线、换轴、或换平台后必须重新确认。来源：`22_实际接线与上位机操作SOP.md` 第4.1节

---

## 测试步骤

1. 光栅尺上位机开始实时显示
2. 记录当前光栅尺位置 = `pos_before`
3. 平台上位机执行 **+10 µm** 相对运动
4. 等待运动完成，记录光栅尺位置 = `pos_after`
5. 计算变化量：`Δ = pos_after - pos_before`

## 判断规则

| Δ 符号 | 含义 | direction_sign |
|--------|------|---------------|
| Δ > 0 | 平台 + 命令 → 光栅读数增加 | **+1** |
| Δ < 0 | 平台 + 命令 → 光栅读数减少 | **-1** |
