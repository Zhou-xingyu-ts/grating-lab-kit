# 04_表格模板

CSV 和 Markdown 格式的检查表、记录表、决策表模板。现场打印或 Excel 打开使用。

## 文件

| 文件 | 用途 |
|------|------|
| `16_硬件资源清单模板.csv` | 光栅尺、平台、控制器、驱动器资源跟踪 |
| `17_闭环测试记录模板.csv` | 闭环测试日志格式 |
| `20_器件选型决策表.csv` | 器件选型决策 |
| `23_接线检查表.csv` | Excel 版接线检查 |
| `24_上位机联调记录表.csv` | 上位机联调记录 |
| `25_接线检查表.md` | Markdown 版接线逐段检查 |
| `26_方向符号确认表.md` | 光栅方向标定模板 |
| `27_闭环测试记录模板_v2.csv` | 闭环测试 CSV v2 |
| `28_ServoStudio_Scope_CSV记录模板.md` | Servo Studio Scope 导出 CSV 的来源、列名、截图和结论边界记录 |

## 使用规则

- 模板供现场打印或 Excel 打开填写，填写后的事实记录回填到 `02_实验与现场/01_当前执行/40_逐线验收记录表.md`
- 修改模板时保留字段结构，不删除列
