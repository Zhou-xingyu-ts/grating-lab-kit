# Motion Acquisition V3.0 Windows 部署

## 复制

复制整个：

```text
release\MotionAcquisition\
```

不要只复制 `MotionAcquisition.exe`。目录内的 `_internal`、文档、配置示例和依赖清单都要保留。发布目录不依赖源码路径、固定用户名或固定盘符。

## 启动

1. 在目标 Windows 电脑解压到普通可写目录。
2. 双击 `MotionAcquisition.exe`。
3. 确认标题显示 V3.0。
4. 首次使用“三轴控制（SIL）”时，不需要 CAN 驱动或硬件。
5. 用户设置和数据按当前 Windows 用户保存，不与其他账号共用。

如果 Windows SmartScreen 提示未知发布者，应按本单位软件分发规定核对 `SHA256SUMS.txt` 后决定是否运行。本项目未提供代码签名。

## 真实只读采集

V3 没有真实三轴控制适配器。只有既有 V2 CANopen SDO upload 采集可能需要：

- PEAK PCAN 驱动；
- PCAN-USB；
- 已由现场文件放行的 Node-ID、波特率和只读对象。

安装驱动、连接硬件和现场采集不属于本机 SIL 验收。

## 目标电脑检查

- EXE 能启动且显示九个顶层页面；
- “三轴控制（SIL）”能连接模拟器、使能/回零、执行任务、保存和分析；
- Demo 能启动、停止并生成 16 列 CSV；
- 旧会话能扫描、回放和分析；
- 数据写入当前用户选择的目录；
- 不出现构建电脑用户名、盘符或源码路径；
- 真实控制页面不存在，模拟器边界清晰。

## 当前证据限制

V3.0 发布包只在构建电脑完成自动测试、软件在环冒烟和启动检查。尚未在第二台 Windows 电脑或干净虚拟机实测，也未连接真实控制器、CAN/USB 或运动硬件。
