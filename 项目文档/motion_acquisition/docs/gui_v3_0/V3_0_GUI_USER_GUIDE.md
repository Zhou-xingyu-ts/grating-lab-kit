# Motion Acquisition V3.0 GUI 使用教程

V3.0 把 V2.0 采集、回放、分析和研究平台扩展为三轴软件在环控制工作站。全部日常操作都可在 GUI 中完成，不需要命令行。

## 先理解红色边界

“三轴控制（SIL）”只连接程序内的模拟实时控制器。页面上的使能、回零、Jog、定位、停止和急停不会发送到 CAN、USB、EtherCAT、驱动器或 Servo Studio。

模拟器结果只能证明上位机的软件逻辑、记录和异常流程可以运行，不能证明真实设备安全、精度、实时性或同步性。真实 CANopen 路径仍只允许 V2 的 SDO upload 采集。

## 启动

1. 保留发布目录内全部文件。
2. 双击 `MotionAcquisition.exe`。
3. 确认标题为 `Motion Acquisition V3.0`。
4. 程序不会自动探测或连接硬件；采集页默认仍是 Demo。

## 完成一次三轴 SIL 控制实验

1. 打开“实验工作台”，确认用户数据目录。
2. 如需关联已有采集，先到“会话管理与分析”点击刷新。
3. 打开“三轴控制（SIL）”。
4. 输入控制记录名称；可选一个 V2 采集会话作为关联。
5. 点击“连接模拟控制器并开始记录”。
6. 对 X、Y、Z 逐轴执行“使能”和“回零”。
7. 选择以下任一种操作：
   - 按住 `Jog −` 或 `Jog +`，松开即提交 Jog 停止；
   - 输入目标和速度，点击“绝对”或“相对”；
   - 在“同步任务与故障注入”输入三个目标，点击“执行三轴任务”。
8. 观察三轴状态、位置、速度、任务状态、曲线、命令确认和事件。
9. 点击“完成并保存”。如果是人工中止验证，点击“停止并保存”。
10. “历史控制记录”可刷新、选择和定位已有记录目录；点击“分析最近控制记录”可对当前选中记录生成 JSON、CSV 和 Markdown 三种摘要。

## 软限位和操作门禁

- X/Y 的合成范围默认是 `-50…50 mm`，Z 默认是 `0…25 mm`；这些只是模拟配置。
- 超限目标先由 PC 服务拒绝，模拟控制器还会独立复核。
- Jog 和定位前必须先使能并完成模拟回零。
- 故障后先“复位故障”，轴仍保持去使能状态，需要重新使能/回零。
- “模拟急停”锁存所有轴；复位后所有轴仍保持去使能。

这些规则不等于真实设备安全策略，不能用于现场放行。

## 故障注入

“同步任务与故障注入”可注入：

- 指定轴模拟故障；
- 连续两次通信超时；
- 通信断开；
- 模拟急停。

故障注入通过独立诊断口进入模拟器，不属于正常控制器业务接口。连续超时或断连会把控制记录收尾为 `error`。

## 控制记录在哪里

控制记录保存在当前用户数据目录：

```text
control_sessions/
  YYYY/
    MM/
      timestamp_name_control-.../
```

每个终态记录含 manifest、命令、确认、反馈、事件、任务、日志和校验账本。关联 V2 采集时只保存相对路径与 CSV SHA-256，不修改原始采集文件。

## V2 功能

原有“实时采集”“实时曲线”“会话管理与分析”“研究与算法”“历史回放”“预设与换算”全部保留。Demo 和只读采集的操作方式不变，`samples.csv` 仍是 16 列 raw 权威数据。

## 关闭程序

关闭窗口时，程序会停止模拟控制会话、完成记录收尾并关闭工作线程。真实采集页面的“停止采集”仍只停止读取，不会停止现场电机。
