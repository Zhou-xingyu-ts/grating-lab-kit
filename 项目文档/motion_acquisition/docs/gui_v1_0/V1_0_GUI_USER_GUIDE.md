# Motion Acquisition V1.0 零命令行使用教程

## 1. 软件定位

Motion Acquisition V1.0 是 Windows 精密运动实验数据工作站。它把实验项目、只读采集、实时数值与曲线、人工事件、历史会话、回放、分析、比较和交付导出放在同一个 GUI 中。

永久安全边界：

- 真实设备路径只允许 CANopen SDO upload。
- 没有 SDO download、控制字写入、NMT 写入、PDO 配置、EtherCAT 或运动命令。
- “停止采集”只停止上位机读取并完成文件收尾，不会停止电机。
- 运动仍由 Servo Studio 独立操作。
- raw counts 和 16 列 `samples.csv` 始终是权威数据；换算值始终标为“未验证换算”。

## 2. 启动

1. 打开完整的 `MotionAcquisition` 发布目录。
2. 双击 `MotionAcquisition.exe`。
3. 不需要安装 Python，也不需要打开命令行。
4. 程序默认进入 Demo，不会自动连接 CAN。

## 3. 第一次使用：建立实验项目

1. 打开“实验工作台”。
2. 填写项目名称；项目编号、默认操作者、说明和备注可选。
3. 点击“新建项目”。
4. 项目只用于组织会话和记录上下文，不会把任何字段发送给设备。
5. 不希望分类时可以保留“未归类（兼容模式）”。

项目采用稳定 ID 保存，新会话位于：

```text
数据根目录/
  projects/
    project-xxxxxxxxxxxx/
      YYYY/
        MM/
          会话目录/
```

修改或删除项目配置不会修改、移动或删除历史会话；每个会话的 manifest 保存项目快照。

## 4. Demo 完整流程

1. 在工作台选择项目，点击“进入采集”。
2. 数据源保持“Demo（无硬件）”。
3. 选择采集预设，或直接设置对象、采样周期和持续时间。
4. 填写实验名称和实验记录字段。
5. 可选一个 counts 换算配置；界面会同时显示 raw counts 和“未验证换算”。
6. 点击“开始采集”。
7. 采集中可以点击“运动开始”“运动结束”“方向切换”“异常”，或输入自定义备注。
8. 点击“停止采集”，或等待自然完成。
9. 软件会后台完成 manifest 和 SHA-256 收尾，然后自动扫描会话。

## 5. 真实 PCAN/CANopen 只读采集

真实采集只在现场条件允许时执行：

1. 安装 PEAK PCAN 驱动，并用厂商工具确认适配器。
2. 当前已知现场值为 `pcan`、`PCAN_USBBUS1`、`1 Mbps`、Node-ID `1`；若现场证据更新，以新证据为准。
3. 选择“真实 PCAN/CANopen”。
4. 点击“连接”。
5. 选择对象，点击“只读通信测试”。
6. 全部选中对象 SDO upload 成功后才能开始真实采集。
7. 上位机不控制运动。运动开始/结束按钮只是人工事件时间标记。

## 6. 会话文件

V1.0 正常会话包含：

```text
samples.csv
manifest.json
acquisition.log
config_snapshot.yaml
events.jsonl
checksums.sha256
```

- `samples.csv`：固定 16 列，只保存原始采集数据。
- `manifest.json`：项目、实验、预设、换算、软件/主机版本、采集配置、统计和 outcome。
- `acquisition.log`：会话打开、收尾和恢复日志。
- `config_snapshot.yaml`：本次只读采集配置快照。
- `events.jsonl`：上位机人工事件，按点击顺序逐条刷新。
- `checksums.sha256`：上述会话文件的收尾校验和。

旧会话没有项目、事件、换算或校验和时仍可正常加载，并显示为“未归类”或“未校验”。

## 7. 工作台与会话健康

点击“扫描并检查数据”后，工作台显示：

- 会话总数；
- completed、stopped、error 数量；
- 待恢复的 incomplete 会话；
- 损坏、不兼容或 SHA-256 不一致的会话；
- 最近八个会话。

SHA-256 不一致时软件不会修改源文件，也不会把该会话当作正常交付数据。

## 8. 分析、比较与回放

在“会话管理与分析”中：

- 可按项目、日期、实验名称、方向和 outcome 筛选；
- 单会话分析在后台运行，可取消；
- 可比较 2～5 个会话；
- 可导出 JSON、CSV 和 Markdown 三种分析摘要；
- 可直接打开历史回放或定位目录。

回放页支持：

- 变速播放和轮次跳转；
- 人工事件列表和曲线竖线；
- 点击事件跳到对应轮次；
- 查看完整性、项目、预设、换算和 SHA-256 状态；
- 将 `in_progress` 会话明确标记为 `recovered_incomplete`；
- 导出不包含 `samples.csv` 的支持诊断包。

## 9. 导出 V1.0 交付包

1. 在会话表选择一个或多个会话，一次最多 20 个。
2. 点击“导出 V1.0 交付包”。
3. 选择 ZIP 保存位置。
4. 导出在后台运行，可以取消；取消后不会留下伪装成完整结果的 ZIP。

交付包包含：

- 每个会话的原始文件；
- 每个会话的完整性报告；
- 每个会话的三种分析摘要；
- `bundle_manifest.json`；
- `README.md`；
- 包内文件 `SHA256SUMS.txt`。

导出不会修改源 `samples.csv` 或 manifest。

## 10. 本机环境诊断

在“帮助”页点击“刷新本机环境诊断”，可查看：

- 软件与 Python/Windows 版本；
- 当前用户配置路径；
- 数据目录是否存在和可写；
- 已保存项目数和已扫描会话数；
- 关键依赖版本；
- 只读安全边界。

可以保存 `product_diagnostics.json` 供部署排查。该诊断不会探测 CAN/USB 硬件。

## 11. 常见情况

- 开始按钮不可用：真实模式需要先连接并通过只读测试；Demo 可直接开始。
- 停止后目录未立即出现：等待状态变为 stopped/completed/error，收尾包含校验和计算。
- 显示“未校验”：通常是 V1.0 以前的兼容会话，不代表 CSV 已损坏。
- 显示“mismatch”：受保护文件与收尾 SHA-256 不一致，应保留原文件并导出诊断，不要覆盖。
- 换算值不是正式标定：任何时候以 raw counts 为准。
