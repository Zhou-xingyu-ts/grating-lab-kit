# V2.0 从采集数据到研究结论

本文给出 V2.0 推荐研究链及指标边界。平台的目标是让结果可复现、可追溯，而不是在证据不足时自动生成物理结论。

## 1. 四类结果必须分开

| 类别 | 典型内容 | 可以说明 | 不能说明 |
|---|---|---|---|
| 数据直接支持 | CSV 行、轮次率、失败数、时间间隔、观测范围 | 保存数据自身的性质 | 驱动器内部时序、绝对精度 |
| 离线算法输出 | 滤波、漂移拟合、补偿表、仿射模型 | 给定输入和参数下的计算结果 | 上线闭环效果 |
| 影子输出 | 实时/历史 PID 建议值 | 只读数据下的建议序列 | 已发送或改变设备 |
| 待验证假设 | 参数假设、未来总线、外部环 | 后续实验方向 | 已被现场证实 |

## 2. 时间语义

V2.0 新会话显式记录：

- 时间来自主机 `time.perf_counter` 和本地 wall clock；
- 时间戳范围是一个 `sample_seq` 的主机轮次起点；
- 同一轮各对象共享轮次时间戳；
- 没有设备时间戳、没有时钟同步、不是硬实时；
- deadline miss 表示该轮执行时间超过目标周期，不等于精确丢失了多少理想节拍。

分析主时间轴使用 `elapsed_s`。wall time 只用于人类日期/事件关联。

## 3. 数据质量

质量评价只读 CSV 和 manifest，使用流式统计与最多 10,000 个间隔样本的确定性分位数缓存。

主要指标：

- 实际采样频率：有效轮次首末 `elapsed_s` 间隔的倒数关系；
- interval min/max/mean/std、p50/p95/p99；
- 缺失或倒退的 `sample_seq`；
- 同轮同对象重复、对象覆盖率和不完整轮次；
- 失败读取总数与最大连续失败段；
- manifest 中的 deadline miss；
- wall clock 解析、倒退及其相对 monotonic 的漂移。

状态：

- `good`：按当前规则没有 warning/error；
- `warning`：可用但存在失败、间隔、覆盖或旧时间语义等问题；
- `insufficient`：轮次少于 3；
- `unusable`：无有效轮次或关键序列/时间错误。

这是主机保存数据质量，不是运动性能等级。

## 4. 标定与精度术语

线性仿射标定：

```text
physical_value = scale × raw_counts + offset
```

证据等级：

- `draft`：工程假设、厂家规格、缺少外部基准或不可追溯；
- `externally_referenced`：每个拟合点都关联可追溯的外部长度基准。

必须分别记录：

- 分辨率：最小数值步进或编码关系；
- 换算关系：counts 到单位值的映射；
- 测量精度：测量值相对基准的误差能力；
- 重复定位精度：重复达到同一目标的离散程度；
- 绝对定位精度：位置相对外部坐标基准的误差。

拟合只产生换算和残差，不自动产生后四类能力声明。无外部证据的 `10000 counts ≈ 5 mm` 只能保存为草稿。

## 5. 成组实验

一个实验组包含 2～20 个会话。每个引用保存相对路径、CSV SHA-256、方向、速度、加速度和重复序号。

推荐实验：

- 重复实验：同协议、同方向、同速度/加速度，多次执行；
- 正反向：成对正向/反向，观察方向差和闭合偏差；
- 速度阶梯：保持其他变量，改变记录的速度条件；
- 加速度阶梯：保持其他变量，改变记录的加速度条件；
- 稳定性/漂移：保持静止或固定状态，延长采集。

当前评价定义：

- 观测位移：末段位置均值减初段位置均值，每段最多 50 个成功点；
- 终点：末段位置均值；
- 末段稳定性：末段位置总体标准差；
- 漂移：末段位置对时间的最小二乘斜率；
- 跟随误差：成功点的均值、RMS 和最大绝对值；
- 速度峰值：成功点的最大绝对值；
- 重复性：组内观测位移/终点的描述性离散；
- 方向差：正反向组汇总和闭合偏差；
- 速度/加速度条件：按实验记录字符串分组的描述性摘要。

没有外部目标位置或基准测量时，不称为定位精度。标定换算保留原证据等级。

## 6. 离线算法

| 算法 | 输入 | 主要输出 | 证据边界 |
|---|---|---|---|
| moving_average | 指定对象 | 有界窗口平均序列 | 离线滤波，不改变源 CSV |
| linear_drift | 指定对象+时间 | 斜率、截距、残差 | 描述所选区间，不证明长期稳定 |
| trajectory_kinematics | position_actual | 差分速度/加速度 | 主机采样下的离线估计 |
| error_compensation_map | position+following error | 位置分箱均值误差 | 同数据代数影子评价，非独立验证 |
| affine_error_model | position/velocity/following error | 仿射系数与残差 | 描述性模型，不是设备模型证明 |
| shadow_pid | following_error | P/I/D 和限幅建议值 | 永不发送设备，无闭环效果声明 |

每次运行写出源 CSV SHA-256、参数、可选标定快照、算法版本、代码指纹、reproducibility fingerprint、派生序列和校验账本。任务取消时不发布 `.part` 结果。

## 7. 推荐判读顺序

1. 先检查完整性和 SHA-256；
2. 再检查时间语义与数据质量；
3. 确认实验记录和对象是否足够；
4. 明确是否使用标定、标定证据等级；
5. 先做单会话直接指标，再做成组描述；
6. 最后运行离线算法；
7. 若要提出硬件/控制结论，另行设计独立现场验证。

任何一步出现缺对象、时间不足、源哈希变化或证据不够，都应保留“不具备该数据/待验证”，不能补造数值。
