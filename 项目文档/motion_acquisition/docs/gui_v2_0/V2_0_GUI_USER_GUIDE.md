# Motion Acquisition V2.0 GUI 使用教程

V2.0 是只读采集、实验比较和离线算法验证平台。日常使用只需双击 `MotionAcquisition.exe`，不需要命令行。程序默认选择 Demo，不会自动探测或连接硬件。

## 1. 先理解三个边界

1. `samples.csv` 的 raw counts 是权威输入，物理换算和算法结果都不会回写它。
2. 实时“影子”只计算建议值并保存，绝不发送到设备；它不是控制效果证明。
3. “停止采集”只停止读取和保存，不停止 Servo Studio 或驱动器中的运动。

## 2. 新建项目与准备实验

在“实验工作台”新建或选择项目。项目只组织会话，不改变设备。

进入“实时采集”：

- 选择 Demo 或真实只读模式；
- 填写实验名称、操作者、轴、方向和运动参数记录；
- 选择采集对象、周期和持续时间；
- 可选择 V0.5 采集预设和“未验证换算”；
- 可选择一个 V2 标定快照和实验组。

运动参数、预设、标定和实验组只作为界面输入或会话快照，不发送运动命令。

## 3. 建立 counts 标定

打开“研究与算法 → 标定证据”。

1. 填写名称、轴和物理单位。
2. 每行输入一个参考点：`raw_counts, physical_value[, reference_uncertainty]`。
3. 如果有可追溯的外部长度基准，填写证据来源、选择“外部长度基准”并勾选“证据可追溯”。
4. 只填写近似关系或工程假设时保持为草稿。
5. 点击“拟合并保存”。

V2.0 只拟合：

```text
physical_value = scale × raw_counts + offset
```

软件会给出残差，但不会由拟合自动声称测量精度、重复定位精度或绝对定位精度。`10000 counts ≈ 5 mm` 在没有外部证据时只能得到“草稿换算”。

## 4. 采集与实时影子

常规 Demo：

1. 选择 Demo；
2. 设置对象、周期和持续时间；
3. 点击“开始采集”；
4. 可添加人工事件；
5. 等待自然完成或点击“停止采集”。

实时影子：

1. 在“研究与算法 → 离线算法与影子”勾选只读 PID 影子；
2. 设置 `Kp/Ki/Kd`、限幅和输出单位；
3. 在采集对象中必须勾选 `following_error`；
4. 开始采集。

GUI 显示限频副本，worker 将完整影子序列写入 `shadow_outputs.jsonl`。影子输出没有设备写通道。

真实 PCAN 模式仍然只有：

```text
连接 → 逐对象 SDO upload 测试 → 开始只读采集 → 停止/完成 → 断开
```

现场必须独立确认 PCAN_USBBUS1、1 Mbps、Node-ID 1 和安全条件；当前离线验收不代表这些项目已通过。

## 5. 判断数据质量

采集或扫描会话后，进入“研究与算法 → 时间与数据质量”。

1. 选择会话。
2. 点击“评估并导出质量报告”。
3. 查看状态、实际轮次率、间隔抖动/分位数、失败读取、连续失败、缺序号、不完整轮次和 deadline miss。

报告自动写入：

```text
数据根目录/research_outputs/quality/<会话_哈希>/
  data_quality_report.json
  data_quality_report.csv
  data_quality_report.md
```

旧会话若没有显式时间语义，会显示“按旧主机时间格式保守解释”，不能称为设备同步时间。

## 6. 建立和评价实验组

进入“研究与算法 → 成组实验”。

1. 输入实验组名称；
2. 选择用途：重复实验、正反向、速度阶梯、加速度阶梯、稳定性/漂移或自定义；
3. 记录协议和控制变量；
4. 勾选 2～20 个会话；
5. 点击“保存所选会话为实验组”；
6. 可选择一个标定快照；
7. 点击“评价并导出”。

实验组保存相对 CSV 路径和 SHA-256。源 CSV 变化后评价会拒绝继续，避免分析对象悄然改变。

结果是描述性比较，包括：

- 各会话观测位移、终点、跟随误差、速度和质量状态；
- 重复位移离散；
- 正反向方向差/闭合偏差；
- 速度或加速度条件分组；
- 末段稳定性和线性漂移。

这些结果不是外部基准下的定位精度结论。

## 7. 运行离线算法

进入“研究与算法 → 离线算法与影子”。

1. 选择源会话；
2. 选择算法；
3. 检查参数 JSON；
4. 可选择标定快照；
5. 点击“运行可复现离线算法”。

支持：

- 移动平均滤波；
- 线性漂移；
- 轨迹运动学；
- 位置分箱误差补偿表；
- 仿射误差模型；
- PID 影子输出。

结果位于：

```text
数据根目录/research_outputs/algorithm_runs/<run_id>/
  run_spec.json
  result.json
  series.csv
  run_manifest.json
  checksums.sha256
```

输入 CSV、参数、代码指纹和输出哈希都被记录。补偿和模型结果属于离线同数据评价，不能替代独立验证或现场闭环。

## 8. 回放、普通分析和交付

V1.0 功能保持不变：

- “会话管理与分析”扫描、筛选、完整性检查、单会话分析和 2～5 会话比较；
- “历史回放”查看曲线、人工事件并点击跳转；
- `analysis_summary.json/.csv/.md` 不修改原始 CSV；
- 交付 ZIP 包含源文件、完整性、摘要和校验账本。

会话浏览器额外显示标定、实验组和显式时间语义。

## 9. 文件与故障处理

常规 V2 会话包含：

```text
samples.csv
manifest.json
acquisition.log
config_snapshot.yaml
events.jsonl
checksums.sha256
```

启用实时影子时增加 `shadow_outputs.jsonl`。旧会话缺少 V2 文件或字段时仍可加载。

遇到异常时：

1. 不要编辑 `samples.csv`；
2. 在回放页检查完整性和日志；
3. 导出诊断或研究交付包；
4. 若是 incomplete，会话可使用既有非破坏性恢复流程；
5. 校验失败时保留原文件并另行复制，不要覆盖证据。

## 10. 尚未由本机离线验收证明

- 真实 PCAN/CANopen 静止和运动采集；
- Servo Studio 配合动作；
- 外部长度基准和正式精度标定；
- 设备同步时间、高频 PDO、EtherCAT 或外部传感器同步；
- 影子算法对真实运动控制的效果；
- 第二台 Windows 电脑部署。
