# Motion Acquisition V0.5 GUI 使用教程

V0.5 是只读采集、回放和实验数据管理工作站。日常使用只需双击 EXE，不需要命令行。

## 1. 启动与安全边界

1. 双击 `MotionAcquisition.exe`。
2. 软件默认进入 `Demo（无硬件）`，不会打开 CAN。
3. 真实模式仍只允许 CANopen SDO upload。软件没有 SDO download、控制字、NMT/PDO 写入、Servo On、Jog、回零或运动命令。
4. “停止采集”只停止数据读取并收尾文件，不会停止电机；现场运动仍由 Servo Studio 独立操作。

## 2. 使用采集预设

1. 在“实时采集”页填写对象、周期、持续时间和实验信息。
2. 点击预设旁的“保存当前”，输入名称即可新建；在“预设与换算”页还可保存修改、复制、重命名和删除。
3. 从“采集预设”下拉框选择预设后，GUI 会自动填写对象、周期、持续时间、实验名称、轴、方向、速度、加速度、减速度、Jerk 和备注。
4. 开始前仍可修改任何字段。预设只填写界面和实验记录，不会发送运动参数。
5. 用户预设存放在当前 Windows 用户配置目录；修改或删除不会改变历史会话 manifest 中的快照。

## 3. 可选的简单 counts 换算

1. 在“预设与换算”页填写名称、轴、scale、offset、物理单位和备注，保存配置。
2. 公式固定为 `physical_value = scale × raw_counts + offset`。
3. 在“实时采集”页选择配置后，位置给定、实际位置和跟随误差会同时显示 raw counts 与换算值。
4. 换算列始终明确显示“未验证换算”。默认不选择任何换算，软件不会根据历史工程估计自动生成正式配置。
5. `samples.csv` 始终只保存 raw counts；本次完整换算配置写入 manifest 快照，后续修改或删除用户配置不影响历史会话。

## 4. 采集与人工事件

1. 选择 Demo 或已经单独放行的真实只读链路，核对采集对象、周期、持续时间、实验信息、数据目录和可选换算。
2. 点击“开始采集”。事件按钮只在采集中启用。
3. 可记录“运动开始”“运动结束”“方向切换”“异常”，也可输入自定义备注后点击“记录备注”。
4. 每次点击记录的是上位机侧人工标记时间和最近 sample_seq，不是驱动器同步时间。
5. 自然完成、主动停止或 error 收尾时，已接收事件都会保存在 `events.jsonl`。

每个 V0.5 会话包含：

- `samples.csv`：原有 16 列 raw 数据，权威原始记录；
- `manifest.json`：配置、统计、实验信息及可选 preset/conversion/events_summary 快照；
- `acquisition.log`：会话日志；
- `config_snapshot.yaml`：采集通信配置快照；
- `events.jsonl`：UTF-8、逐行 JSON 的人工事件；没有点击事件时文件仍存在。

## 5. 会话浏览、回放和分析

1. “会话管理与分析”扫描数据目录后，会显示预设名称、换算名称和事件数量；旧会话缺失这些字段时显示为空或 0。
2. “历史回放”可打开会话目录或旧 16 列 CSV。事件显示在列表和位置时间线的竖线上。
3. 点击事件列表任一行，会跳转到对应 sample_seq 或最接近的 elapsed_s。
4. 单会话分析、2～5 会话比较和三种摘要导出沿用 V0.4，均不修改原始 `samples.csv`。
