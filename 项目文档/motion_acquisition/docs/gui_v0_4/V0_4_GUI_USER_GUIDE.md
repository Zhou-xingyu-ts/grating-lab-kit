# Motion Acquisition V0.4 GUI 使用教程

V0.4 是只读采集、回放和实验数据管理工作站。全程可使用 GUI，不需要命令行。

## 1. 启动与 Demo

1. 复制完整 `MotionAcquisition` 文件夹，双击 `MotionAcquisition.exe`。
2. 软件默认进入 `Demo（无硬件）`，不会打开 CAN。
3. 填写实验名称、操作者、轴、方向、目标位移、速度、加速度、减速度、Jerk 和备注。
4. 这些运动参数只写入 manifest，绝不会发送给设备；未冻结物理单位时请把单位一并写在输入值中。
5. 选择对象、周期、持续时间和数据目录，开始或停止采集。每个会话仍生成 `samples.csv`、`manifest.json`、`acquisition.log` 和 `config_snapshot.yaml`。

## 2. 会话浏览与筛选

1. 打开“会话管理与分析”。
2. 点击“扫描数据目录”。扫描在后台线程执行，不访问 CAN。
3. 可按日期、实验名称、方向和 outcome 筛选。
4. 表格显示采样轮数、manifest 实际频率、失败读取、deadline miss 和完整性状态。
5. 单选会话后可打开回放或定位所在目录。

旧 manifest 没有结构化实验信息时仍可识别；缺失字段显示为空或“不具备该数据”，不会补造内容。

## 3. 单会话分析

1. 在会话表中选择一个会话，点击“分析所选会话”。
2. 分析在独立后台线程逐行读取 CSV，可点击“取消分析”。
3. 结果包括实际采样频率、持续时间、各对象最小/最大/均值/总体标准差、跟随误差最大绝对值/均值/RMS、实际位置范围、速度峰值、失败读取和 deadline miss。
4. 对象不存在时显示“不具备该数据”。
5. 点击“导出三种摘要”，在会话目录生成 `analysis_summary.json`、`analysis_summary.csv` 和 `analysis_summary.md`。原始 `samples.csv` 不会修改。

## 4. 多会话比较

1. 使用 Ctrl 或 Shift 选择 2～5 行。
2. 点击“比较所选 2～5 个会话”。
3. 工作站叠加实际位置、跟随误差和速度的有界抽样曲线，并显示简洁对比表。
4. 对比只提供描述性数值和曲线，不做统计推断或自动结论。

## 5. 历史回放

“历史回放”仍可直接打开会话目录或16列 CSV，支持播放、暂停、倍速、轮次跳转、完整性显示、中断恢复标记和诊断包导出。回放不访问 CAN。

## 安全边界

- 真实链路只允许 CANopen SDO upload。
- 不提供 SDO download、控制字、目标值、NMT 写入、PDO、EtherCAT、Servo On、Jog、回零或运动命令。
- “停止采集”只停止读取，不是电机停止功能。
- 当前版本尚未完成真实硬件和第二台 Windows 电脑验证。
