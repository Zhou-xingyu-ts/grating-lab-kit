# 34_全系统逐根接线总表

> 本文件是当前执行层的“接线入口索引 / 调度表”，不是单独的最终放行表。  
> 任何接线是否允许执行，必须以 `39_上电前逐线放行矩阵.md`、`40_逐线验收记录表.md`、`46_未闭环逐线缺口清单.md` 和现场实测/手册证据为准。  
> 本文件不得把未闭环接线写成已完成。

## 1. 当前系统口径

当前目标仍是用已有 Z 轴平台验证低速、小行程、可停止的单轴闭环控制链。2026-08-01 更新：Windows-PCAN 对 DS-BVM 的固定单轴 PPM `+5000/-5000 counts` 已完成一次控制—采集闭环；GM1/EtherCAT 与 STM32/CANopen 仍是独立待验证差异层。本文件继续只作为接线入口，不把单次软件运行改写成逐线普遍放行。

共享硬件底座：

```text
Renishaw grating scale / Ri0040
-> DINGS DS-BVM
-> 30ZWWC65TEK5B-1 brake-equipped coreless motor
-> motor encoder, brake, STO/J13, 24 V power and safety checks
```

控制路线：

| 路线 | 当前口径 |
|---|---|
| GM1 / EtherCAT | `Panasonic GM1 -> EtherCAT -> DS-BVM` |
| STM32H743 / CANopen | `STM32H743 -> CAN transceiver -> CANopen -> DS-BVM` |
| Windows / PCAN / CANopen | `Windows -> XCAN-USB/PCAN -> CANopen -> DS-BVM`；固定PPM首次闭环已验证 |

三条路线共用 DS-BVM、电机、编码器、刹车、STO/J13、24 V 电源和安全检查。STM32/CANopen 路线中，STM32 只替代 GM1 或 Windows 成为总线主站，不直接接电机 U/V/W、编码器或刹车。

Windows-PCAN 的一次固定轨迹实验已在用户逐项确认现场条件并明确授权后完成，详见 `60_实验室推进记录/2026-08-01_Windows直连DS-BVM_PCAN_PPM首次闭环.md`。该结果不自动放行 GM1、STM32、任意轨迹或后续无人确认的运动。

## 4. 双路线差异层索引

### 4.1 GM1 / EtherCAT 路线

GM1 / EtherCAT 路线只处理 Panasonic GM1 主站、EtherCAT 线缆、ESI/XML、扫描、PDO 和对象读写。DS-BVM 到电机、编码器、刹车、STO/J13、电源的安全底座仍按 `57`、`39`、`40`、`46` 执行。

应查文件：

|---|---|
| `02_实验与现场/01_当前执行/57_共享硬件底座与双总线验证计划.md` | 确认共享底座和 GM1/EtherCAT 差异层边界 |
| `03_资料与参考/02_技术调研/控制链路方案对比/EtherCAT_GM1_DS-BVM_候选路线/00_索引.md` | EtherCAT 候选路线资料入口 |

### 4.2 STM32H743 / CANopen 路线

STM32H743 / CANopen 路线只处理 STM32 主站、CAN 收发器、CANH/CANL/GND、CANopen 报文和对象读取。DS-BVM、电机、编码器、刹车、STO/J13 和电源仍属于共享硬件底座。

应查文件：

| 文件 | 用途 |
|---|---|
| `02_实验与现场/01_当前执行/57_共享硬件底座与双总线验证计划.md` | CANopen 差异层、物理层、只读监听和 SDO 只读边界 |
| `02_实验与现场/01_当前执行/58_现场实拍确认事实索引.md` | STM32H743、USB-CAN、疑似 VP230、DS-BVM CAN 口等照片事实 |
| `02_实验与现场/01_当前执行/46_未闭环逐线缺口清单.md` | CANopen 相关未闭环项继续保留 |
| `03_资料与参考/02_技术调研/控制链路方案对比/CANopen_STM32_赖建君原路线/00_索引.md` | STM32/CANopen 技术调研入口 |

STM32H7 FDCAN 逻辑引脚不得直接接 DS-BVM CAN `HIGH/LOW`，必须经过板载或外接 CAN 收发器。CANH/CANL/GND、终端电阻、共地/隔离、nodeID、波特率、heartbeat/boot-up、SDO 只读返回均未闭环前，不得发送控制命令。

### 4.3 Windows / PCAN / CANopen 研究路线

Windows 路线使用现场已有 XCAN-USB 的 PEAK-System 兼容接口，不改变 DS-BVM 到电机、反馈、刹车和电源的共享底座接线。2026-08-01 正式会话 `motion_acquisition\data\20260801\2026\08\20260801_233700_run-3a2bfcc9` 已证明 Node 1、1 Mbps 下 NMT、CiA 402、固定 PPM 和同步 SDO 采集可闭环。该路线的控制实现、Manifest和控制日志与 STM32 路线分开保存，不将 PC 端成功冒充 STM32 证据。

## 5. 当前禁止误判事项

- `fdcan_demo` 不等于现场最终 CANopen 主站固件。
- VP230 仍是疑似，不是已确认芯片型号。
- U/V/W 颜色或线标不等于已完成相序和运动方向放行。
- DS-BVM 手册 pinout 不等于现场线已经接好。
- STIL CCS PRIMA 不是电机控制链路必要组成。
- 照片只能证明可见事实，不能单独证明电气连续性、固件身份、CAN 节点号/波特率或运动安全。
- 只读通信成功不等于运动放行。
