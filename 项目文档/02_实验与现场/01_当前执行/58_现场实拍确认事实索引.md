# 现场实拍确认事实索引

> 更新时间：2026-08-01
> 用途：固定近期现场照片、截图和明确命名的软件会话证据，供后续对话、文档整理和现场研判查询。照片只证明可见事实；软件会话只证明其记录的那次运行，均不自动等于普遍接线或运动放行。

## 1. 总口径

当前台架按”一套共享硬件底座 + 多条控制路线”管理。Windows-PCAN 研究路线已经完成一次固定 PPM 闭环；STM32 与 GM1 仍是待验证路线：

```text
已验证工作链路：
PC(USB) -> Servo Studio -> DS-BVM -> 电机 U/V/W + 光栅尺(数字编码器口)
Windows -> XCAN-USB/PCAN -> CANopen -> DS-BVM -> 同一共享底座

其他差异层（待验证）：
GM1 -> EtherCAT -> DS-BVM
STM32H7 -> CAN 收发器 -> CANopen -> DS-BVM
```

照片确认的关键点是：CANopen 方案不是把电机线、编码器线或刹车线接到 STM32；STM32 只可能替代 GM1 成为总线主站。只要 DS-BVM、电机、编码器、刹车和电源不换，两条路线共用同一套电机侧接线和驱动器参数底座。

## 4. CANopen 路线的最小物理链路

照片和手册支持的 CANopen 候选链路如下：

```text
STM32H743 FDCAN_TX/RX
-> 板载或外接 CAN 收发器
-> CANH / CANL / CAN GND
-> DS-BVM CAN J8/J9: HIGH / LOW / GND
-> DS-BVM 内部 CANopen/CiA402 对象
-> DS-BVM 驱动电机 U/V/W 并读取电机编码器
```

禁止误接：

- STM32 FDCAN 逻辑引脚不能直接接 DS-BVM `HIGH/LOW`。
- 电机三相 U/V/W 不能接 STM32。
- 电机编码器 8 线不能接 STM32 当作 CANopen 主站输入。
- 刹车白线不能接 STM32 GPIO，也不能假定可由 DS-BVM GPO 直驱。
- STIL CCS PRIMA 的 `ENCODERS` 口不能当成电机编码器接入 DS-BVM 的替代口。
