# 自动刹车外部电路候选方案

> 适用场景：`30ZWWC65TEK5B-1` 带刹车电机，两根白色刹车线先按独立 24 V 刹车线圈处理。DINGS DS-BVM-FETC 的 J13 `GPO0/GPO1` 只允许作为小电流控制信号，不能直接给刹车线圈供电。

这份文件解决一个现场很危险的问题：以后想让驱动器 Servo On/Off 时自动释放/抱闸，刹车线到底怎么接？

先给结论：**第一轮低速闭环验证，刹车继续用独立 24 V 手动控制；自动刹车只能作为后续扩展。** 要自动化，也必须走“GPO 控制中间器件，中间器件控制刹车 24 V 功率回路”的结构。

> **安全提醒：刹车不是普通指示灯。**  
> Z 轴刹车一释放，平台可能因重力下滑。任何刹车上电、断电、自动控制测试前，必须有机械支撑、限位、急停/断电手段和人员分工。人手托住不算机械支撑。

> 📎 DS-BVM-FETC 的官方硬件手册：<https://www.dingsmotion.cn/uploadfile/2022/0509/20220509031426706.pdf>  
> 请重点看 J13 引脚和 Digital Output 参数。手册给出 J13 pin 8/9/10 分别是 `GPO0/GPO1/GPO_COMMON`，Digital Output 为 24 V、open collector、最大输出电流 50 mA。

> 📎 DS-BVS/BVM 的官方参考手册：<https://www.dingsmotion.cn/uploadfile/2022/0509/20220509031529520.pdf>  
> 请重点看 `0x4610 Brake Parameters` 和 `0x60FE Digital Outputs`。参考手册说明刹车功能可以映射到 digital output，同时提醒要考虑输出电流限制。

> 📎 DINGS Servo Studio 官方软件页：<https://www.dingsmotion.cn/software/110-1.html#>  
> 请重点看 Servo Studio Manual 的 Brake Setting：`Digital Output bit0`、Brake Polarity、Release/Holding delay。软件能配置输出逻辑，但不能让 50 mA 的 GPO 变成功率刹车电源。

## 为什么不能把 GPO 直接接两根白色刹车线

DS-BVM-FETC 手册给出数字输出最大 50 mA。刹车线圈是电磁负载，实际电流必须由现场测得：

```text
刹车电流 I = 24 V / 刹车线圈电阻 R
```

举几个数，你马上就能判断：

| 刹车线圈电阻 | 估算电流 | 是否能直接由 50 mA GPO 带 |
|---:|---:|---|
| 20 ohm | 1.2 A | 不能 |
| 60 ohm | 0.4 A | 不能 |
| 120 ohm | 0.2 A | 不能 |
| 480 ohm | 0.05 A | 理论接近上限，工程上仍不建议直接带 |

你可能会问：“如果我量出来刚好 50 mA 以下，是不是就能接？”  
不建议。因为刹车是感性负载，断电时会产生反向尖峰；GPO 是驱动器内部小信号输出，不应该承担线圈浪涌、长线干扰和刹车功率回路故障。

所以本项目规则很硬：

```text
GPO0/GPO1 不接刹车白线。
GPO0/GPO1 只接继电器、光耦、MOSFET 驱动级或假负载。
刹车白线只接外部 24 V 功率回路。
```

## 先把刹车本体测清楚

自动刹车之前，先做本体测试。

| 项目 | 怎么测 | 通过标准 |
|---|---|---|
| 两根白线电阻 | 断电，用万用表电阻档测 | 不是短路，不是开路，数值能算出合理电流 |
| 是否分正负极 | 看电机图纸/线标；没有标记则短时低风险测试 | 有极性按极性接，无极性按线圈处理 |
| 24 V 释放 | Z 轴支撑后短时上 24 V | 听到/感觉释放，电流合理，无发热 |
| 断电抱闸 | 断开 24 V | 能抱住或恢复制动状态 |
| 持续通电能力 | 查厂家 | 不确定时只短时测试 |

记录表：

| 项目 | 实测值 |
|---|---|
| 刹车线圈电阻 R | ____ ohm |
| 估算电流 24/R | ____ A |
| 通电电流 | ____ A |
| 通电释放现象 | ____ |
| 断电抱闸现象 | ____ |
| 是否分正负 | ____ |
| 测试时 Z 轴支撑方式 | ____ |

如果这张表没填，后面所有自动刹车方案都只能停留在图纸候选。

## 方案 A：中间继电器

这个方案最容易给新人讲清楚：DS-BVM 的 GPO 只驱动继电器线圈，继电器触点去接刹车功率回路。

```text
控制回路：
外部 24V+  -> 继电器线圈 -> GPO0
外部 0V   -> GPO_COMMON
继电器线圈两端并续流二极管或 TVS

功率回路：
外部 24V+ -> 保险 -> 继电器常开触点 -> 刹车白线1
外部 0V  -> 刹车白线2
刹车线圈两端并 TVS 或续流保护
```

| 优点 | 缺点 | 适合阶段 |
|---|---|---|
| 直观、隔离清楚、容易用万用表查 | 有机械寿命，动作较慢，继电器线圈也要保护 | 第一版自动刹车验证 |

关键判断：

| 项目 | 要求 |
|---|---|
| 继电器线圈电流 | 必须小于 GPO 允许电流，建议留足余量，不贴 50 mA 上限运行 |
| 触点电流 | 大于刹车实际电流，并留余量 |
| 触点形式 | 通常用常开触点：GPO 有效 -> 继电器吸合 -> 刹车通电释放 |
| 失电状态 | 默认断电抱闸，符合 Z 轴保守策略 |
| 保护器件 | 继电器线圈和刹车线圈都要有续流/TVS |

注意：如果继电器线圈本身电流就超过 50 mA，仍然不能直接接 GPO。那就要再加一级晶体管/光耦驱动，或选小电流接口继电器。

## 方案 B：光耦隔离 + MOSFET

这个方案用 GPO 驱动光耦输入，光耦输出再控制 MOSFET，MOSFET 开关刹车线圈。

```text
控制侧：
DS-BVM GPO0/GPO_COMMON -> 限流电阻 -> 光耦输入

功率侧：
外部 24V+ -> 保险 -> 刹车白线1
刹车白线2 -> N-MOSFET Drain
N-MOSFET Source -> 外部 0V
刹车线圈两端并 TVS 或续流二极管
MOSFET Gate 由光耦/驱动电路控制，并有下拉电阻
```

| 优点 | 缺点 | 适合阶段 |
|---|---|---|
| 无机械触点，响应快，寿命长 | 需要懂 MOSFET 选型、栅极驱动、浪涌保护 | 后续工程化版本 |

选型要点：

| 项目 | 要求 |
|---|---|
| MOSFET 电压 | 至少高于 24 V 系统并留浪涌余量 |
| MOSFET 电流 | 大于刹车电流并留余量 |
| `Rds(on)` | 足够低，避免发热 |
| Gate 下拉 | 必须有，防止上电悬空误释放刹车 |
| 保护 | 刹车线圈两端加 TVS/二极管，必要时 MOSFET D-S 保护 |
| 默认状态 | 控制失效时 MOSFET 关断，刹车断电抱闸 |

续流二极管保护简单，但会让线圈电流衰减慢，刹车抱闸可能变慢；TVS 能把电压钳在较高但安全的水平，释放能量更快。最终选哪种，要看刹车厂家允许的浪涌和抱闸时间要求。

## 方案 C：成品光耦继电器或固态继电器

```text
GPO0/GPO_COMMON -> 成品隔离输入
成品输出 -> 串在外部 24 V 刹车功率回路
```

| 优点 | 缺点 | 适合阶段 |
|---|---|---|
| 接线简单，隔离明确 | 要确认输出类型、漏电流、压降、感性负载能力 | 不想自搭 MOSFET 时 |

固态继电器要特别注意漏电流。有些 SSR 断开时仍有微小漏电流，对刹车线圈一般不至于释放，但必须实测。还要确认它适合 DC 负载，不要拿 AC SSR 来接 DC 刹车。

## 推荐推进顺序

### 第 1 步：手动独立刹车

```text
外部 24V+ -> 保险/开关 -> 刹车白线1
外部 0V  -> 刹车白线2
```

目的：证明刹车本体的释放/抱闸、电流和安全支撑。通过后才能进入下一步。

### 第 2 步：GPO 假负载测试

先不接刹车，不接继电器，接一个小电流假负载，例如带限流电阻的 LED 或已知电阻。

```text
外部 24V+ -> 假负载 -> GPO0
外部 0V  -> GPO_COMMON
```

测试内容：

| 测试 | 记录 |
|---|---|
| Servo Studio 手动切 Digital Output bit0 | GPO0 对 GPO_COMMON 电压变化 |
| `0x60FE` 写输出 | 物理输出是否对应 |
| 断电状态 | 输出默认有效还是无效 |
| 报警/Servo Off 状态 | 输出是否按预期变化 |

这一步的目标是弄清楚 GPO 是怎么动作的，不是为了让刹车动。

### 第 3 步：接中间器件，不接刹车

用继电器或光耦/MOSFET，但功率侧先接假负载。

```text
GPO -> 中间器件控制侧
中间器件功率侧 -> 假负载
```

确认中间器件动作逻辑、延时、默认状态、发热。

### 第 4 步：接刹车线圈，低风险短时测试

只有前 3 步通过，才允许把假负载换成刹车线圈。测试时：

1. Z 轴机械支撑到位。
2. DS-BVM 保持 Servo Off。
3. 只测试刹车释放/抱闸，不点动电机。
4. 手动触发 GPO。
5. 记录刹车电流、动作时间、声音、温升。
6. 断电确认默认抱闸。

## Servo Studio Brake Setting 怎么理解

Servo Studio 里的 Brake Setting 表达的是“驱动器在 Servo On/Off 时如何控制某个数字输出位”。但要分清两层：

| 层级 | 作用 |
|---|---|
| 软件层 | 决定什么时候让 Digital Output bit0 有效 |
| 电气层 | 决定这个输出能不能安全驱动外部负载 |

软件层可以配置，不代表电气层能直驱刹车。DS-BVM-FETC 的 GPO 电流限制仍然有效。

建议首次自动刹车参数先保守：

| 参数 | 初始策略 |
|---|---|
| Brake Type | Digital Output bit0，仅在假负载验证后使用 |
| Brake Polarity | 先按假负载实测确定，不靠默认值 |
| Release Delay | 先给足释放时间，再逐步优化 |
| Holding Delay | 确保 Servo Off 前后不会掉轴 |
| Min Motor Speed for Brake On | 先让电机停稳后再抱闸 |

## 故障排查

### GPO 切换了，刹车不动作

| 先查 | 判断 |
|---|---|
| GPO0/GPO_COMMON 假负载是否动作 | 不动作说明输出逻辑或接线问题 |
| 中间继电器/光耦是否动作 | 不动作说明控制级问题 |
| 功率 24 V 是否到触点/MOSFET | 没有说明功率回路断 |
| 刹车两端是否有 24 V | 有电不动作，查刹车本体 |

### 一上电刹车就释放

| 可能原因 | 处理 |
|---|---|
| 输出极性反 | 改 Brake Polarity 或外部电路逻辑 |
| MOSFET Gate 悬空 | 加下拉，检查光耦输出 |
| 继电器触点选成常闭 | 改用常开或重新定义失电状态 |
| GPO 默认状态误判 | 回到假负载测试 |

### GPO 或中间器件发热

| 可能原因 | 处理 |
|---|---|
| 继电器线圈电流过大 | 换小电流继电器或加驱动级 |
| MOSFET 选型不够 | 换低 `Rds(on)`、更高电流/电压余量 |
| 线圈无续流保护 | 加二极管/TVS |
| 刹车电流超过设计 | 回查刹车电阻和电源 |

## 最终放行标准

自动刹车只有满足下面条件才算能接入闭环流程：

| 放行项 | 必须证据 |
|---|---|
| 刹车本体 | 电阻、电流、释放/抱闸、温升记录 |
| GPO 输出 | 假负载下 GPO0/GPO1 与软件/对象对应关系 |
| 中间器件 | 控制侧电流、功率侧电流、默认状态、温升 |
| 保护器件 | 继电器线圈和刹车线圈续流/TVS 方案 |
| 失电状态 | 断电默认抱闸 |
| 延时参数 | Release/Holding delay 已低风险验证 |
| Z 轴安全 | 支撑、限位、急停/断电、人员分工 |

本项目当前结论保持不变：**第一轮闭环调试不依赖自动刹车。** 手动独立 24 V 刹车先跑通；自动刹车在 GPO 假负载、外部驱动电路、刹车本体数据全部闭合后再接入。
