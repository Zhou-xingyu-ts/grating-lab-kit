## 1. 发给 DINGS 技术支持

设备信息：

- 驱动器：`DS-BVM-FETC/FCAO` 系列，现场型号写作 `DS BVMFETCFCAO`
- 电机：`30ZWWC65TEK5B-1` 带刹车空心杯电机
- 电机反馈：增量编码器 A/B/I 为差分；霍尔为单端数字霍尔，线色为红 `+5VDC`、黑 `GND`、灰 `Hall U`、白 `Hall V`、蓝 `Hall W`
- 当前目标：只做 Z 轴低速小行程闭环。DS-BVM、电机、编码器、刹车、STO 和电源是 GM1/EtherCAT 与 STM32/CANopen 两条路线共用的硬件底座；厂家问题优先确认这套共享底座，不绑定某一个主控制器。

请确认以下问题：

> 已有聊天记录说“正常的话有编码器就可以了 / 霍尔可以不需要”，但这不是逐针正式接线答案。下面问题仍保留，用于确认 DS-BVM J201 的 `HALL-` 处理方式和是否允许编码器-only 调试。

1. `DS-BVM-FETC` 的 J201 数字霍尔接口为 `HALL U+/U-`、`HALL V+/V-`、`HALL W+/W-`。若电机只有单端 0/5 V 数字霍尔，是否允许接入？
2. 如果允许，逐根线应如何接？

| 电机线 | 电机信号 | 当前拟接 DS-BVM | 请厂家确认 |
|---|---|---|---|
| 红 | 霍尔 `+5VDC` | J201 pin 1 `5V` | 对 / 错 |
| 黑 | 霍尔 `GND` | J201 pin 2 `GND` | 对 / 错 |
| 灰 | `Hall U` | J201 pin 9 `HALL U+` | 对 / 错 |
| 白 | `Hall V` | J201 pin 11 `HALL V+` | 对 / 错 |
| 蓝 | `Hall W` | J201 pin 13 `HALL W+` | 对 / 错 |
| 无 | `HALL U-` | J201 pin 10 | 接 GND / 留空 / 需转换 |
| 无 | `HALL V-` | J201 pin 12 | 接 GND / 留空 / 需转换 |
| 无 | `HALL W-` | J201 pin 14 | 接 GND / 留空 / 需转换 |

3. 如果 J201 数字霍尔必须差分输入，请推荐单端霍尔转差分霍尔的接法或器件型号。
4. Servo Studio 反馈类型应选哪一项：`Incremental Encoder & Hall Sensor`、`Incremental Encoder with Index & Hall Sensor`，还是其他？
5. 若只接增量编码器 A/B/I、不接霍尔，驱动器是否支持无刷电机启动/整定？如果支持，需要设置哪些参数？
6. J13 数字输入 `STO/GPI_COMMON` 的接法是 PNP 还是 NPN？请给出 `STO` 使能时的逐线接法：

| J13 pin | 信号 | 如果 PNP | 如果 NPN | 请厂家确认 |
|---:|---|---|---|---|
| 1 | `STO` | 经急停/安全开关接 +24 V | 经急停/安全开关接 0 V | 哪种有效 |
| 7 | `GPI_COMMON` | 接 0 V | 接 +24 V | 哪种有效 |

7. J13 的 `STO` 是否必须接通才能 Servo On？如果不接，驱动器是否会报 STO/安全使能错误？
8. `0x4610 Brake Parameters` 的刹车功能若映射到 `GPO0/GPO1`，我已确认 GPO 是 24 V 开集电极且最大 50 mA，因此不会直接驱动 24 V 刹车线圈。请确认推荐使用哪一个 GPO、`GPO_COMMON` 如何接，以及推荐的继电器/光耦/MOSFET 控制电路。

设备：`30ZWWC65TEK5B-1`，现场标签显示 30 mm 空心杯 + 编码器 + 刹车。

请确认以下逐线定义：

| 线组 | 现场颜色 | 当前判断 | 请供应商确认 |

| 三相动力 | 绿 | `W` | 对 / 错 |

| 编码器 | 红 | `Vcc +5V` | 对 / 错 |

| 编码器 | 黄 | `Ch B+` | 对 / 错 |

| 编码器 | 绿 | `Ch I+` | 对 / 错 |

4. 电机绕组电阻、额定/峰值电流、相序错误时驱动器是否有保护建议。

## 4. 当前不能直接接的线

这些线在厂家/现场确认前只贴标签、绝缘固定：

| 线号 | 原因 |
|---|---|
| `HALL-U-` / `HALL-V-` / `HALL-W-` | DS-BVM 数字霍尔为差分输入，电机是单端数字霍尔 |
| `J13-STO` / `J13-GPIC` | J13 输入极性和 STO 使能逻辑未确认 |
| `J13-LIM-` / `J13-LIM+` / `J13-HOME` | 当前没有限位/Home 开关，最小闭环先不用 |
| `RI-X` / `RI-E+` / `RI-E-` | Ri 设置/报警线，初次只读 A/B/Z 不需要 |
| `RI-NC10` / `RI-NC15` | Renishaw 手册要求不接 |
