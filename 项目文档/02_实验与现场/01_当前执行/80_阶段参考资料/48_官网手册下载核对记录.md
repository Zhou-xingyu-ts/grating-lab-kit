## 3. 对当前接线缺口的影响

| 缺口 | 官网下载版是否解决 | 结论 |
|---|---|---|
| `G5`：单端霍尔接 DS-BVM J201 `HALL+/-` | 未解决 | Servo Studio 手册只说明有 `Incremental Encoder`、`Incremental Encoder with Index`、`Incremental Encoder & Hall Sensor` 等反馈类型；没有给 `HALL U-/V-/W-` 接 GND、留空或转差分的逐针接法 |
| 最小闭环是否可以不接霍尔 | 有帮助 | Servo Studio 手册列出纯 `Incremental Encoder` 和 `Incremental Encoder with Index` 反馈类型，结合 2024-03-13 聊天记录，可支持“编码器优先、霍尔贴标绝缘”的最小闭环路线 |
| `G6`：J13 `STO/GPI_COMMON` PNP/NPN 极性 | 未解决 | Servo Studio 手册说明 I/O 页面可设置 Digital Inputs 的 Polarity 和 Function，但没有给 J13 公共端接 +24 V 还是 0 V 的接线图 |
| `G7b`：刹车 GPO 间接控制 | 部分支持 | Servo Studio 手册说明 Brake Type 可选 Digital Output bit0，并给出 Non Invert/Invert、Release/Holding delay；但外部继电器/光耦/MOSFET 接线仍需按硬件手册输出能力和现场电路设计 |

## 4. 后续使用规则

1. 硬件端子定义仍以 `DINGS_DS-BVM-FETC_Hardware_Manual.pdf` 为主。
2. 对象字典、刹车参数、数字输入输出对象仍以 `DINGS_DS-BVS-BVM_Series_Reference_Manual.pdf` 为主。
3. Servo Studio 操作步骤优先参考 `DINGS_Servo_Studio_Manual_官网20260601下载版.pdf`，因为它是本次从官网下载的文件；原 `DINGS_Servo_Studio_Manual.pdf` 保留作版本对照。
4. EtherCAT 主站导入文件使用 `90_原始资料/官方软件/DINGS_DS-BVS-FETC_DS-BVM-FETC_E_ESI_XML_官网/WELCON Systems EtherCAT Drive_V3_12_P0x00000001_WE.xml`；若 GM1 工程需要 ESI/XML，应优先用这一份。
5. Servo Studio 软件安装包使用 `90_原始资料/官方软件/DINGS_Servo_Studio_官网软件下载_20220712.zip`；若现场安装失败或 DINGS 支持明确要求新版工具，再回到官网软件页补下载 `Tuner Pro` 或 `Tuner FB`。
6. 这些官网手册、软件和 XML 仍不能替代现场实测：绿色 DB15 板通断、Ri 5 V、电机三相电阻、刹车电阻/释放、J13 输入极性都必须现场确认。
