# 未闭合接线项验证作业指导：Hall、J13/STO、刹车 GPO、极对数

> 更新时间：2026-06-01  
> 用途：把当前仍不能直接放行的接线项变成”可验证、可问厂家、可回填”的工程动作。  
> 边界：本文件不是让你把未知线硬接上，而是告诉你怎样在不冒险的前提下把未知项逐个关闭。
> 2026-06-12 更新：基本接线已理清，G1/G2 已关闭。当前阶段 USB+Servo Studio 调试中，CANopen 总线控制器未接入。详见 `46_未闭环逐线缺口清单.md`。

## 先把证据边界摆清楚

当前最小闭环可以推进，因为它只依赖已经能解释清楚的主链路：

```text
GM1 -> EtherCAT -> DS-BVM -> U/V/W -> 电机 -> 编码器 -> DS-BVM
GM1 <- Ri/光栅尺 A/B/Z <- 平台真实位移
刹车 <- 独立 24 V 手动验证
```

但下面四项仍不能写成“已完备”：

| 缺口 | 当前能证明什么 | 还缺什么 | 当前处理 |
|---|---|---|---|
| `G5` Hall | DS-BVM J201 有差分命名 `HALL U+/U-` 等；电机资料表现为单端 Hall U/V/W | 单端 Hall 的 `HALL-` 是否接 GND、留空，还是必须转差分 | 最小闭环不接，贴标绝缘 |
| `G6` J13/STO | J13 有 `STO`、`GPI_COMMON`，输入为 24 V 光耦隔离 | PNP/NPN 公共端接法、STO 有效电平、STO 是否必须接通 | 先不接；若需判断，用 GPI0 限流测试，不先碰 STO |
| `G7b` 自动刹车 | 软件对象 `0x4610` 支持刹车参数，GPO 可做小电流输出 | GPO0/GPO1/GPO_COMMON 实物接法、外部驱动电路 | 不直驱刹车线圈，只允许外部继电器/光耦/MOSFET |
| 极对数 | 电机型号和若干参数已知 | 电机极对数官方值 | 不能猜；等电机完整资料或厂家确认 |

> ⚠️ 本文件的硬规则  
> Hall 不接 DS-BVM，J13 不短 STO，GPO 不接刹车白线，极对数不靠经验猜。所有验证都在 Servo Off、低压限流、Z 轴有支撑的前提下做。

## G5：Hall 线怎么推进

### 为什么 Hall 第一轮不接

电机已有差分增量编码器 A/B/I，Servo Studio 支持 `Incremental Encoder` 或 `Incremental Encoder with Index` 反馈路线。也就是说，第一轮让电机低速、小行程动起来，不需要 Hall 参与。

Hall 的风险在于：电机侧看起来是单端 Hall U/V/W + 5 V/GND，而 DS-BVM J201 数字 Hall 端子表现为差分命名 `HALL U+/U-`、`HALL V+/V-`、`HALL W+/W-`。如果你把 `HALL-` 随手接 GND，可能出现误触发、反馈错误，甚至损坏输入。

现场线束事实：这 5 根 Hall 细线是从电机 U/V/W 出线处/同束同步引出的，不是另一个独立“霍尔出线口”。这只改变识别和贴标方式，不改变第一轮“不接 DS-BVM”的策略。

当前线号处理：

| 电机线 | 线号 | 当前动作 |
|---|---|---|
| Hall 5 V | `HALL-5V` | 贴标，绝缘 |
| Hall GND | `HALL-GND` | 贴标，绝缘 |
| Hall U | `HALL-U` | 贴标，绝缘 |
| Hall V | `HALL-V` | 贴标，绝缘 |
| Hall W | `HALL-W` | 贴标，绝缘 |
| J201 `HALL U-/V-/W-` | `HALL-U-` 等 | 不接 |

### 允许做的 Hall 独立体检

这一步只证明电机 Hall 本体有没有跳变，不证明它能接 DS-BVM。

> ⚠️ Hall 体检必须与 DS-BVM 断开  
> 不把 Hall U/V/W 接入 J201，不把 Hall GND 和编码器 GND 混在一起。只用独立 5 V 限流电源和万用表/示波器体检。

工具：

| 工具 | 用途 |
|---|---|
| 独立 5 V 限流电源 | 给 Hall 供电 |
| 万用表或示波器 | 看 U/V/W 跳变 |
| 4.7 kOhm 上拉电阻 | 仅在确认或怀疑开漏/开集电极输出时使用 |
| 记录表 | 记录转动角度和 U/V/W 状态 |

步骤：

1. DS-BVM 断电，Hall 线不接 J201。
2. Hall 红线接独立 5 V +，黑线接独立 5 V 0 V，电源限流从小电流开始。
3. 量 Hall U/V/W 对 Hall GND 的电压。
4. 手慢慢转电机轴，观察 U/V/W 是否在低电平和高电平之间跳变。
5. 如果输出始终悬空或只有很弱变化，再判断是否需要 4.7 kOhm 上拉；不要一上来就乱加。
6. 记录一圈内 U/V/W 的状态序列。

记录模板：

| 角度/位置 | Hall U | Hall V | Hall W | 备注 |
|---|---|---|---|---|
| 位置 1 | | | | |
| 位置 2 | | | | |
| 位置 3 | | | | |
| 位置 4 | | | | |
| 位置 5 | | | | |
| 位置 6 | | | | |

判定：

| 现象 | 结论 | 下一步 |
|---|---|---|
| U/V/W 都有清晰 0/5 V 或接近电源电压跳变 | Hall 本体大概率正常 | 仍不接 DS-BVM，等待 `HALL-` 接法 |
| 只有一相不跳 | Hall 相或线束可能异常 | 查线色、供电、输出类型 |
| 三相都不跳 | 供电、GND、输出类型或 Hall 本体问题 | 停止，问电机厂家 |
| 电流异常大 | 可能短路或接错线 | 立即断电 |

问 DINGS 的关键句：

```text
DS-BVM-FETC J201 的数字 Hall 输入是 HALL U+/U-、V+/V-、W+/W-。
我的电机 Hall 是单端 0/5 V 输出：+5V、GND、Hall U、Hall V、Hall W。
请确认单端 Hall 接入时，HALL U-/V-/W- 应接 GND、悬空，还是必须经过单端转差分电路？
如果允许直接接，请给出 J201 逐针接线图和 Servo Studio Feedback Type 设置。
```

问电机厂家的关键句：

```text
请确认 30ZWWC65TEK5B-1 的 Hall 输出类型：推挽、开漏、开集电极，还是其它。
Hall 供电电压、允许电流、输出高低电平范围、是否需要外部上拉电阻分别是多少？
```

## G6：J13/STO 怎么推进

### 为什么不能先短 STO

STO 是安全链路，不是普通输入。为了消报警随手短 STO，相当于把安全功能拿掉。更关键的是，当前资料只证明 J13 有 `STO` 和 `GPI_COMMON`，没有完全证明现场应该按 PNP 还是 NPN 接。

当前 J13 处理：

| J13 线 | 当前动作 |
|---|---|
| `J13-STO` | 不接，除非 Servo Studio 明确报 STO 且极性已确认 |
| `J13-GPIC` | 不接，等 GPI/STO 极性确认 |
| `J13-GPI0/GPI1` | 贴标绝缘，可用于限流极性测试 |
| `J13-LIM+/-` | 贴标绝缘，等限位开关方案 |
| `J13-HOME` | 贴标绝缘，等回零方案 |

### 用 GPI0 限流判 PNP/NPN，不先碰 STO

> ⚠️ 只测 GPI0，不测 STO  
> GPI0 是普通输入，适合用来判断输入公共端逻辑。STO 属于安全输入，不作为第一根试验线。测试时 Servo Off，电机不使能，Z 轴支撑。

准备：

| 工具 | 作用 |
|---|---|
| 24 V 限流电源 | 给输入测试提供电压 |
| 10 kOhm、4.7 kOhm 串联电阻 | 限制试探电流，先 10 kOhm，不触发再用 4.7 kOhm |
| Servo Studio I/O 页面 | 观察 GPI0 状态 |
| 万用表 | 量实际电压 |

测试前确认：

1. DS-BVM 已能通过 USB 连接 Servo Studio。
2. Servo Off，U/V/W 不执行运动。
3. J13 其它线保持绝缘。
4. 现场记录当前 I/O 页面截图。

PNP 假设测试：

```text
GPI_COMMON -> 24 V 电源 0 V
GPI0       -> 24 V 电源 +，中间串 10 kOhm
观察 Servo Studio 中 GPI0 是否变化
若无变化，断电后改 4.7 kOhm 再试
```

NPN 假设测试：

```text
GPI_COMMON -> 24 V 电源 +
GPI0       -> 24 V 电源 0 V，中间串 10 kOhm
观察 Servo Studio 中 GPI0 是否变化
若无变化，断电后改 4.7 kOhm 再试
```

记录模板：

| 测试 | GPI_COMMON | GPI0 经电阻接到 | 串联电阻 | GPI0 状态 | 结论 |
|---|---|---|---:|---|---|
| PNP 假设 1 | 0 V | +24 V | 10 kOhm | | |
| PNP 假设 2 | 0 V | +24 V | 4.7 kOhm | | |
| NPN 假设 1 | +24 V | 0 V | 10 kOhm | | |
| NPN 假设 2 | +24 V | 0 V | 4.7 kOhm | | |

判定：

| 结果 | 判断 | 下一步 |
|---|---|---|
| PNP 假设下 GPI0 可控变化 | 输入大概率支持 PNP 接法 | 记录，不立即接 STO |
| NPN 假设下 GPI0 可控变化 | 输入大概率支持 NPN 接法 | 记录，不立即接 STO |
| 两种都不变化 | 电阻过大、I/O 配置、接线或公共端理解仍不清 | 停止，问 DINGS |
| 两种都异常或报警 | 接法风险大 | 断电，停止测试 |

问 DINGS 的关键句：

```text
DS-BVM-FETC J13 pin 1 是 STO，pin 7 是 GPI_COMMON。
请确认 J13 输入是 PNP 高电平有效还是 NPN 低电平有效？
GPI_COMMON 应接 0V 还是 +24V？
STO 不接时是否允许 Servo On？如果必须接通，请给出急停/安全开关串入 STO 的推荐接线图。
```

如果后续确认 STO 必须接入，正确方向是：

```text
24 V 或 0 V -> 安全开关/急停触点 -> STO
GPI_COMMON -> 与输入类型对应的公共端
```

不是用一根永久短路线把 STO 固定住。临时测试也要有开关、限流、记录和恢复计划。

## G7b：自动刹车 GPO 怎么推进

### 为什么 GPO 不能直接接刹车白线

刹车线圈是功率负载，电流通常远大于数字输出能直接承受的电流。当前证据支持 GPO 是小电流输出，不能把两根白色刹车线直接接到 J13 GPO。

自动刹车要分成两个回路：

```text
控制回路：DS-BVM GPO -> 光耦/继电器/MOSFET 控制端
功率回路：外部 24 V -> 保险 -> 触点或功率管 -> 刹车白线
```

### 第一步：先完成 G7a 刹车本体测试

没有刹车本体数据，不允许做自动刹车。

| 项目 | 必须记录 |
|---|---|
| 两根白线电阻 | ____ ohm |
| 估算电流 | `24 / R = ____ A` |
| 实测释放电流 | ____ A |
| 通电动作 | 释放/无动作/异常 |
| 断电动作 | 抱闸/无动作/异常 |
| 是否分极性 | 是/否/未知 |
| 建议续流保护 | 二极管/TVS/厂家指定 |

> ⚠️ 刹车本体测试前 Z 轴必须机械支撑  
> 人手扶住不算。刹车一释放，平台可能下滑。

### 第二步：用假负载测 GPO，不接刹车线圈

假负载可以用 24 V 指示灯模块、光耦输入模块或 LED + 限流电阻。目标是确认 GPO 激活时是拉高、拉低，还是开集电极方式。

当前因为 `GPO_COMMON` 具体接法仍需确认，优先问 DINGS。若现场必须验证，按下面原则：

1. GPO 测试只接假负载，不能接刹车线圈。
2. 假负载电流必须小于 5-10 mA，低于 GPO 50 mA 上限很多。
3. Servo Studio 里只切换 Digital Output bit，不使能电机运动。
4. 每次改线前断电。

记录模板：

| 测试 | GPO_COMMON | GPO0/GPO1 接法 | 假负载电流 | 输出 bit | 假负载现象 | 结论 |
|---|---|---|---:|---|---|---|
| 1 | | | | 0 -> 1 | | |
| 2 | | | | 1 -> 0 | | |

### 第三步：画自动刹车外部电路

推荐先画成低风险的“GPO 控制中间器件，中间器件控制刹车功率”的结构。

继电器方案：

```text
DS-BVM GPO -> 继电器/光耦模块输入端
外部 24 V + -> 保险 -> 继电器触点 -> BRK+
BRK- -> 外部 24 V 0 V
刹车线圈两端 -> 续流二极管或 TVS
```

MOSFET 方案：

```text
DS-BVM GPO -> 光耦/MOSFET 驱动输入
外部 24 V + -> 保险 -> BRK+
BRK- -> MOSFET 漏极
MOSFET 源极 -> 24 V 0 V
刹车线圈两端 -> TVS 或续流二极管
```

二极管和 TVS 的取舍：

| 保护 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 续流二极管 | 简单、便宜、保护强 | 刹车释放/抱闸响应可能变慢 | 低速验证 |
| TVS | 释放更快 | 选型更严，电压和功率要算 | 对抱闸响应有要求 |

问 DINGS 的关键句：

```text
我不打算用 GPO 直接驱动 24 V 刹车线圈，只想让 GPO 控制外部光耦/继电器/MOSFET。
请确认 DS-BVM-FETC J13 的 GPO0/GPO1/GPO_COMMON 具体接法、输出类型、最大电流、激活极性。
Servo Studio Brake Type 选择 Digital Output bit0 时，对应的是 GPO0 还是其它位？
```

问电机厂家的关键句：

```text
30ZWWC65TEK5B-1 两根白色刹车线额定 24 V，请确认线圈电阻、额定电流、是否分正负极、允许持续通电时间、推荐续流二极管或 TVS 参数。
```

## 极对数怎么推进

极对数不是接线端子，但会影响电机参数和整定。当前不能从“6900 RPM、65 W、3.85 A”直接倒推出可靠极对数。极对数必须来自电机图纸、厂家参数表或铭牌资料。

当前处理：

| 场景 | 动作 |
|---|---|
| Servo Studio 参数页必须填极对数 | 不猜，暂停该项，问厂家 |
| 软件允许先用默认/识别流程 | 仍记录默认值，不把它当官方极对数 |
| 厂家给出极对数 | 回填 `49` 手册、参数卡和现场放行记录 |

问电机厂家的关键句：

```text
请确认 30ZWWC65TEK5B-1 电机的极对数/磁极数，以及 Servo Studio 中 Motor Pole Pairs 应填写的值。
如果该电机支持驱动器自动识别，请说明识别前是否必须接 Hall，是否只用增量编码器即可。
```

## 今天可以推进的安全动作

不等厂家回复，今天仍然可以做这些事：

1. Hall 全部贴标绝缘，并记录“最小闭环未启用 Hall”。
