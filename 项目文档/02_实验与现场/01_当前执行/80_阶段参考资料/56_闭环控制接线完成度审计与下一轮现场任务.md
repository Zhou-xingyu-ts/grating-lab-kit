# 闭环控制接线研判审计与下一轮现场任务

> 目的：把“候选路线资料已经写到哪里”和“现场真正能不能独立接线运行”分开。本文按目标逐项审计：能作为候选依据的给出文件位置；未闭合的给出下一步现场测量、厂家问询或官方下载任务。

当前项目场景仍然是：使用已有 Z 轴平台验证”光栅尺反馈 + 带刹车空心杯电机”的低速小行程闭环能力。2026-06-12 更新：基本接线已理清，USB+Servo Studio 是当前实际调试入口（电机 Jog、光栅反馈观测）。CANopen/EtherCAT 总线控制路线尚未最终裁定，仍按两条候选路线研判。详见 `57_共享硬件底座与双总线验证计划.md` 和 `46_未闭环逐线缺口清单.md`。

## 必须问厂家或找完整图纸的证据

| 编号 | 问题 | 为什么必须确认 | 当前不能做什么 |
|---|---|---|---|
| V1 | `30ZWWC65TEK5B-1` 极对数/Pole Pair | 影响电角度、换相、调谐 | 不能猜填 4；不能把正式 Servo On 当放行 |
| V2 | 编码器 CPR/PPR 定义 | 影响位置比例和反馈配置 | 不能凭“线数”随便换算 |
| V3 | 电机额定/峰值电流 | 影响限流、发热和调谐 | 不能用驱动器默认电流直接跑 |
| V4 | 电机类型 | 影响 Servo Studio Motor Type | 不能随便选 Sinusoidal/Trapezoidal |
| V5 | Hall 输出类型和 `HALL-` 接法 | 当前电机 Hall 是单端，DS-BVM Hall 口偏差分 | 不能接入 J201 Hall |
| V6 | STO/GPI_COMMON 有效电平 | 安全输入不能猜 | 不能盲短 STO |
| V7 | 刹车额定电流、极性、续流建议 | 决定外部自动刹车电路 | 不能接自动刹车功率回路 |

## 下一轮现场执行顺序

1. **USB+Servo Studio 调试（当前阶段）**：光栅读数方向标定、实测 counts/mm、Servo Studio Jog 参数记录。
2. **CANopen 接口激活（下一步）**：确认 STM32 CAN 收发器硬件接线 → 固件只读 → CAN 物理层验证 → SDO 只读。
3. 不接 Hall，不接自动刹车，不盲接 STO。
4. 收集 V1-V7 厂家/图纸证据。
5. 只有 CANopen 总线通信验证通过且安全条件闭合后，才做 CANopen 总线 Servo On/Jog。
6. EtherCAT 候选路线（GM1）的材料保留在 `../../../03_资料与参考/02_技术调研/控制链路方案对比/EtherCAT_GM1_DS-BVM_候选路线/`，作为备选方案参考。

## 何时才能说目标达成

只有下面证据都回填后，才能说“目标达成，这套系统你可以独立接线了”：

| 类别 | 达成证据 |
|---|---|
| 接线 | 所有必接线逐线通断、电压、电阻、绝缘记录完整 |
| 电源 | GM1 24 V、DS-BVM 电源、Ri 5 V、编码器 5 V、刹车 24 V 均实测 |
| 反馈 | DS-BVM 编码器手转连续；GM1 光栅尺静止不跳、移动连续 |
| 参数 | 极对数、CPR、电机电流、电机类型均有厂家/图纸证据 |
| 安全 | 刹车、机械支撑、急停/断电、限位策略可验证 |
| 通信 | 候选路线对应的 EtherCAT 扫描/PDO/对象读写，或 CANopen 报文/对象字典/状态机证据完整 |
| 运动 | 首次小步正反方向可停止，三本账方向和比例可解释 |
| 排错 | 常见故障已有对应检查路径，并至少完成一次异常演练或口试 |

当前还没达到这个终点。下一步最关键的不是继续写理论，而是把 F1-F10 的现场值和 V1-V7 的厂家/图纸证据补齐。
