# 2026-06-18 实验日志：光栅尺单反馈闭环与 Scope 数据记录

## 实验对象

DINGS DS-BVM 驱动 + 30ZWWC65TEK5-1 电机 + Renishaw Ri0040 光栅尺反馈（单反馈闭环），PC USB 直连 DS-BVM (CP2102N)，Servo Studio 2.01.0008。

## 实验目标

1. 确认当前系统的反馈结构（光栅尺是否真正参与闭环）。
2. 理解 PPM 模式下的位置指令、实际位置和跟随误差的含义。
3. 验证 Servo Studio Scope 的实际 CSV 导出采样率。

## 实验前状态

- 电机 Jog 点动正常（06-12 已验证）。
- 光栅尺反馈数据可在 Servo Studio 中观测（06-12 已验证）。
- DS-BVM 单编码器接口约束已确认（光栅与电机编码器二选一接入，当前接入光栅尺）。
- 对 Scope CSV 采样率无实测数据。

## 实际操作

1. 确认反馈配置：光栅尺通过绿板 DB15 → DS-BVM 数字编码器口接入，Servo Studio 中为唯一位置反馈源。
2. 在 PPM（Profile Position Mode）下执行多段位置运动：
   ```
   -205 → 795 → 3795 → 6795 → 3795 → 795 count
   （分别对应 +1000, +3000, +3000, -3000, -3000 count）
   ```
3. 使用 Servo Studio Scope 添加 Channel（Position Demand Value、Position Actual Value、Following Error、Average Current），设置 Interval Time = 1 ms / 10 ms，Buffer Size 不等。
4. 多次 Read Buffer → Save 导出 CSV。

## 现场观察

### 1. 闭环确认
- **Position Actual Value 能够跟随 Position Demand Value 变化**，且方向一致。
- Following Error 动态变化并在到位后收敛，说明光栅尺反馈已参与位置误差计算并影响电机输出。
- 正向运动跟随较好，反向回程阶段跟随误差明显增大。

### 2. Scope CSV 采样率
多次导出的 CSV 实测数据：

| 数据 | 点数 | 总时长 | 平均采样间隔 | 等效采样率 |
|------|------|--------|-------------|-----------|
| scope_usb_2026-06-18.csv | 85 | ~8.31 s | ~0.100 s | ~10 Hz |
| 另一次多段运动 | 785 | ~78.41 s | ~0.100 s | ~10 Hz |

与 Servo Studio Scope 界面中设置的 1 ms / 10 ms Interval Time 严重不一致。

### 3. 运动现象
- 正向小位移（+1000 count）：可跟随，有一定超调，静态收敛好。
- 正向大位移（+3000 count）：最终基本到位。
- 反向回程：跟随误差明显大于正向去程。

## 可支持结论

1. **当前系统为光栅尺单反馈位置闭环**。光栅尺不是只用于显示，而是当前位置闭环的实际反馈来源——这确认了"基于光栅尺反馈的闭环控制"课题的物理基础成立。
2. **PPM 位置指令单位是 count**。Target Position / Position Demand Value / Position Actual Value / Following Error 均应先在 count 域理解，物理 μm 是后续换算结果。
3. **Servo Studio Scope CSV 导出约 10 Hz**，与界面 Interval Time 设置无关。Scope Save 导出的很可能是 GUI 图表刷新数据而非驱动器内部高频缓冲数据。
4. **10 Hz 不足以支撑伺服动态分析**。加减速、超调、振荡可能发生在几十毫秒内，100 ms 采样会漏掉真实峰值误差和振荡频率。

## 不能推出的结论

- 不能根据 10 Hz CSV 判断真实最大跟随误差、超调峰值或振荡频率。
- 不能用 Actual Velocity Value 做速度环严肃分析（低频采样下量化/刷新不连续）。
- 不能把"反向跟随误差更大"直接归因于摩擦/间隙/参数——需要更高频采样和对比实验。
