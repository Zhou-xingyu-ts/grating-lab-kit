## 5A. 任务组 E：比例、方向核对与独立长度标定（2026-10-22 修订）

**目的**：分开回答“读数方向/数量级是否合理”和“实际位移误差是多少”。前者可以粗核，后者需要独立位移基准。`1 count≈0.5 μm` 仍是工程换算；本次文档修订没有新增任何实测或放行。

### E-0 前置与边界

- 先明确反馈源、可用行程、基准器具、预期移动方式和现场停止手段，再对具体动作取得授权。
- Z 轴涉及重力与刹车。Servo Off 不等于可安全手推；不得在抱闸状态下强推或强转，也不得未支撑就释放刹车。移动方式不明时停止，不自动选择手推。
- 不预定“转 10 圈”或“移动 1 mm”：位移必须由实际行程、导程、机械结构与许可范围确定。
- Servo Studio 或 CAN 读位置都属于硬件访问，需纳入当次授权；不能把“只读”写成“不接硬件”。

### E-1 可选粗核：标称导程 × 圈数

确认丝杠**每转导程**、是否存在传动比以及实际可安全移动方式后，可用转数估算位移，交叉检查 counts/mm 的数量级。单头丝杠导程等于螺距，多头时不能混用；不从看不清的螺纹照片估计。

计算关系：`估算位移 = 丝杠实际转数 × 标称导程`，`粗核比例 = Δcounts / 估算位移`。

丝杠导程误差、回差、转数判断与传动误差均可能影响估算。比值接近 1 只说明没有明显尺度错误；偏离约 2/4 倍也仅是倍频/比例配置等排查线索，不能单凭比值锁定原因。**这不是独立长度标定，不能凭“相差不到 1%”宣称微米级定位精度。**

### E-2 独立基准比较

选用量程、分辨率和校准状态适合目标的独立测量工具，记录安装方向、测点、温度及已知误差来源。按批准的行程，在静止驻留点同时记录驱动器计数与基准读数，做正反向重复。

| 次数 | 方向 | 起点 counts | 终点 counts | 基准起点 | 基准终点 | 基准单位 | counts/mm | 备注 |
|---:|---|---:|---:|---:|---:|---|---:|---|
| 待测 | | | | | | | | |

`counts/mm = Δcounts / 有符号基准位移(mm)`。需要区分比例、回差、重复性与定位误差；少数两点比例测量不等于整行程精度验收。基准能力不足时，只报告它能分辨的量级。

### E-3 方向与静止稳定性

在已批准的机械移动/支撑条件下，记录机械 Z+、Z−分别对应计数增加还是减少；静止驻留可记录 60 s 的计数范围与漂移。异常时保留原始结果，不先用软件滤波隐藏。方向不一致仅记录，任何接线或参数修改另行明确。

### E-4 回填与结论

结果回填 `40_逐线验收记录表.md`，注明采用“导程粗核”还是“独立基准比较”。只有证据覆盖的缺口才更新 `46_未闭环逐线缺口清单.md`；`00_总览.md` 的换算依据必须保留方法与适用范围。

- [ ] 反馈源与测量工况明确

- [ ] 方向极性与静止稳定性有记录
- [ ] 比例核对与精度结论分开，基准能力及未解决项写明
