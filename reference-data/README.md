## 打开方法

1. 不连接实验设备，启动 Motion Acquisition 主窗口。
2. 进入历史回放，点“打开会话目录”，选择上表任一目录本身；不要选择总的 `reference-data` 目录，也不必先导入数据库。
3. 保留该目录的完整文件；不要只复制 CSV。直控会话包括控制日志；只读会话没有控制日志可以是正常结构。
4. 如需导出 PNG、摘要或诊断 ZIP，保存到自己的独立结果目录，不写回这里。

## 原始文件与含义

- `samples.csv`：16 列原始采集记录。每轮按对象占多行，不要把 CSV 行数当成采样轮数。
- `manifest.json`：当时版本、电脑、采样参数、统计、时间语义和运行结局。原始软件版本可能为 7.0.0，不改成当前 9.0.0。
- `config_snapshot.yaml`：历史实际配置，用于追溯；不是新电脑自动生效的连接配置。
- `acquisition.log`、`events.jsonl`：原始采集日志和事件；空事件文件保留。
- `control_commands.jsonl`：直控的命令及结果，包含失败处置线索。
- `checksums.sha256`：当时已有账本；本次复制后验证通过，未新生成账本。

三组原始会话共 20 个文件、1,702,098 字节；已有账本的 17 项校验全部通过，复制文件与源文件逐字节摘要一致。原始 manifest 中的历史 hostname 等来源字段保留，仓库保持私有。

这是 DS-BVM 驱动器读取数据，不是独立自研光栅尺采集。单位以原始 counts/raw 为准；同轮对象共用主机周期时间戳，但 SDO 实际顺序读取，不提供硬件同步或硬实时证明。
